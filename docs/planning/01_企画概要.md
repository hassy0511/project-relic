## 1. コンセプト

### ひとことで
**「歩く遺物の背中で暮らす少年が、失われた文明の遺跡に潜り、世界が沈黙した理由を知る」**
ロックオン射撃と剣を切り替えて戦う 3D アクションアドベンチャー。

### ゲームの柱（4本）
1. **撃って斬る、ロックオン戦闘**
   ロックオンして敵の周りを回りながら撃つ気持ちよさを中心に置く。剣への切り替えと、ロックオン状態からの踏み込み斬りを組み合わせる。
2. **遺跡に潜り、持ち帰り、強くなる**
   遺跡で手に入れたセル（通貨）・素材・コアを町の工房に持ち帰り、主砲の強化、特殊武器の開発、アーマーの解析に使う。この循環が基本の遊びになる。
3. **歩く町という拠点**
   拠点の町は巨大な古代機械の背中にあり、物語が進むと町ごと新しい土地へ移動する。章が変わるたびに景色と遺跡が変わる。
4. **敵も味方もしゃべる**
   ボスや幹部との戦闘前後の掛け合い、戦闘中のひと言、相棒 AI のツッコミ。多すぎず、キャラが立つ量にする。

### 「ああいう感じ」と「似せない」の線引き

| 受け継ぐのは「ジャンルの手触り」 | 避けるもの（具体的に似る要素） |
|------|------|
| 3D の遺跡探索＋ロックオン射撃 | 腕そのものが砲身になるデザイン、青いヘルメット少年の外見 |
| 主武器を育てる、特殊武器を開発する | 「バスター」「E缶」「セイバー」「ディグアウト」「リーバード」などの固有用語 |
| 探索で見つけるアーマーパーツ（X 的な要素） | カプセルに入った博士のホログラムがパーツを授ける演出 |
| 光の剣（ZERO 的な要素） | 赤いアーマーに金髪ロングの剣士 |
| 憎めない敵との掛け合い | 空賊の一家と、量産型の手下という構図 |
| 島（拠点）と地下遺跡という構造 | 海の世界の島、エネルギー結晶を採掘する生業 |

→ 主砲は**手持ち（ガントレット装着型）**の機械にし、腕から生えているようには見せない。主人公は「アンドロイド」ではなく**人間＋古代の外装フレーム**という設定にする。

## 2. 世界観

### 舞台
遠い未来。地表の大半は赤錆色の砂と、先史文明が残した巨大構造物の残骸に覆われている。
技術は「未来っぽい」が現実的な理屈にはこだわらない。明るい色彩の、少しレトロフューチャーな冒険世界。

### キーワード（仮称）

| 用語 | 内容 |
|------|------|
| **大沈黙** | 約千年前、高度な先史文明が一夜にして姿を消した出来事。原因は誰も知らない |
| **巡礼機（ピルグリム）** | 山のような大きさの古代歩行機械。決まった「巡礼路」を何百年もかけて歩き続けている。人々はその背中に町を築いて暮らす。町の電力と水も巡礼機から得ている |
| **オルド** | 主人公の町を乗せている巡礼機。背中の町の名前は「オルド背町（せまち）」 |
| **ノード（中継塔）** | 巡礼路の途中に点在する先史の巨大施設。巡礼機はここに停泊してエネルギーを補給しないと先へ進めない。**各章のメインダンジョンになる** |
| **遺物（レリック）** | 先史文明の技術の欠片。生活も経済もこれに頼っている |
| **回収屋** | 地上や遺跡に降りて遺物を持ち帰る職業。免許制。主人公はその見習い |
| **番機（ばんき）** | 遺跡を守り続ける無人の自律機械。主な敵。主人に去られた今も命令を守っている |
| **セル** | 遺物由来のエネルギー電池。燃料であり、通貨でもある |
| **黎明機構** | 遺物を独占し、「先史文明の復活」を掲げる組織。敵勢力 |
| **白潮（はくちょう）** | 伝承に残る「空が白く燃える日」。千年に一度来ると言われている |

### 巡礼機とステージの関係

**巡礼機の上は安全な拠点、下の地上が冒険の舞台**という関係になっている。

- 巡礼機は歩きっぱなしではなく、巡礼路の途中にある**ノードに立ち寄って停泊**する。そこでエネルギーを補給しないと先へ進めない。
- ところがノードの多くは、千年の間に故障していたり、番機に占拠されていたり、黎明機構に先回りされて封鎖されていたりする。
  → **ノードを動かさない限り、町ごと足止めになる**。これが各章で遺跡に潜る理由になる。
- 停泊中、主人公は町の**昇降リフトで地上に降り**、周辺のフィールドを探索してからノード内部（遺跡）へ潜る。
- 一度起動したノード同士は先史の転送網でつながる。そのため、**起動済みのノードへはワープで再訪できる**（前の地域に戻れることを世界観で説明できる）。
- 第1章だけは例外で、オルド自身が突然止まるため、**オルドの体内（背中の遺構）**がダンジョンになる。

#### 1章ぶんの流れ

```
[オルド背町（拠点）]  準備・依頼・開発・会話
      │ 昇降リフトで地上へ
      ▼
[地上フィールド]      探索・小さな遺跡・賞金首の番機・素材集め
      │
      ▼
[ノード遺跡]          メインダンジョン。ギミック、隠し部屋のアーマーパーツ
      │
      ▼
[ボス戦] → ノード再起動 → オルドが次の地域へ歩き出す（移動中は町でイベント）
```

### 世界の謎（物語の背骨）
表向きの謎は3つある。
1. 先史文明はなぜ消えたのか？
2. 巡礼機はどこへ向かって歩いているのか？
3. 最近、すべての巡礼機が一斉に同じ方角（終着点〈ターミナス〉）へ進路を変えたのはなぜか？

**真相（プレイヤーが段階的に知っていく内容）**
- 白潮は実在する。千年周期で起きる、恒星由来の惑星規模の災厄である。
- 千年前、先史人は白潮から逃れるため、自らの意識をデータ化し、地下深くの〈アーカイブ〉で眠りについた。これが「大沈黙」の正体。
- データ化を拒んだ人、あるいは選ばれなかった人々は地上に置いていかれた。巡礼機は、その**置いていかれた人々のための避難船**として造られた。今の人類はその子孫である。
- 巡礼機は白潮が近づくとターミナスに集まり、合体して惑星を覆う盾になるよう設計されている。進路を一斉に変えたのはそのため。

### 敵の動機：総帥はなぜ地上を見捨てるのか
**総帥は自分たちを滅ぼしたいわけではない。「同胞を救うために、地上の人類を犠牲にする」ことを選んだ人物である。**

1. 総帥は先史人の一人で、アーカイブの**管理人**。アーカイブに異常が起きたときにだけ目覚めるよう設定されていた。
2. 約30年前に目覚めた彼が見たのは、千年のあいだに動力が尽きかけたアーカイブだった。眠る数百万の先史人の意識が少しずつ崩れ、消え始めていた。その中には彼の家族もいる。
3. 同胞を救う手段は一つしかない。ターミナスに集まる巡礼機の莫大なエネルギーを、アーカイブに注ぎ込むことである。
4. しかし、それは**盾を張るためのエネルギーと同じもの**だった。アーカイブは地下深くにあるので白潮を耐えられるが、盾がなければ地上の人類は滅ぶ。
5. 彼は「千年待たせた同胞との約束」を選んだ。黎明機構を作り、地上の人々を「先史文明が復活すれば豊かな時代が来る」と言って集めた。盾が失われることは部下にも隠している。

→ 幹部たちも途中で真相を知り、揺れ始める。これが中盤以降のドラマ（とコメディ）の種になる。

### 結末の方向性：第三の道
- ナゴミの失われた記憶の奥には、先史人の中の「置いていく側の罪悪感に苦しんだ人々」が用意していた、もう一つの計画が眠っている。
  それは、盾として役目を終えた巡礼機がエネルギーを取り戻し、アーカイブの人々を受け入れる「器」になれる、というもの。
- 総帥はこの計画を知らない。主人公はそれを示すが、彼は信じられずに最終決戦になる。
- 白潮を越えたあと、先史人は巡礼機に移り住む形で目覚め、今の人類との共存が始まる。

### 章構成案（メイン 8章＋クリア後）
巡礼機オルドがターミナスへ向かって歩き、章ごとに新しい地域のノードに停泊する。

| 章 | 地域 | 主な出来事 | 章のボス |
|----|------|-----------|---------|
| 1 | オルド背町と背中の遺構 | オルドが突然止まる。外装フレームとの適合、ナゴミの目覚め（チュートリアル） | 大番機「閂（かんぬき）」 |
| 2 | 錆の砂海 | ライバル初登場（ノードを奪い合う）。黎明機構が姿を見せる | 黎明機構幹部① |
| 3 | 鏡の塩原 | 光を反射させるギミック。父の足跡をたどる | 大番機 |
| 4 | 呑まれた塔（樹海化した巨大塔） | ライバルとの共闘 | 黎明機構幹部② |
| 5 | 凍結プラント | 白潮の真相の断片を知る。オルドが襲撃される | 大番機 |
| 6 | 浮遊岩礁 | 総帥の正体と動機が明らかになる | 黎明機構幹部③ |
| 7 | 暁の城塞（黎明機構の本拠） | ライバルとの決着、幹部たちの選択 | 黎明機構幹部④ |
| 8 | 終着点ターミナス | 白潮の到来、最終決戦 | 総帥 |
| 後 | 深層アーカイブ | やり込み用の深層ダンジョン、裏ボス | — |

メイン 16時間は、1章あたり約2時間（フィールド 20分＋遺跡 60分＋ボスと物語 20分＋町 20分）で見積もっている。

## 3. キャラクター

### 名前の付け方ルール
- 実在の著名人、有名な作品のキャラクターと同じ名前・酷似した名前は使わない。
- 確定する前に、Web 検索と商標検索（J-PlatPat など）で衝突がないかを確認する。
- 響きの方向性：巡礼機の民は短く呼びやすい愛称的な名前、先史人はラテン・ギリシャ語風の長めの名前にする。

### 主人公側

**ハル**（15歳・少年）｜主人公
- オルド背町で育った見習い回収屋。前向きで調子に乗りやすいが、筋は通す。
- 伝説の回収屋だった父は、10年前に「ターミナスへ行く」と言い残して行方不明になった。
- 父が遺した記録ログを遺跡で集める要素がある（収集要素と真相の断片を兼ねる）。

**ハルの目的の移り変わり**

| 時期 | 目的 |
|------|------|
| 物語開始時 | **一人前の回収屋になること**（正式な免許を取る）と、工房に作ったツケ（修理代）を返すこと。父を探したい気持ちはあるが、まだ力がない |
| 第1章 | ある朝、オルドが突然止まる。止まったままだと町の電力と水が尽きる。大人の回収屋たちは遠征中で戻らない。ハルは無断で背中の遺構に潜り、外装フレーム〈ヴェスティージ〉とナゴミに出会い、オルドを再起動させる → **町を救う** |
| 第2章〜 | 再起動したオルドは、他の巡礼機と同じくターミナスへ進路を変える。そこは父が最後に目指した場所でもある。ハルは**オルドを先へ進ませるため**に各地のノードを動かしながら、**父の足跡を追う** |
| 中盤〜 | 白潮と黎明機構の目的を知り、**盾の完成を阻む総帥を止めること**が目的になる |

**ナゴミ**｜外装フレームに宿る先史 AI（ナビ役）
- ハルの肩のあたりに浮かぶ、小さな光る球体ドローンとして姿を見せる。
- 記憶領域の大半が壊れている。丁寧語で話すが、どこかずれた発言をする。ハルとの掛け合いの要。
- ロックオン時の弱点解析や遺跡の案内を担う。記憶が戻るにつれて「第三の道」に近づく。

**ヤーナ**（38歳・女性）｜工房主（開発役）
- ハルの父の元相棒。義手の元・一流回収屋で、今は町の工房を営む。
- 豪快で酒好き、面倒見がいい。ハルのツケの債権者でもある。主砲の強化、特殊武器の開発、アーマーの解析を担当する。

### ライバル（コメディ枠）

**ボルタ**（17歳・少女）｜ライバル
- 別の巡礼機の町「カラン」から来た、自称「天才」の回収屋。自作の二脚機甲〈ボルタ号〉に乗って現れる。
- カランもエネルギー不足で、同じノードを狙っている。そのため毎章ぶつかる。
- 登場するたびに機甲が妙な方向に改造されていて、最後は派手に自爆して撤退するのがお約束。機甲に積まれた辛口 AI が彼女にツッコミを入れ、ナゴミとの「AI 同士の掛け合い」も生まれる。
- お金に弱く、一時期は黎明機構に雇われて（騙されて）いる。中盤で騙されていたと知って共闘し、終盤では「ライバルとしての」決着をつける。

### 敵勢力：黎明機構

**アルデン**｜総帥・ラスボス
- 穏やかで理知的。先史人で、アーカイブの管理人。動機は上の「敵の動機」のとおり。

**幹部4人**｜章のボス（戦闘の前後や最中に掛け合いがある）
- 鉄腕の武人（正々堂々を好む）、ドローンを操る狙撃手（冷徹）、幻影とトラップを使う道化、総帥に心酔する氷の剣士。
- 全員が今の時代の人間で、総帥の嘘を知らずに従っている。
- 名前は v0 の案に有名作品との衝突があったため、ルールに沿って確認済みの案を詳細設計で改めて出す。
- 倒すと「コア」を落とし、工房主がそれを特殊武器に加工する。

### その他
- 大番機各種（章ボス）と雑魚の番機（地域ごとに 4〜6種）。
- 町の住人：店主、依頼人、子どもたちなど。サブクエストの担い手。

## 4. ゲームシステム概要（詳細設計はこの後）

| 分類 | 設計の方向 |
|------|-----------|
| 操作・カメラ | 3人称のフリーカメラ。ロックオン中は敵を中心に周回（ストレイフ）でき、ターゲットを切り替えられる。ゲームパッドとキーボード・マウスの両方に対応 |
| 移動 | 走る、ジャンプ、ダッシュ。アーマーによってエアダッシュや二段ジャンプなどが解放される |
| 主砲 | ガントレット装着型。攻撃力・連射・射程・弾速・チャージの5軸で強化する。チューニングチップ（スロット制、長所と短所がある）で性能をカスタマイズできる。上限まで上げるのに長い時間がかかり、やり込み要素になる |
| 光刃（剣） | 3段コンボ、ダッシュ斬り、溜め斬り。ロックオン中は敵に踏み込んで斬る。剣技は遺跡で見つけた記録から習得する |
| 特殊武器 | 8種以上。ボスのコアと素材から開発し、レベルアップさせる。ドリルで壁を壊す、冷気で水を凍らせるなど、探索用の鍵も兼ねる |
| アーマー | 頭・胴・腕・脚の4部位×複数シリーズ。遺跡の隠し部屋で見つける。組み合わせは自由で、シリーズをそろえるとボーナスがある。能力で行ける場所が増え、既に訪れた遺跡を再探索する動機になる |
| 経済・成長 | セルと素材を集めて工房で使う。町の発展（施設の開放）にもつぎ込める |
| 町・サブ | 住人の依頼、町の発展、賞金首の番機、射撃場やレースなどのミニゲーム、図鑑、父のログ収集 |
| 進行・セーブ | 章とフラグで進行を管理する。セーブ地点でのセーブに加え、エリアを移るたびにオートセーブする。複数スロット |
| 難易度 | ノーマル／ハード、クリア後にエキスパートを追加 |

## 5. 技術方針

| 項目 | 方針 |
|------|------|
| エンジン | **TypeScript + Three.js + Vite**。ブラウザで動くので、プレイ確認が簡単 |
| 当たり判定・物理 | Rapier（WASM）のキャラクターコントローラーを使う |
| 3D モデル・モーション | **Blender をスクリプトで操作して生成**し、glTF で出力する。モデルそのものをコードとしてバージョン管理できる。コンテナで Blender が動かない場合は、TypeScript 側でモデルを生成する方式に切り替える（MVP で検証する） |
| マップ | 地域ごとの「部品キット」（床・壁・柱・階段など）を作り、配置はデータファイルで定義する |
| データ駆動 | 武器・敵・会話・クエスト・マップ・ドロップはすべて定義ファイルで管理する。量産の要になる |
| サウンド | 最初は Web Audio によるコード生成の SE と BGM を使う。のちに無料素材への差し替えや追加を検討する |
| 検証 | 単体テスト（Vitest）と、ヘッドレス Chromium による自動プレイ・スクリーンショット確認（Playwright） |
| 性能目標 | 中程度の性能の PC で 1080p・60fps |
| 販売形態 | Web 版で開発し、販売時は Electron または Tauri でデスクトップアプリ化して Steam などに出す想定 |

## 6. Codex への発注の進め方（D. 表現）

### 流れ
1. **アートバイブル発注**：世界観とキャラ設定を渡し、画風の方向性案を 3 案描いてもらう → あなたが選ぶ。
2. **個別の設定画発注**：選ばれた画風で、キャラクター・機械・背景キット・UI を発注する。
3. **納品**：`art/concepts/<アセットID>/` に PNG を置いてもらう。
4. **3D 化**：Claude が設定画から 3D モデルとモーションを作る。

### 発注要件の共通ルール（3D 化するための条件）
- 三面図は**透視なしの正投影**で描き、すべての図を同じ縮尺にそろえ、頭頂・肩・腰・膝・足元の高さを揃える。
- 背景は無地、陰影はフラット寄りにし、色は hex 値つきのパレット表を添える。
- ローポリで再現できるデザインにする。シルエット重視、大きな面で構成し、細部は色分けや模様で表現する。
- 既存 IP（特にロックマンシリーズ）に似ないこと。似ている点があれば指摘して修正するよう指示に明記する。

### アセット種別ごとの納品物（案）

| 種別 | 必要な絵 |
|------|---------|
| キャラクター | ターンアラウンド 5 方向（正面・斜め前・側面・斜め後ろ・背面）の A ポーズ、頭部アップ（正面・側面）、表情集 8 種（会話の顔アイコン用）、アクションポーズ 4〜6 枚、持ち物・武器の単体図、頭身比較表、パーツ分解図（アーマーの着脱部位） |
| 機械・ボス | ターンアラウンド、稼働部位の図解、攻撃モーションのキーフレーム、弱点位置の指示 |
| 背景キット | 部品一覧（床・壁・柱など）、見下ろしのレイアウト例、雰囲気を伝えるムード画 |
| UI | HUD のモック、メニュー画面、アイコン群、フォントの方向性 |

→ 個別の発注書は、キャラ設定の大枠が固まってから作成する。

## 7. 開発フェーズ

| 段階 | 内容 | 完了条件 |
|------|------|---------|
| ⓪ 企画確定 | 本書の合意 → 詳細設計書の作成 → Codex への発注書作成 | コンセプト・世界観・キャラ・システムの大枠について合意できている |
| ① MVP | 仮モデル（単純な図形）で、移動・カメラ・ロックオン射撃・剣・敵 1 種・部屋 2 つ・会話 1 本・セーブを動かす。Blender パイプラインなど技術面の検証もここで行う | ブラウザで遊べ、自動テストとスクショ確認が回っている |
| ② 本気の最小ステージ | 第1章の一部（町の一角＋遺跡 1 つ＋大番機 1 体）を製品品質で作る。Codex の絵から作った本番モデル、特殊武器 1、アーマーパーツ 1、開発 1 回、会話演出、BGM と SE を含む | 30〜60 分遊べ、手触りの調整まで終わっている。このときの作り方が以降の量産の基準になる |
| ③ 量産 | ②を手直ししつつ、2章以降を作る | 章ごとに通しでプレイできる |
| ④ 仕上げ | バランス調整、やり込み要素、クリア後コンテンツ、販売用のビルド | 通しプレイ・性能・安定性の基準を満たしている |

Codex への発注（アートバイブル・主人公まわり）は①と並行して進め、②の開始までに納品されている状態にする。

### プレイ確認と感想の戻し方
- ビルドは GitHub Pages などで公開し、URL を開けば遊べるようにする（リポジトリが非公開の場合は、手元で `npm run dev` を実行する方式）。
- 手触りの調整がしやすいよう、デバッグメニューからパラメータをその場でいじれるようにする。
- 感想は「どの場面で・どう感じたか」の粒度でもらえれば、数値に落とし込んで調整する。

## 8. タイトル案（→ 一度『ワンダリング・アーク』に決めたが、同名ゲームがあるため『アークウォーカー』に変更）

どの案も、確定前に商標と既存作品の検索を行う。サブタイトルを付けられる形にしておくと、続編を出しやすい（例：『WANDERING ARK ―白潮の彼方へ―』）。

| 案 | 意味 | 長所 | 短所 |
|----|------|------|------|
| **ワンダリング・アーク**（WANDERING ARK） | さまよう方舟。序盤は「歩く町」、真相を知ると「避難船＝方舟」という二重の意味になる | 物語の仕掛けがタイトルに込められる。響きが冒険的 | 「アーク」は使われがちな語 |
| **レリック・ピルグリム**（RELIC PILGRIM） | 遺物である巡礼機と、巡礼の旅 | 世界観の中心が直球で伝わる | 「Pilgrim」を含む有名作がある |
| **ナゴミ・オブ・サイレンス**（ECHO OF SILENCE） | 大沈黙の残響。相棒 AI のナゴミと、先史人の声を指す | 物語的で余韻がある | アクションゲームらしさが伝わりにくい |
| **ヴェスティージ**（VESTIGE） | 痕跡。主人公の外装フレームの名前であり、先史文明が残したものでもある | 短く、ロゴにしやすい | 意味が伝わりにくく、発音しにくい |
| **ピルグリム・ハート**（PILGRIM HEART） | 巡礼機の心臓（ノード・コア）と、主人公の旅心 | 優しく覚えやすい響き | 戦闘の激しさが出ない |
| **レリック・ダイバー**（RELIC DIVER） | 遺跡に潜る者。遊びの内容そのもの | ジャンルが一目でわかる | 世界観の独自性は弱い |
| **ホワイトタイド**（WHITE TIDE） | 白潮。世界に迫る危機 | 緊張感と謎がある | 不穏寄りで、明るい冒険感が弱い |

**おすすめ**：『ワンダリング・アーク』。タイトルの意味が物語の途中で変わる仕掛けが、「世界の謎を解く」ゲームと噛み合う。
