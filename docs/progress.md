## 2026-09-27：① MVP 完成（CP1）

**ここで報告して止まる**（ユーザーの指示：ゴーは MVP までの意味）。

### できたこと
| 分類 | 内容 |
|------|------|
| 土台 | Vite＋TypeScript＋Three.js＋Rapier。60Hz 固定刻み、sim と描画の分離、種つき乱数（同じ入力なら同じ結果） |
| 操作 | キーボード＋マウス、ゲームパッド。短い押下の取りこぼし防止。マウス固定が外れたら自動でポーズ |
| 移動 | 走る、ジャンプ（押す長さで高さが変わる、着地の猶予、先行入力）、ダッシュ（出だし無敵）、ダッシュジャンプ |
| カメラ | 3 人称の追従、壁の回避、ロックオン時の画面の収め方、操作がないとき背後へ回る |
| 戦闘 | ロックオン（対象の選び方、切り替え、周回移動、弱点の解析）、主武器（ラピッド型／チャージ型）、光刃（3 段コンボ、踏み込み斬り、ダッシュ斬り、空中斬り、溜め斬り＋衝撃波）、ブレイクドリル、怯み、ヒットストップ |
| 敵 | 歩哨型（距離を保って 3 連射、弱点は背中）、突撃型（溜め→突進、壁に激突すると動けなくなる）、同時に攻撃してくる数の制限、予兆の光 |
| 世界 | Blender で作った試験場（段差と溝の計測、通路、戦闘の部屋、ひび割れた壁の奥の宝箱）、セーブビーコン、中継地点、トリガー |
| 物語の仕組み | 会話（1 文字ずつ表示、途中でアイテム受け渡し）、イベントの台本、目的の表示 |
| セーブ | ビーコンでセーブ、タイトルの「つづきから」、ポーズの「最後のセーブから再開」 |
| 見た目 | 仮のハル（骨入り、14 種のアニメーション、撃つときに右腕が照準へ向く）、仮の番機 2 種、宝箱・NPC・ビーコン、弾・火花・爆発・斬撃の軌跡 |
| 音 | 自作シンセの効果音 23 種、BGM 1 曲 |
| デバッグ | 調整パネル（F1、「YAML としてコピー」つき）、入力の記録、性能の表示、無敵 |
| テスト | 手触りの数値テスト 6 本、戦闘・仕組みのテスト 13 本、ブラウザでの通し確認（撮影つき） |
| 公開 | GitHub Actions で CI と GitHub Pages への自動公開 |
