# コンテンツの書き方（部屋・扉・宝箱・仕掛け・イベント・会話）

> 段階 C（第1章の 20 部屋と町）を作る人が、**コードを触らずデータだけで部屋を作る**ための手引き。
> 動く見本は `godot/content/areas/sample.json`（広間・動力の試験室・倉庫の 3 部屋）。確認：`tools/godot.sh shot -- --room=sample.gym`（ブラウザ版は `…/?room=sample.gym`）。
> 実装は `godot/scripts/sim/`（`world.gd`・`room_geo.gd`・`cond.gd`・`story.gd`・`economy.gd`・`game_sim.gd`）。

---

## 1. ファイルの置き場所

| 置く場所 | 内容 |
|----------|------|
| `godot/content/world.json` | **目次**。どのファイルを読むか、始まる部屋。新しいファイルを足したらここに書く（ブラウザ版でも読めるよう、フォルダの自動探索はしない） |
| `content/areas/<エリア>.json` | エリア 1 つ＝部屋の集まり。部屋の id は「エリア id.部屋名」（例：`ch1.r02`） |
| `content/dialogue/*.json` | 会話（id → 行の並び） |
| `content/events/*.json` | イベント（id → 手順の並び） |
| `content/items.json` | アイテム・素材・遺物の名前と売値 |
| `content/economy.json` | 店・工房・ギルドの依頼 |

`world.json` の例：

```json
{ "start": { "room": "mvp.main", "spawn": "start" },
  "areas": ["areas/mvp.json", "areas/ch1_b1.json"],
  "dialogue": ["dialogue/mvp.json"], "events": ["events/mvp.json"],
  "items": "items.json", "economy": "economy.json" }
```

- 単位はメートル、角度は**度**（目印の yaw も度。GLB の目印は従来どおりラジアンに変換済み）。向き 0 は +Z、90 は +X。
- 座標は `[x, y, z]`。**y は上**。
- ほかの部屋を指すとき、ドットのない名前は同じエリアの部屋（`"to": "r03"`）。

## 2. 部屋

```json
"r02": {
  "name": "ジャンク溜まり",
  "map": { "floor": "B1", "x": 1, "y": 0, "w": 1, "h": 1 },
  "geometry": [ …形… ],
  "markers": { "start": { "pos": [0,0,-8], "yaw": 0 }, "from_r03": { "pos": [9.5,0,0], "yaw": -90 } },
  "playerStart": "start",
  "objective": "…",
  "props": [ … ], "triggers": [ … ], "enemies": [ … ], "checkpoints": []
}
```

- `markers`：名前つきの位置。移ってくる先（`spawn`）はここで決める。**出口の範囲の中に置かない**（着いた瞬間にまた移ってしまう。入口の 2m 以上手前に置く）。
- `map`：地図用（階層名・格子の位置・大きさ）。入った部屋は自動で記録される（フラグ `visited.<部屋 id>`）。
- GLB の地形を使う部屋は `"model": "levels/xxx.glb"` を足す（`m_` で始まるノードが目印になる。`geometry` や `markers` を足してもよい）。MVP の部屋がその例。
- `"mood"`：空と光の雰囲気。`outdoor`（屋外。フラグ `ch1.night` が立つと停電の夜）・`dawn`（夜明け）・`interior`（屋内）・遺構の階層ごとの色 `ruin_b1`（外殻層：割れ目の暖かい光）`ruin_b2`（配管層：暗い青灰）`ruin_b3`（駆動層：青銅とオレンジ）`ruin_b4`（心臓部：紫と青緑）。省略は昼。`"lights": [ { "pos": [x,y,z], "color": "#ffc27a", "range": 12, "energy": 1.5 } ]`：部屋の明かり（街灯・窓・室内灯）。
- どの部品にも `"when": 条件` / `"unless": 条件`（4 章）を付けると、その部屋に入った時点で条件に合うときだけ置かれる（イベントのあとで住人の位置が変わる、など）。
- 位置は `"at": "目印の名前"` か `"pos": [x,y,z]`（＋ `"yaw": 度`）のどちらでも書ける。

### 2.1 形（geometry）：灰色の箱から部屋を組む

| `t` | 書き方 | 内容 |
|-----|--------|------|
| `box` | `pos`（底の中心）, `size` [幅,高さ,奥行き], `yaw` | 箱。柱・壁・段・足場 |
| `ramp` | `pos`, `size`, `yaw` | 斜面（ローカルの +Z 側が高い）。45 度までは歩いて登れる |
| `stairs` | `pos`, `size`, `steps`, `yaw` | 階段（1 段 0.35m 以下で自動で登れる） |
| `shell` | `pos`（床の中心）, `size`（**内側**の寸法）, `thick`, `ceiling`, `openings` | 床＋四方の壁（天井は `"ceiling": true` のとき）。`openings` で壁に穴をあける |

`openings` の 1 つ：`{ "side": "e", "at": 0, "w": 2.5, "h": 3.5, "y": 0 }`。`side` は n（+Z）・s（−Z）・e（+X）・w（−X）の壁、`at` は壁の中心からのずれ、`y` は穴の下端の高さ。
色を変えるには各形に `"tint": "#8a8f99"`。見た目は灰色の格子（本番の地形に差し替える前提）。
本番の見た目は、部屋に `"kit"`（面の材質）と `"dress"`（飾りの部品）を足して付ける（14 章）。当たり判定は geometry のまま。

寸法の目安は `30_レベルデザイン設計.md` 1 章（通路 4m 以上、扉 2.5×3.5m、戦闘の部屋 18m 四方以上、など）。

## 3. 置く物（props）

どれも `"id"`（**世界で重ならない名前**。例：`"ch1.r02.chest1"`）と位置が要る。

| `type` | 主なキー | 内容 |
|--------|----------|------|
| `exit` | `to`, `spawn`, `size`, `lock?`, `text?` | **別の部屋への出口**。範囲に入ると移る（暗転し、オートセーブ）。開口の位置に置く。`lock` が偽なら通れず `text` を出す |
| `door` | `size`, `lock?`, `opens`, `side`, `consume?`, `text?`, `open?`, `event?` | 扉（4 章） |
| `chest` | `contents`, `event?` | 宝箱（1 度だけ。中身は 5 章） |
| `loot` | `contents` | 置いてある物。触れると 1 度だけ手に入る（遺物・素材・セル） |
| `breakable` | `size`, `breaksWith`, `toughness?`, `persist?` | ひび割れた壁（ドリルで壊す。壊すと戻らない）。`"persist": false` なら壊れた状態をセーブしない（ボス部屋の壊れる柱：やり直しで元に戻る） |
| `beacon` | `flag?`, `event?` | セーブビーコン：HP・武器エネルギー全回復、セーブ、**やられたとき戻る場所** |
| `npc` | `name`, `talk` か `event` | 住人。調べると会話（2 回目以降は `<talk>.again` があればそれ）。`id` が `npc_yana` ならヤーナのモデルが出る |
| `terminal` | `event`, `prompt?` | 調べるとイベントが走る端末・看板・店の窓口 |
| `sign` | `text`, `pos`, `size?`, `color?` | 見た目だけの看板・名札（その高さに文字が浮く）。建物の名前・訓練場の目印に |
| `decor` | `pos`（底の中心）, `size`, `color?`, `yaw?` | 当たり判定のない遠景の箱（`when` で出し入れできる）。章末の地平線のカランの影に使った |
| `switch` | `mode`, `radius?`, `timer?`, `toggle?`, `cond?` | スイッチ。`shoot`＝撃つと入る（動力の球・弁の輪。`pos` は球の中心の高さ）／`interact`＝調べると入る。入るとフラグ `switch.<id>`。`timer` 秒で切れる |
| `mover` | `size`, `move` か `to`, `speed`, `mode`, `cond`, `wait?` | 動く足場・ピストン・リフト（下記） |

### 扉・近道

```json
{ "type": "door", "id": "ch1.r10.door", "pos": [0,0,12.2], "yaw": 0, "size": [4,4,0.5],
  "lock": { "item": "key.valve" }, "consume": "key.valve", "text": "鍵が要る" }
```

- `lock`：条件（4 章）。省略すると鍵なし。
- `opens`：`interact`（調べて開ける。既定）／`auto`（`lock` の条件が満ちたら勝手に開く。「動力が通ると開く扉」）。
- `side`：`front`（扉の正面＝ローカル +Z 側からだけ開けられる）／`back`／`any`。**近道の「内側から開ける」**は、内側に向けた扉に `side` を指定し、開けた扉は `door.<id>` フラグで残る（部屋を出入りしても開いたまま）。
- 開いた扉はセーブされる（フラグ `door.<id>`）。イベントからは `{"open": "id"}` / `{"close": "id"}`。
- `"open": true`＝最初から開いている（戦闘の部屋の「閉じ込め」は、イベントで `close` し、倒したら `open`）。

### 動く足場（動力を流す仕掛け B3）

```json
{ "type": "switch", "id": "ch1.r12.s1", "pos": [-6,1.5,12], "mode": "shoot" },
{ "type": "switch", "id": "ch1.r12.s2", "pos": [6,1.5,12], "mode": "shoot" },
{ "type": "mover",  "id": "ch1.r12.piston", "pos": [0,0,9], "size": [5,0.5,5], "move": [0,4,0],
  "speed": 2.5, "mode": "toggle", "cond": { "all": ["switch.ch1.r12.s1", "switch.ch1.r12.s2"] } }
```

- `pos`＝足場の底の中心（始点）。終点は `move`（始点からの差）か `to`（座標）。
- `mode`：`toggle`（`cond` が真なら終点、偽なら始点へ。動力の足場）／`pingpong`（`cond` が真の間ずっと往復。端で `wait` 秒止まる。ピストン）／`ride`（上に乗ると終点へ、降りると戻る。リフト）。
- 乗っているハルは一緒に運ばれる。**切り替わり（動力が通ったとき）はトリガーの `on: "flag"` でカメラを足場へ向ける**とよい（`sample.gym` の `gym_power`）。
- 動力が通った状態は `ch1.drive_powered` のようなフラグにして、ほかの部屋の扉の条件にも使える。
- セーブから戻ると、条件に合った位置から始まる。

### 宝箱・拾い物の中身（contents / give）

`{ "cells": 200, "item": "chip.charge", "items": ["key.x"], "materials": { "scrap": 3 }, "relics": ["relic.old_gear"], "heals": 1, "gp": 10, "mark": "降下許可", "lifecore": true }`（すべて任意）。`lifecore` は最大 HP +20（ライフコア。セーブされる）。
アイテム・素材・遺物の名前と売値は `items.json`（`name`, `kind`, `sell`）。無いと id がそのまま表示される。

## 4. 条件（cond）とフラグ

フラグは世界で 1 つの名前の表（真偽）。イベントで立て、条件で読む。**セーブされる。**

```
"ch1.drive_powered"                        文字列＝そのフラグが立っている
{ "flag": "x" }  { "item": "key.a" }  { "cells": 200 }  { "mark": "降下許可" }  { "material": "scrap", "n": 3 }
{ "cleared": "グループ名" }
{ "not": 条件 }  { "all": [条件…] }  { "any": [条件…] }  配列＝all
```

ゲームが自動で立てるフラグ：`chest.<id>`（開けた）、`broken.<id>`（壊した）、`door.<id>`（開いた）、`switch.<id>`（入っている）、`got.<id>`（拾った）、`beacon.<id>`（使った）、`defeated.<id>`（`once` の敵を倒した）、`cleared.<グループ>`（グループを全滅させた）、`visited.<部屋>`、`trigger.<id>`（1 回きりのトリガーが走った）、`<talk>.done`（会話した）、`crafted.<レシピ>`、`request.<依頼>`。
ボス「閂」を倒すと `ch1.boss_defeated`。第1章のフラグ名は `30_レベルデザイン設計.md` 4.6 の表（`ch1.*`）に合わせる。

## 5. 敵

```json
{ "type": "sentry", "pos": [4,0,6], "yaw": 180, "id": "r09.s1", "group": "r09_wave1" }
{ "type": "kannuki", "pos": [0,0,0], "id": "kannuki", "unless": "ch1.boss_defeated" }
```

- 型：`sentry`・`charger`・`mini`・`shield`・`floater`・`kannuki`。
- `group`：同じ名前の敵が全滅すると `cleared.<group>` が立つ（トリガーの `on: "cleared"`、イベントの `wait_until` に使う）。
- `once: true`（と `id`）：倒したら二度と出ない。ふつうの敵は部屋に入り直すと復活する。
- ボスは `unless: "ch1.boss_defeated"` で、倒したあとは出さない。やられたらボスは最初から。
- `"invulnerable": true`：倒せない敵（追跡の演出の歩哨型）。部屋を出れば消える。
- `"passive": true`：何もしない敵（動かず撃たない。`invulnerable` と組み合わせると練習用の的になる）。
- 戦闘の部屋の作り方：敵を `enemies` に `group` と `"unless": "ch1.<部屋>.cleared"` で置き、「全滅したら次の波」はトリガー `{ "on": "flag", "cond": { "all": [ { "cleared": "グループ" }, { "not": "ch1.<部屋>.cleared" } ] }, "event": …, "persist": false }`。最後の波のあとにイベントで `ch1.<部屋>.cleared` を立てる。途中でやられて部屋が作り直されても、`persist: false` のトリガーと `cleared` の旗はやり直しで元に戻る。

## 6. トリガーとイベント

```json
{ "id": "enter",  "pos": [0,0,3], "size": [4,3,2], "event": "ch1.r04.enter" }              範囲に入る
{ "id": "powered", "on": "flag", "cond": "ch1.drive_powered", "event": "ch1.r12.powered" }  条件が真になる
{ "id": "wave1",  "on": "cleared", "group": "r09_wave1", "event": "ch1.r09.wave2" }         グループ全滅
```

`once`（既定 true）、`cond`（範囲に入ったとき、さらに条件を付ける）。1 回きりのものはセーブされ、二度と走らない。`"persist": false` を付けると「走った」ことをセーブしない（部屋に入り直すとまた走る。戦闘の部屋・ボス部屋の入口の会話に）。

イベントは手順の並び。1 つの手順に主となるキー 1 つ。

| 手順 | 内容 |
|------|------|
| `{"say": "会話id"}` | 会話を出す（終わるまで待つ） |
| `{"flag": "x"}` / `{"clear": "x"}` | フラグを立てる／消す |
| `{"give": { contents の形 }}` | 渡す（セル・アイテム・素材・遺物・補修パック・印） |
| `{"wait": 秒}` / `{"wait_until": 条件}` | 待つ／条件が真になるまで待つ（敵の全滅待ちなど） |
| `{"message": "文"}` / `{"objective": "文"}` / `{"sfx": "id"}` / `{"music": "id"}` | 通知／目的／効果音／音楽。音楽の既定は部屋の `mood`（遺構＝`bgm_ruins`、屋外・屋内＝昼は `bgm_town_day`・`ch1.night` で `bgm_town_night`）とボス戦（`bgm_boss`）から自動で決まる。`music` 手順は上書き：曲の ID（`bgm_end` は 1 回だけ鳴る）、`"none"` で無音、`"auto"` で自動へ戻す。部屋を移ると上書きは解ける。部屋に `"music": "id"` を書けばその部屋の既定の曲になる |
| `{"if": 条件, "then": […], "else": […]}` | 分岐 |
| `{"event": "id"}` | 別のイベントを呼ぶ |
| `{"open": "扉id"}` / `{"close": "扉id"}` | 扉を開ける／閉める |
| `{"spawn": [敵の指定…]}` | 敵を出す（`pos` か `at`、`group`） |
| `{"boss": "敵id"}` | その敵の戦闘を始める |
| `{"go": {"room": "r05", "spawn": "start"}}` | 別の部屋へ移す（崩落で B2 へ落ちる、など。`autosave: true` でオートセーブ） |
| `{"teleport": {"at": "目印"}}` | 同じ部屋の中で移す |
| `{"camera": {"pos": [x,y,z], "height": 1.5, "time": 2.0}}` | カメラをその点へ向ける（`time` 秒、待つ）。`{"camera": {}}` で戻す |
| `{"freeze": true/false}` | プレイヤーの操作を止める／戻す（演出中。会話中は自動で止まる） |
| `{"mark": "降下許可"}` | 回収屋の印を上げる（見習い→降下許可→銅→銀→金→一人前→白磁） |
| `{"shop": "id"}` / `{"workshop": "id"}` / `{"guild": "id"}` | 店・工房・ギルドの画面を開く（`economy.json`。画面は段階 D で作り込む） |
| `{"accept": "依頼id"}` / `{"complete": "依頼id"}` | 依頼を受ける／完了する |
| `{"autosave": true}` | オートセーブ |
| `{"hint": {"kb": "…", "pad": "…", "touch": "…"}}` | 操作の案内を画面の上に出し続ける（機器に合わせて文言が変わる。文字列でも可。`""` で消す）。訓練場の「歩く・跳ぶ・撃つ・ロックオン・ダッシュ」に使った |
| `{"remove": "npc_nico"}` | 住人を今の部屋から消す（走り去る演出）。部屋に入り直すと `when`/`unless` どおりに戻る |
| `{"shake": 0.5}` | 画面を揺らす（強さ 0.3〜0.9。崩落・咆哮・再始動） |
| `{"despawn": "グループ"}` | そのグループの敵を倒さずに消す（`cleared.<グループ>` は立つ） |

例（戦闘の部屋の閉じ込め）：

```json
"ch1.r09.start": { "steps": [
  { "close": "r09.door" },
  { "spawn": [ { "type": "sentry", "pos": [5,0,5], "group": "w1" }, { "type": "sentry", "pos": [-5,0,5], "group": "w1" } ] },
  { "wait_until": { "cleared": "w1" } },
  { "spawn": [ { "type": "charger", "pos": [0,0,9], "group": "w2" } ] },
  { "wait_until": { "cleared": "w2" } },
  { "open": "r09.door" }, { "give": { "cells": 80 } }, { "flag": "ch1.r09.cleared" } ] }
```

## 7. 会話

```json
"ch1.yana.debt": { "lines": [
  { "who": "ヤーナ", "face": "smirk", "text": "来たね、坊主。ツケの話だよ。" },
  { "who": "ヤーナ", "face": "normal", "text": "どうする？", "choices": [
      { "text": "払う", "set": "ch1.debt_paid", "event": "ch1.debt.pay" },
      { "text": "待ってほしい", "say": "ch1.yana.debt_wait" } ] },
  { "action": "flag", "flag": "ch1.debt_scene" },
  { "action": "give_item", "item": "special.drill" } ] }
```

- 行：`who`（名前）、`face`（表情。ヤーナは normal・laugh・surprised・angry の顔の絵がある。足りない表情は通常になる）、`text`。顔のアイコンは今は名前の頭文字の丸（仮）。
- `choices`（少なめに）：出し終えたあと上下で選び、決定で確定。`set`（フラグ）、`event`（イベントを走らせる）、`say`（続きの会話）のどれでも。
- 行と行のあいだに `{ "action": "flag" | "give_item" | "objective" | "event" | "give", … }` を入れられる。
- 住人の会話は `talk` に `"<id>"` を書き、2 回目以降の別の台詞は `"<id>.again"` を作る。

## 8. 経済（economy.json）

```json
{ "shops": { "zakka": { "name": "雑貨屋", "buys_relics": true,
      "stock": [ { "item": "consumable.repair", "price": 150 }, { "item": "key.x", "price": 500, "cond": "ch1.open" } ] } },
  "workshops": { "yana": { "name": "ヤーナの工房", "recipes": [
      { "id": "drill", "name": "ブレイクドリルを開発", "cost": 0, "needs": { "core.kannuki": 1 }, "gives": { "item": "special.drill" }, "cond": "ch1.boss_defeated" } ] } },
  "guild": { "requests": [
      { "id": "ch1.req1", "name": "探し物", "text": "…", "cond": 受けられる条件, "done": 達成の条件, "reward": { "cells": 300, "gp": 10 } } ] } }
```

イベントの `{"shop": "zakka"}` などで画面を開く。コードからは `Economy.buy / sell_relic / craft / accept_request / complete_request`。セル・素材（`materials`）・遺物（`relics`）・印（`mark`）・依頼（`requests`）・ギルドポイントはセーブされる。

## 9. セーブとやられたとき

- **ビーコン**：HP・武器エネルギーを回復し、セーブ（手動の枠）し、**やられたとき戻る場所**になる。エリアを移るたびにオートセーブ（別の枠）。「つづきから」は新しいほうを読む。
- やられたら、最後に使ったビーコン（無ければ最初の場所）から再開。開けた宝箱・壊した壁・開いた扉・倒したボス・立てたフラグはそのまま。ほかの部屋なら、その部屋は作り直される（敵は復活）。
- セーブには、フラグ全部・持ち物・セル・素材・遺物・印・依頼・今の部屋と位置・戻る場所が入る。形式は v2（v1 も読める）。

## 14. 部屋の見た目：キット（`kit`）・飾り（`dress`）・`skin`・`hide`

灰色の箱の部屋に、絵（Codex の部品のシート）から作った材質と部品をかぶせる。**見た目だけ**で、当たり判定・目印・出口・トリガー・置く物は何も変わらない（当たり判定はいつも geometry から作る）。
`"kit"` も `"dress"` も無い部屋は、今までどおり灰色の格子で描く。作るのは `scripts/view/room_kit.gd`（`RoomView.build` から呼ぶ）、テストは `tests/test_kit.gd`。

### 14.1 部屋に書くこと

| 場所 | 項目 | 内容 |
|------|------|------|
| 部屋 | `"kit": "ruins_b1"` | `content/kits/<id>.json` を読み、geometry の面に材質を貼る（14.2） |
| 部屋 | `"dress": [ … ]` | 飾りの部品（`res://assets/kit/<part>.glb`）を並べる（14.3） |
| 形（geometry の 1 つ） | `"skin": "metal"` | その形の面を全部、キットの面 `metal` にする。`{"floor": "sand", "wall": "plate"}` なら面の向きごとに替える（`floor`・`wall`・`ceiling`） |
| 形 | `"hide": true` | 描かない（当たり判定は残る）。飾りの部品がその形の代わりに見えるとき |
| 形 | `"trim": false` | その形の壁の縁取り（幅木・笠木）を付けない |

### 14.2 キット（`content/kits/<id>.json`）

```json
{
 "auto": {"floor": "floor", "wall": "wall", "ceiling": "ceiling", "up": 0.6},
 "trim": {"surface": "trim", "on": ["wall", "plate"], "base": 0.3, "top": 0.25, "out": 0.06},
 "dress_shadows": false,
 "light": {"ruin_b1": {"ambient_color": "#b49a78", "ambient_energy": 0.55}},
 "surfaces": { "floor": { "albedo": "res://assets/kit/tex/ruins_ancient_floor.jpg", "uv_m": 6, "color": "#f4ece0", "roughness": 0.8 }, … },
 "materials": { "ivory": { … }, "graphite": { … }, "amber": { "color": "#ffbc52", "emission": {"color": "#ffbc52", "energy": 4} }, … }
}
```

- `dress_shadows`：飾りが影を落とすか（既定）。天井のある屋内（遺構）は太陽が入らないので false にする（影の描画を省く）。
- `auto`：`skin` の無い面の振り分け。上向き（法線の y > `up`）は `floor`、下向きは `ceiling`、ほかは `wall` の面の名前を使う。
- `trim`：縦の四角い面のうち、面の名前が `on` にあるものの下（高さ `base` m）と上（`top` m）に、`out` m 出た帯（面 `surface`）を付ける。低い面（`base + top + 0.2` 未満）は上の帯だけ。
- `surfaces`：面の名前 → 材質。`materials`：部品（GLB）の材質の名前 → 材質（同じ名前の材質を、部屋をまたいで共有の 1 つに置き換える。無い名前は GLB の色のまま）。
- 材質の項目：`albedo`（絵。1 枚 = `uv_m` m 四方）、`color`（掛ける色）、`roughness`、`metallic`、`macro`（0〜1。別の縮尺で同じ絵を重ね、繰り返しを目立たなくする）、
  `tint_mix`（0〜1。形の `tint` を掛ける）、`seams`（`{"every": [横 m, 縦 m], "width": m, "color"}`：板の継ぎ目の線。ワールドの格子にそろう）、`emission`（`{"color", "energy"}`：発光）。
- `light`：部屋の雰囲気（`mood`）ごとの光の上書き。`{"ruin_b1": {"ambient_color": "#b49a78", "ambient_energy": 0.55}}`。項目は `ambient_color`・`ambient_energy`・`sun_energy`・`sun_color`・`fog_color`・`sky_energy`・`saturation`（色の鮮やかさ）。
  `sky`：雰囲気ごとの遠景の空の絵（`{"day": "res://…jpg"}`、町のキット）。どちらも `EnvironmentSetup.apply_sky`（`main._apply_mood` から）。
- `tex_strength`（0〜1）：絵の模様の強さ（絵の平均の色は保つ）。黒鉛の擦り目のような強すぎる模様を弱める。絵は VRAM 圧縮・ミップマップありで取り込む（`.import` の `compress/mode=2`・`mipmaps/generate=true`。平均の色をミップマップから取る）。
- 光の筋の材質：`{"blend": "add", "color", "strength", "fade_m"}`（`kit_glow.gdshader`。足し合わせの半透明、上から `fade_m` m で消える）。
- 面の UV はワールドのメートル：床・天井は (x, z)、壁は (壁に沿った長さ, 高さ)。だから 2 m の格子の継ぎ目は、どの部屋でも格子の線にそろう。

### 14.3 飾り（`dress`）

```json
"dress": [
 {"part": "ruins/b1_pillar", "pos": [-12, 0, -12]},
 {"part": "ruins/b1_wall", "pos": [-11, 0, -13], "yaw": 0, "count": 11, "step": [2, 0, 0]},
 {"part": "ruins/b1_lantern", "pos": [-12.5, 2.4, 0], "yaw": 90, "light": {"at": [0, 0, 0.3], "color": "#ffbc52", "range": 6, "energy": 1.2}}
]
```

| 項目 | 内容 |
|------|------|
| `part` | `res://assets/kit/<part>.glb`。無い部品は描かずに飛ばし、名前を警告に出す（部屋の `missing_parts` にも残る。落ちない） |
| `pos` | 部品の原点を置く位置（部品ごとの原点は 14.4） |
| `yaw` | 向き（度）。部品の正面（通路側）は yaw 0 で +Z、90 で +X |
| `rot` | `[x, y, z]`（度）。`yaw` の代わりに 3 軸で回す（倒れた物、縦の管など） |
| `scale` | 数か `[x, y, z]` |
| `count`・`step` | 同じ部品を `count` 個、ワールドの `step` [dx,dy,dz] ずつずらして並べる（壁・手すり・梁の列） |
| `shadow` | 影を落とすか（既定はキットの `dress_shadows`） |
| `light` | 部品に明かりを付ける：`{"at": 部品の中の位置, "color", "range", "energy"}`。`"type": "spot"` なら `"dir"`（部品の中の向き）・`"angle"`（度）・`"shadow"`（影。部屋に 1 つまで）。明かりは重いので、部屋に数個まで |

- 同じ部品は 1 つの MultiMesh にまとめて描く（部品 1 種 × 材質の数だけの描画）。部品のメッシュと材質は 1 回だけ読む。毎フレームの処理は無い。
- 飾りには当たり判定が無い。歩ける所に置くのは、床の上の薄い物（格子・砂）や、壁から 0.5 m 以内の物だけにする。高い所の通路（`b1_walkway`）は跳んでも届かない高さに。

### 14.5 オルド背町のキット（`town`、W2-05）

絵：`origin/art/w2-town`（`town_kit_*`・`town_props*`・`town_facilities`・`town_mood_*`・`bg_desert_*`・`tex_town_*`）。寸法は `spec_town_3d.md`（2 m の格子）。
部品を作る：`.venv-blender/bin/python tools/blender/kit/town.py`（`--tex` 表面の絵、`--sky` 空の絵、`--review` 部品の一覧の画像、`--gallery` 確認ページ用の `tools/model_viewer/kit_town.glb`）。
部屋に置く：`python3 tools/dress_town.py [部屋]`（何度流しても同じ。形の位置・当たり判定・目印・出口・住人・置く物は変えない）。今は中段（`mid`）だけ。

- 部品の原点：底の中心、正面が +Z。壁に付く物（日よけ・看板の腕・窓 `window_frame`）は壁の面。段の正面（`terrace_a〜d`・`terrace_4`）は高さ 16 m の壁の面の下の中心、胸壁の手すり（`parapet_rail_8/4`）は高さ 1.2 m・厚さ 1 m の胸壁の上の面の中心。
  露店（`stall`）は屋根の箱の中心の真下（8×5.2 m、高さ 3.45 m の屋根の箱に合わせてある）。一覧と寸法は `godot/assets/kit/town/parts.json`、各部品の説明は `town_parts.py`・`town_sets.py` の冒頭。
- 材質：平らな色は頂点の色にして `flat` 1 つ、黒鉛と真鍮は `metal`、灯の芯は `amber`（キットの `flat`・`metal` は `tint_mix: 1`）。部品 1 つの描画は多くて 3 回。
- 遠景：`ordo_far`（オルドの背の外殻・持ち上がった頭と尾・4 対の脚。原点 = 町の背の面。中段では y = -6.5、影なし）と、空の絵（`sky`：`bg_desert_*` を正距円筒にした `sky_day/night/dusk.jpg`）。
- 影：キットの既定は影なし。近くで形を読ませる物（露店・天幕・記念の柱・建物の正面・外灯・ベンチ・箱）だけ `"shadow": true`（`dress_town.py` の `SHADOW`）。
- 看板の板：看板（`sign`）に `"board": "town/sign_post_2"`・`"yaw": 180`・`"board_w": 2.2` を足すと、浮いた文字の代わりに板（キットの部品）を置き、文字を板の表に貼る（ビルボードにしない。文字は板の幅に収まるよう小さくなり、光の影響を受けないので夜も読める）。
  `pos` は文字の中心（板の部品の原点はその 0.62 m 上の棒）。板：`sign_wall_2/3`（棒から壁へ腕。壁の面は板の 0.5 m 奥）、`sign_post_2/3`（棒から下へ 1.75 m の柱。露店の梁の上）、`sign_roof_2`（1.65 m。屋根の上）。
