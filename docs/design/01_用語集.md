# 用語集・固有名詞一覧

『ワンダリング・アーク』（開発中タイトル）で使う固有名詞の**唯一の正本**。
名前を変えるときは、まずこの表を更新してから各文書に反映する。

- 状態：**確定**＝ユーザー承認済み／**案**＝Claude の提案で未承認
- 命名ルール：実在の著名人・有名作品のキャラクターと同じ名前、または強く連想させる名前は使わない。確定前に Web 検索し、販売前には商標検索（J-PlatPat 等）を行う。
