> 2. 真相：アルデンの計画を「今の人類を犠牲にして同胞を救う」から、「**今を生きる人々も含めて、全員をアーカイブへ移す**（同意なしの善意の避難）」に変えた。

## 1. テーマ

**「置いていかれた者たちが、誰も置いていかない道を選ぶ物語」**

登場人物の多くが「置いていかれた」経験を持っている。

| 人物 | 何に置いていかれたか |
|------|---------------------|
| ハル | 10年前に父が町を去った |
| 今の人類 | 千年前、先史人がアーカイブに去った |
| アルデン | 同胞はみな眠りにつき、たった一人で目覚めてしまった |
| ナゴミ | 設計者に託されたまま、千年間ひとりで眠っていた |
| ボルタ | 祖父が病に倒れ、町を一人で支えている |

物語の答えである「第三の道」は、**誰も置いていかない**という選択そのものである。
タイトル『アークウォーカー（歩く方舟）』は、「誰も置いていかない方舟」として歩き続ける巡礼機を指す。相棒 AI の名「ナゴミ（和）」は、イレーネ（ギリシャ語で「平和」）が自分の名の意味を託したもので、第8章でそのつながりが明かされる。

### 繰り返し現れる言葉
**「回収屋は、持ち帰るまでが仕事だ」**（父コウの口ぐせ）

| 場面 | 誰が | 意味 |
|------|------|------|
| 第1章 | ヤーナが言う | 父から受け継いだ、職業の心得として |
| 第7章 | ハルが父に言う | 「あんたを持ち帰る」。父を救い出す決意 |
| 第8章 | ハルが言う | 「みんなを持ち帰る」。第三の道の選択 |

## 2. 裏設定の年表

プレイヤーが段階的に知っていく「真実の時系列」。

| 時期 | 出来事 |
|------|--------|
| 約千年前 | 白潮が迫る。先史人の多数派はアーカイブ計画を選び、意識をデータ化して地下深くのアーカイブで眠りにつく（**大沈黙**） |
| 同時期 | データ化を拒んだ人、選ばれなかった人のために、技術者イレーネたちが**巡礼機**を造る。白潮の際、巡礼機はターミナスに集まって盾となり、残された人々を守り抜いた。その子孫が今の人類である |
| 同時期 | イレーネは夫アルデンと別れ、残される側に加わる。彼女は、次の白潮で巡礼機を束ねる守護 AI **ナゴミ**を、自分の人柄と声をもとに作り、外装フレームに宿らせた。ナゴミは、**ノードに残された記憶（その場所で起きたことの記録）を取り込んで育つ**ように作られている。「盾を張ったあと、巡礼機をアーカイブの人々の新しい器にする」計画（**第三の道**）は、各地のノードに分けて記録した |
| 最初の白潮のあと | 最初の白潮は、巡礼機と技術者たちの手で越えた。ナゴミは次の白潮に備え、**一度も起動しないまま**深層のノードで眠りにつく。第三の道は「**今を生きる人間（登録者）が、先史人を受け入れると選んだときにだけ実行される**」設計だったため、実行されないまま忘れられた |
| 千年のあいだ | 巡礼機は巡礼路を歩き、各地の**ノード**でエネルギーを集め、その一部をアーカイブへ送り続けた。しかしノードは少しずつ壊れていき、アーカイブの動力は細っていった |
| 約30年前 | アーカイブの動力が危険域に達し、管理人**アルデン**が目覚める。同胞の意識が崩れ始めていること、次の白潮が千年前より強いこと、老朽化した巡礼機とノードでは盾がもたないかもしれないことを知る |
| 約15年前 | 伝説の回収屋**コウ**（ハルの父）がアルデンと出会う。「先史の技術で、今の暮らしを豊かにできる」という言葉を信じ、共に**黎明機構**を立ち上げる。相棒のヤーナも手伝う |
| 約11年前 | コウは深層のノードで、休眠中のフレーム〈ヴェスティージ〉を見つけ、登録者になる（ナゴミは眠ったまま目覚めない）。そのノードの記憶から、アルデンの計画が「今を生きる人々も、本人たちが望まなくても、全員をアーカイブへ移す（地上の暮らしを終わらせる）」ものだと知る。同時に、ノードを直せば盾はまだ張れることも知る |
| 約10年前 | コウはヴェスティージを持ち出して黎明機構を離反する。故郷オルドの体内の最深部にフレームを封印し、**血縁しか開けられない生体錠**をかける。ヤーナに手紙を託して町を去る。息子を巻き込まないため、二度と帰らないと決めていた |
| 10年間 | コウは一人で各地を巡る。黎明機構の妨害と、「第三の道」を開く方法の手がかり探し。訪れたノードに、いつか目覚めるナゴミと息子への言葉を記録して残していく |
| 約1年前 | 太陽の異変を感知し、全巡礼機がターミナスへ進路を変える。同じ頃、コウは鏡の塩原でハイナルに捕まり、暁の城塞に幽閉される。アルデンはコウから登録者の情報を抜き出そうとしている |
| 数か月前〜 | 黎明機構が巡礼路のノードに**楔**を打ち込み、エネルギーをアーカイブ側へ流す「転送網」に作り変え始める。楔を打たれたノードでは巡礼機が補給できず、止まった町はアーカイブへ移るしかなくなる |
| **物語開始** | オルドは直前の二つのノードで補給できず、エネルギーが尽きかけている |

### アルデンの計画（整理）
1. アルデンは「次の白潮は、老朽化した巡礼機の盾では防げない」と考えている。**眠りの中（アーカイブ）でしか、誰も守れない**。
2. だから、今を生きる人々もアーカイブへ移す（意識をデータにして眠らせる）。本人たちの同意は求めない。**善意による、全員の強制的な避難**である。
3. 楔でノードを作り変え、エネルギーをアーカイブへ集める転送網を作る。補給できずに止まった巡礼機の町は、移るしかなくなる。
4. 白潮の直前、ターミナスに集まった巡礼機のエネルギーと人々を、まとめてアーカイブへ移す。これには、巡礼機を統べる守護者（ナゴミ）とその登録者の権限が必要になる。
   - アルデンはコウを捕らえ、登録者の情報を時間をかけて複製しようとしている。
   - ナゴミそのものはコウが隠したため、行方を探している。

→ **ハルが各章でノードを再起動する行為は、アルデンの転送網を一本ずつ断ち切り、盾を張る力を取り戻すことでもある。** さらに、再起動したノードの記憶をナゴミが取り込むことで、真相が少しずつ明らかになる。これが、黎明機構がハルを敵視していく理由になる。

## 3. 主人公の動機の段階設計

### 3.1 全体の流れ

| 段階 | 章 | ハルの目的 | プレイヤーへの見せ方 |
|------|----|-----------|---------------------|
| 日常 | 序盤 | 一人前の回収屋として認められる。工房へのツケを返す | 持ち場を放り出して叱られ、ヤーナに借金を取り立てられる |
| 使命 | 第1章 | 止まった町を救う | 町の電力と水が止まる。大人は不在 |
| 旅 | 第2〜3章 | 町を先へ進ませる。父の足跡をたどる | ノードで補給しないと、町がまた止まる |
| **転換** | **第3章の終わり** | **生きている父を見つけ出す** | 父の生体リンク信号の受信（下記 3.2） |
| 深化 | 第4〜6章 | 父を取り戻す。父が何をしようとしたのかを知る | ヤーナの告白、黎明機構の襲撃、アルデンの取引 |
| 決着 | 第7〜8章 | 父を救い、アルデンを止め、みんなを救う | 救出、登録者の継承、第三の道 |

### 3.2 父を追う動機を強める仕掛け

父への想いを「背景の感情」から「物語を引っ張る最大の目的」に押し上げるため、次の4つの原則で設計する。

1. **一度に明かさず、段を踏んで強くする。** 章ごとに「具体的な発見 → 感情の揺れ → 次の問い」を一つずつ積む。
2. **遊びの行為と動機をつなげる。** ノードを起動するたびに父の信号の位置が絞り込まれていく。遊ぶこと自体が父に近づくことになる。
3. **動機を画面に見せる。** ワールドマップに「父の信号」の範囲円を表示し、ノードを起動するたびに小さくする。
4. **父のイメージを一度揺さぶってから確かめる。** 「父は敵の創設者だった」という疑いを経て、真意を知る。ただ会いたいだけでなく、真実を確かめたいという動機が加わる。

#### 段階表

| 章 | 発見 | ハルの感情 | 次の問い |
|----|------|-----------|---------|
| 1 | フレームの生体錠がハルに反応する。ナゴミ「登録者の血縁と推定。**仮登録**します」 | 戸惑い | 登録者って誰だ？ |
| 2 | 再起動したノードの記憶をナゴミが取り込むと、その中に父が残した声があった。「目覚めたら、**息子を頼む**」。ノードの壁に父の印も見つかる | 父はこれを自分に遺した。なのに、なぜ直接来なかった | 父は何をしていた？ |
| 3（前半） | 塩原の野営跡で父のログを拾う。約1年前の記録：「千の目に見つかった。ここまでだ。ナゴミのことは絶対に渡さない」 | 父は1年前まで生きていた。そして何かに追われていた | 父はそのあとどうなった？ |
| **3（結末）** | **鏡塔を起動すると、ナゴミが父の生体リンク信号を受信する。「登録者コウは、生存しています」** | 衝撃、怒り（10年も何を）、そして決意 | **どこにいる？ → 信号の範囲円がマップに現れる** |
| 3（町） | ハルが報告すると、ヤーナは工具を落とし、何も言わずに立ち去る | 違和感 | ヤーナは何を知っている？ |
| 4 | ヤーナが10年預かっていた父の手紙を渡す。「アルデンという男と、俺は黎明を作った。間違いだった。俺を探すな。オルドを終着点へ連れていけ」。さらに幹部ハイナルが「あの男を捕まえたのは私だ」と言い放つ | 父は敵の創設者だった？ 「探すな」と言われて探さない息子がいるか | 父は本当は何者なのか |
| 5 | 黎明機構がオルドを襲撃する。狙いはナゴミ。幹部ダグ「コウは裏切り者だ。だが最後まで口を割らなかった。大した男だ」 | 父は裏切ったのではなく、止めようとしたのだと気づく | 父は今どこで、何をされている？ |
| 6 | アルデンと対面する。「ナゴミを渡せば、コウを返そう」。ハルは拒む。信号の範囲円が暁の城塞を指す | 父の命と世界を天秤にかけられる怒り | 城塞へ行く |
| 7 | 城塞の最上部で父を見つける。登録者の情報を抜き取られて衰弱している。ハル「回収屋は持ち帰るまでが仕事なんだろ。——**あんたを持ち帰る**」 | 再会 | アルデンはすでにターミナスへ |
| 8 | 父が登録者の権限をハルに引き継ぐ。「今日からお前が登録者だ。……一人前だな、ハル」 | 継承 | —— |

> 第8章の「一人前」は、物語開始時の目的（一人前の回収屋として認められる）への答えになっている。第1章の「仮登録」と、ハルの「見習い」も対応させている。

#### 転換点の場面（第3章・鏡塔の頂上）
1. 大番機「鏡守」を倒し、鏡の角度を整えて通信塔を起動する。塩原一面が光を反射して輝く（見せ場の演出）。
2. ナゴミ「ノード網との同期範囲が広がりました。……受信しています。これは——」
3. ナゴミ「登録者の生体リンク信号です」
4. ハル「登録者って……親父のことだろ。信号って、どういう意味だよ」
5. ナゴミ「生体リンクは、登録者が生きている間だけ発信されます。つまり——」
6. ハル「……生きてる？」
7. ナゴミ「はい。登録者コウは、生存しています」
8. 長い沈黙。この章の前半で拾った「1年前のログ」の声が重なって流れる。
9. ハル「……10年だぞ。10年も、何やってたんだよ」（怒り）→「……待ってろよ、親父。絶対、見つけてやる」（決意）
10. ナゴミ「信号の方角を記録しました。ノードをさらに起動すれば、位置を絞り込めます」
11. ワールドマップに大きな範囲円が現れる（ここから毎章、円が小さくなる）。

## 4. 章ごとのシナリオ

各章は「オルドが新しい地域のノードに停泊 → 町の準備 → 地上へ → ノード遺跡 → ボス → ノード再起動 → オルドが次へ」という基本の流れに沿う。
プレイ時間はメインルートの目安。

### プロローグ＋第1章「止まった町」（約1.5時間）
**舞台**：オルド背町、背中の遺構

1. **オープニング**：夜明け、砂の大地を歩く巨大な巡礼機オルドの遠景。背中に町の灯り。
2. **見習いの仕事（チュートリアル）**：ギルドの訓練場で、見習い回収屋ハルが、動かなくなった番機の残骸の片付けを任される。移動・ジャンプ・射撃を学ぶ（この時点ではロックオンがない、古い練習銃）。
3. 仕事の途中、子どものニコが肝試しで立入禁止の遺構入口に入り込む。ハルは持ち場を放り出して追いかけ、小型の番機からニコを助ける（初戦闘）。
4. 持ち場を離れたことをギルド支部長バートンに叱られ（見習いの期間が延びる）、ヤーナに修理代のツケを取り立てられる（ハルの日常と目的の提示）。
5. **その夜、オルドが止まる**。地響き、町の灯りが消える。町長トルーデ「このままでは水も電気も三日ともたない」。大人の回収屋たちは地上へ遠征中で戻らない。
6. 動力の中継器は体内の奥、立入禁止の遺構にある。ヤーナは止めるが、ハルの決意を見て折れる。**10年しまっていた父の愛銃「スパーク」を渡し、「回収屋は、持ち帰るまでが仕事だよ。あんたの親父の口ぐせさ」**。
7. 夜の町（自由行動）：住人と話す、雑貨屋で補修パックを買う、家でセーブする。
8. **背中の遺構・外殻層**：ハルが遊び場にしていた浅い層。移動と戦闘の復習。
9. **配管層**：床が崩れて深い縦穴に落ちる。番機に追い詰められたとき、壁の奥の封印室が**ハルに反応して開く**。
10. **フレームとの適合（見せ場）**：外装フレームがハルの体に組み上がっていく。光の球体が目を開ける。ナゴミ「起動シーケンス完了。……登録者の生体情報と一致しません。血縁と推定。**仮登録**します。はじめまして、ハル」
11. チュートリアル：ロックオン、ダッシュ、光刃。ナゴミとの最初の掛け合い。ナゴミは起動したばかりで、この世界のことを何も知らない（「巡礼機……とは何ですか？」）。
12. **駆動層**：オルドの脚の駆動機構。ナゴミが眠っていた装置に動力を流して足場を動かす仕掛け。浮遊型の番機が登場する。
13. **心臓部前室**：ナゴミの診断「オルドの動力が枯渇しています。直前の二つのノードで補給できなかった形跡があります」（ノードの概念の提示）。
14. **ボス：大番機「閂」**（心臓部の門番）。
15. 心臓部：ナゴミがフレームの予備動力をオルドに流す。オルドが咆哮して再び歩き出す。町に灯りが戻り、歓声が上がる。ナゴミが初めてノードの記憶を取り込む（取り込みの仕組みの提示）。ナゴミ「オルドの記憶を取り込みました。目的地を確認。……ターミナス。1年前から、すべての巡礼機が同じ場所を目指しています」。ハル「ターミナス……親父が最後に『行く』って言ってた場所だ」（父への想いの最初の種）
16. ナゴミ「補給しなければ、オルドはまた止まります。次のノードまでは持ちます」→ **第2章の目的を提示**。
17. **翌朝**：ギルドが功績を認め、ハルは「降下許可」を得る（見習いのまま、地上に降りてよいという許し）。ヤーナが閂のコアから最初の特殊武器を開発する（開発の流れを学ぶ）。
18. **章末の引き**：
    - 地平線の彼方に、もう一つの巡礼機（カラン）の影が見える。
    - 黎明機構の飛行艇の中。ダグ「オルドから反応だと？」ハイナル「間違いない。……ヴェスティージが目覚めた」

**報酬**：特殊武器「ブレイクドリル」（閂のコア）、ライフコア 1、チューニングチップ 1
**再訪要素**：ブレイクドリルで駆動層のひび割れた壁を壊すと、隠し部屋に入れる

### 第2章「錆の砂海」（約2時間）
**舞台**：赤錆の砂丘に沈んだ都市と、半分埋もれたノード

- オルドが砂海のノードに停泊する。ハルは初めて昇降リフトで地上に降りる。
- **ボルタ初登場**：ノードの前で「早い者勝ち！」。彼女の巡礼機カランもエネルギー不足で、同じノードを狙っている。ノードの仕掛けを先に解いた方が補給できる**先取り競争**になる（ボルタは自作の道具で仕掛けに挑む。競争の区間）。負けたボルタは「覚えてなさいよ！」と撤退する。
- ノードには黎明機構の**楔**が打ち込まれていて、補給できない。黎明機構の存在が初めて明確になる。
- ノードの壁に父の印（コウの回収屋の刻印）と、9年前のログ「ここにも楔か。……あいつ、本気で全部持っていく気だ」。
- **ボス：鉄腕のダグ**。正々堂々を好む武人。「名乗れ、小僧。拳を交える相手の名は覚えておく主義だ」。敗れても「今日は退く。次は本気だ」と去る。
- ノードを再起動すると、ナゴミがノードの記憶を取り込む。その中に、**父が残した声「ナゴミ、目覚めたら息子を頼む」**がある。
- オルドとカランがそろって補給する。ボルタは「コンサル料」の請求書をハルに押しつけて去る（彼女らしさの提示）。

**報酬**：特殊武器「アイアンナックル」、アーマー（踏破シリーズ・頭）
**遊びの追加**：地上フィールドの本格的な探索、賞金首番機、回収屋ギルドの依頼

### 第3章「鏡の塩原」（約2時間）
**舞台**：どこまでも白い塩の平原と、巨大な鏡が林立する通信塔ノード

- 光を反射させる謎解きが中心の章。
- ボルタは黎明機構に雇われていて（「カランに優先してエネルギーを回す」と言われた）、ハルの邪魔をする。黎明機構から貸し与えられた番機を操って立ちはだかる（中ボス戦は借り物の番機）。
- 塩原の野営跡で**父のログ（約1年前）**を拾う：「千の目に見つかった。ここまでだ。ナゴミのことは絶対に渡さない」。
- **ボス：大番機「鏡守」**。
- **転換点**：鏡塔の起動 → 父の生体リンク信号の受信（3.2 の場面）。
- 町に戻り、父が生きていたことをヤーナに伝える。ヤーナは工具を落とし、黙って立ち去る。
- ギルドから「銅の印」を受ける（一人前への一歩）。

**報酬**：特殊武器「プリズムレーザー」、アーマー（踏破シリーズ・脚＝エアダッシュ）

### 第4章「呑まれた塔」（約2時間）
**舞台**：樹海に呑まれた、雲を突く巨大塔

- **移動中の夜、ヤーナの告白**：10年預かっていた父の手紙をハルに渡す。
  - 手紙：「アルデンという男と、俺は黎明を作った。間違いだった。ハル、俺を探すな。オルドを終着点へ連れていけ。答えはナゴミが知っている」
  - ヤーナ「あの人は間違えた。でも、間違いを正すために全部捨てた人だよ」
  - ハル「……探すなって書かれて、探さない息子がいるかよ」
- 塔の中で、ボルタは黎明機構に騙されていたと知る。カランにはエネルギーが回されていなかった。
- 幹部ハイナルは、用済みになったボルタを罠ごと始末しようとする。ハルが助け、**共闘パート**になる（ボルタの道具で足場を作ってもらう、仕掛けを解くボルタを守る区間など）。
- ボルタの事情が明かされる。カランの技師長である祖父が病に倒れ、町と祖父の薬のために必死だった（彼女の「お金好き」の理由）。
- **ボス：千眼のハイナル**。「あの男を捕まえたのは私だ。父親と同じ目をしている」。
- 樹上の記録庫で、ナゴミが記録庫の記憶を取り込む：光の中へ消えていく先史人たちの映像（大沈黙の真相の入口）。

**報酬**：特殊武器「ホーミングドローン」、アーマー（踏破シリーズ・腕）

### 第5章「凍結プラント」（約2時間）— 物語の中間点
**舞台**：氷に閉ざされた先史の観測施設

- 観測施設の記録から**世界の真相**を知る（白潮の周期、大沈黙＝アーカイブへの避難、巡礼機＝残された人々の避難船、盾）。
- ハルがノードで戦っている間、**黎明機構がオルドを襲撃する**。狙いはナゴミ（ハルの不在を狙った陽動）。
- 急いで町に戻ると戦闘になっている。ヤーナは子どもたちをかばって負傷する。
- 襲撃を率いるダグは、住人が傷つくのを見て部下を止める。「コウは裏切り者だ。だが最後まで口を割らなかった。大した男だ」→ **父は生きていて、捕らわれている**ことが確定する。
- ボルタとカランの防衛隊が駆けつけ、襲撃を退ける（彼女の見せ場）。
- **ボス：大番機「雷殻」**（観測施設の発電核）。
- 町の一部が壊れる → **町の復興**要素が始まる（施設の再建に資材を投じる）。
- ギルドから「銀の印」を受ける。

**報酬**：特殊武器「サンダーウィップ」、アーマー（踏破シリーズ・胴）、強襲シリーズの手がかり

### 第6章「浮遊岩礁」（約2時間）
**舞台**：重力の乱れで巨岩が空に浮かぶ岩礁地帯

- 重力を切り替えて進む仕掛けの章。
- 幹部モルゲンとボルタの「コメディ対決」が繰り返される（サブイベント）。
- **ボス：道化のモルゲン**。幻影と罠。敗れると、あっさり寝返りを持ちかける。「城塞の地図、お安くしときますよ？」
- ノードを起動すると、**アルデン本人が姿を現す**。
  - 正体（先史人、アーカイブの管理人）と動機を語る。「千年待たせた者たちがいる。私は、その約束を破れない。……白潮は来る。老いた巡礼機の盾はもたない。眠りの中でしか、誰も守れないのだ」
  - 取引を持ちかける。「ナゴミを渡せば、コウを返そう」
  - ハルは拒む。ナゴミ「私は、ハルといたいです」（ナゴミの成長）
  - ナゴミの声を聞いたアルデンが動揺する。「その声は……」（イレーネの伏線）
- 信号の範囲円が**暁の城塞**を指す。

**報酬**：特殊武器「ミラージュデコイ」「グラビティウェル」（中ボスの番機から）、アーマー（強襲シリーズ・脚＝二段ジャンプ）、隠しアーマー（強襲シリーズ・胴）

### 第7章「暁の城塞」（約2.5時間）
**舞台**：巨大ノードの上に築かれた黎明機構の本拠

- モルゲンから買った地図で潜入する。ボルタが自作の仕掛けで陽動役を務める（「城塞の半分、煙で包んでやったわよ！」）。
- ハイナルは真相（盾を捨てれば地上の人類が滅ぶ）を知って揺れる。最終的に、父の独房の鍵を密かに開ける（捕らえた者が解放する側に回る）。
- ダグは寝返り、城塞内の非戦闘員を逃がすために門を守る。
- **ボス：氷刃のオロール**。総帥に心酔する剣士との剣戟戦。彼女だけは最初から真相を知っていて、それでもアルデンに従っている。
- **父の救出**：最上部で、機械につながれて衰弱した父を見つける。
  - ハル「回収屋は持ち帰るまでが仕事なんだろ。——あんたを持ち帰る」
  - コウ「……でかくなったな」
- アルデンは、1年かけてコウから抜き出した登録者の情報の複製を完成させ、すでにターミナスへ向かっていた。ナゴミがなくても、不完全で危うい方法で転送を強行できる段階に達している（第6章でナゴミを求めたのは、確実に実行するため）。空が白み始める（白潮の前兆）。

**報酬**：アーマー（強襲シリーズ・腕／頭）、剣技

### 第8章「終着点ターミナス」（約2.5時間）
**舞台**：すべての巡礼機が集まる大地の果て

- 数十体の巡礼機がターミナスを取り囲む壮大な光景。オルドとカランが並んで歩く。
- ボルタとカランの防衛隊、寝返った幹部たちが黎明機構の軍勢を食い止め、ハルと父を中枢へ送り出す。
- **登録者の継承**：父が登録者の権限をハルに引き継ぐ。「今日からお前が登録者だ。……一人前だな、ハル」
- ターミナスの中枢のノードの記憶を取り込み、ナゴミは**自分がイレーネをもとに作られていた**ことを知る。名前の「和」は、イレーネ（「平和」）が自分の名の意味を託したものだった。そして第三の道の全容が明らかになる。
- **ボス：総帥アルデン**（多段階）。オロールが最後までアルデンの隣に立つ。
- 戦いのあと、ナゴミがイレーネの遺した言葉を再生する。「アルデン、あなたが目覚めたなら……誰も置いていかないで」。アルデンが膝をつく。
- **第三の道の実行**：イレーネの設計では、実行には「今を生きる人間の同意」が要る。**登録者となったハルが、先史人を受け入れる（誰も置いていかない）ことを選ぶ。**「みんなを持ち帰る」。盾を張り、白潮を越えたあと、巡礼機をアーカイブの人々の器にする（先史人は巡礼機の中で目覚め、今を生きる人々と一緒に地上を歩く）。ただし、それを制御するには、誰かがターミナスの中枢に残る必要がある。
  - ナゴミが残ろうとするが、アルデンが代わりに中枢に入る。「千年、待たせすぎた。今度は私が待つ番だ」（アルデンの償い）
  - ナゴミ「ハル。冗談を一つ、覚えました。……いえ、いまは言わないでおきます」
- 白潮が空を焼く。盾の下で、すべての巡礼機と人々が夜明けを迎える。

### エピローグ
- 数か月後。青空の下を歩くオルド。先史人たちが少しずつ巡礼機の中で目覚め始めている（アルデンの娘の姿も）。
- ギルドがハルに「一人前の印」を渡す。ヤーナ「ツケは消えないからね」。
- 中枢のアルデンから、先史人の目覚めが順調だという便りが届く。ハルの肩の上でナゴミが言う。「冗談を学習しました。……いまのは面白かったですか？」
- ボルタが現れる。「決着、まだついてないんだからね！」→ **クリア後コンテンツへ**
- **次回作への引き（最後の場面）**：展望台で、ナゴミが遠くの信号を取り込む。「ハル。盾を張ったとき、海の向こうでも、もう一つの盾が灯りました。……とても弱い光でした」。コウ「俺が歩けたのは、この大陸の巡礼路だけだ」。ハルは地平線を見て言う。「行こう。まだ、持ち帰ってないものがある」。オルドが歩き続ける遠景で終わる。

### 次回作につなげるための方針
- **この作品の物語は、この作品の中で閉じる**（父の救出、アルデンの計画、第三の道、白潮はすべて決着する）。次回作は、閉じた物語の「外側」に広がる形で引く。途中で話を切って終わる形（いわゆる投げっぱなし）にはしない。『ロックマンDASH2』の終わり方（主人公が月に取り残される）とも重ねない。
- 引きの本筋：**海の向こうにも巡礼機とターミナスがあった**。向こうの盾は弱く、誰かが助けを必要としている。回収屋としての次の仕事（「持ち帰る」）につながる。
- 種として、本編の中に少しずつ置いておくもの（本編の筋には影響しない）：
  - ノードの記憶に、ときどき「海を渡ってきた巡礼機」の記録が混じる（第4・5章の記録庫で 1 つずつ）。
  - イレーネの最後の記録に、ターミナスの外への言及がある（「向こう岸の人たちにも、同じ道を」）。
  - コウの10年の旅のログに、「渡れなかった海」の話がある（収集要素の父のログの 1 つ）。
- **シリーズの広げ方（案）**：世界には海で隔てられた陸地がいくつもあり、それぞれに巡礼路・巡礼機の群れ・ターミナスがある。**1 作につき 1 つの陸地**を舞台にし、陸地の数だけ物語を増やせる。陸地ごとに、巡礼機の姿、白潮への備え方、先史人との関係（アーカイブの有無など）を変えて、同じ型の繰り返しに見えないようにする。
  - **世界の全容は謎のままにする**：大陸がいくつあり、どこにあるのかは、この作品でも次回作でも全部は明かさない。わかるのは、ノードの記憶から拾える断片だけ（「海を渡ってきた巡礼機」の記録、遠くの盾の光、父のログの「渡れなかった海」など）。断片どうしが少し食い違っていてもよい（記録した時代や場所が違うため）。
  - 設定を作る側でも、大陸の一覧や世界地図は決めない。次回作を作るときに、その作品の舞台になる大陸だけを決める。
  - 注意：『ロックマンDASH』シリーズは「島」を舞台にし、2 作目は島々を巡る構成だった。こちらは「小さな島を渡り歩く」形ではなく、「**大きな陸地ごとに、歩く町で旅をする**」形にして重ならないようにする。
- 次回作に持ち越せるもの：ナゴミ（ノードの記憶を取り込む能力はそのまま使える）、一人前になったハル、ボルタとの決着、オルドとカラン。

### クリア後
- **深層アーカイブ**：アーカイブの防衛機構が暴走した、何十層もの深層ダンジョン。裏ボスは大番機「静寂」。
- ボルタとの最後の競争：全地域のノードを巡る先取り競争（おまけ）。
- 賞金首の最上位ランク、「白磁の印」、エキスパート難易度。

## 6. 章の合間（オルドの移動中）

巡礼機が次の地域へ歩く数日間は、町でのんびり過ごす時間として描く。

- 住人との会話が章ごとに変わる（新しい地域から来た行商人など）。
- 町の発展（施設の追加や再建）の結果がここで見える。
- サブイベントの多くがこの時間に起きる。
- 物語上の大事な会話（第4章冒頭のヤーナの告白など）もここに置く。
