## 1. どんな人物か

| 項目 | 内容 |
|------|------|
| 名前 | コウ |
| 年齢・身長 | 45 歳の男性・180cm |
| 立場 | 伝説の回収屋。10 年前に息子を残して姿を消した |
| 性格 | 飄々として大らか。だが決めたことは曲げない。責任を一人で抱え込む |
| 口ぐせ | 「回収屋は、持ち帰るまでが仕事だ」 |
| 物語 | 敵組織に捕らわれている。終盤、主人公に救い出される |

**見た目のキーワード**：大きな背中、旅慣れた風格、無骨な優しさ、主人公の「未来の姿」を少し感じさせる

---

## 2. デザインの条件

- 長身。風雨にさらされた**ロングコート**、首元のスカーフ、無精ひげ。
- **ハルと同じデザインのゴーグル**を着けている（ハルのゴーグルは父の予備という設定。W1-01 のハルの納品物に合わせること）。
- ハルと親子だと分かる顔立ちの共通点（目元など）。
- 2 つの姿を描く。
  - **通常**：10 年前の、旅をしていた頃の姿（回想や記録映像で登場）。
  - **幽閉後**：1 年間捕らわれて痩せこけた姿。髪が伸び、服は傷んでいる。機械につながれていた跡（首や腕の接続具の痕）。
