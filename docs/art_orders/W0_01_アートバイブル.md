# 発注書 W0-01：アートバイブル（画風の方向性 3 案）

> Codex（作画担当）へ。`00_共通ルール.md` と併せて読むこと。
> 納品先：`art/concepts/W0_art_bible/`

---

## 目的

ゲーム全体の見た目の方向性を決める。**方向性の違う 3 案**を描いてほしい。ユーザーが 1 案を選び、以後のすべての発注はその画風で描く。

この段階では、キャラクターのデザインはまだ確定していない。あくまで「画風の見本」として描いてよい（W1 で本番のデザインを作る）。

---

## 世界と雰囲気

- 遠い未来。赤錆色の砂漠と、千年前に消えた先史文明の巨大な残骸。
- 山のような古代の歩行機械〈巡礼機〉が大地を歩き、その背中に人々の町がある。
- **明るいレトロフューチャーの冒険活劇**。わくわくする冒険が主で、終盤に少しシリアスな真相が来る。
- 3D アクションゲームとして、ロックオンして撃つ・光の剣で斬る戦闘と、遺跡の探索が中心。

### 全案に共通する条件
| 項目 | 条件 |
|------|------|
| 読みやすさ | 3D ゲームの画面で、キャラ・敵・調べられる物がひと目で分かること |
| 先史の技術の見た目 | 候補：**白磁のような滑らかな白い外装＋真鍮の継ぎ目＋琥珀色の光**。より良い案があれば提案してよい（ただし `00_共通ルール.md` の 5 章に反しないこと） |
| アクセントカラー | 候補：**琥珀色**（主人公のフレーム、相棒 AI、遺物の光で共通に使う「遺物の光」の色） |
| 主人公の色 | **青系を主な色にしない** |
| 3D での再現 | ローポリ〜ミドルポリ（主要キャラ 6,000〜10,000 三角形程度）で再現できること |

### 3 案の振り分け（目安）
3 案は、塗り方と頭身がはっきり違うものにしてほしい。以下は目安であり、より良い振り分けがあれば提案してよい。

| 案 | 塗り方の方向 | 頭身の目安 |
|----|-------------|-----------|
| A | テクスチャの手触りを残したレトロ調（初期 3D ゲームのような素朴さを、現代の解像度で） | 5 頭身前後 |
| B | アニメ塗りのセル調（輪郭線あり、影は 1〜2 段） | 5.5〜6 頭身 |
| C | 手描き風の柔らかい塗り（絵本やガッシュ画のような質感） | 6〜6.5 頭身 |

## 納品物（1 案につき以下の 4 点＋spec.md）

### 1. キービジュアル（`artbible_<案>_keyvisual.png`）
- 16:9、3840×2160px 推奨（最低 1920×1080px）。
- 内容：夜明けの赤錆色の砂漠を歩く巨大な巡礼機。その背中の町の縁に、主人公の少年（外装フレームを装着）と、肩のあたりに浮かぶ光る球体の相棒 AI が立ち、遠くを見ている。
- 世界の広さ、冒険の始まりのわくわく感を伝える。

### 2. キャラクターの並び図（`artbible_<案>_lineup.png`）
- 次の 6 人を**同じ縮尺・正面・全身**で横に並べる（画風の見本として）。

| 人物 | 要点 |
|------|------|
| ハル | 15 歳の少年、155cm。回収屋の作業着に、部分的な外装フレーム（頭はヘルメットではなくバイザー）。右手に小型のエネルギー銃、左腕に光の剣を出すガントレット |
| エコー | 直径 25cm の光る球体ドローン。花のつぼみのような分割された外殻 |
| ヤーナ | 38 歳の女性、172cm。工房主。がっしりした体格、右腕が機械の義手、作業エプロン |
| ボルタ | 17 歳の少女、150cm。自称天才の回収屋。ぶかぶかのツナギ、大きなスパナ、跳ねたくせ毛 |
| コウ | 45 歳の男性、180cm。伝説の回収屋。風雨にさらされたロングコート、主人公と同じゴーグル |
| アルデン | 外見 40 代の男性、185cm。先史人。白金色の短髪、幾何学文様の白と金の長衣、瞳にかすかな光の輪 |

### 3. 機械の見本（`artbible_<案>_machines.png`）
- 小型の敵〈番機〉1 体（人の腰ほどの高さ。遺跡を守る無人の自律機械）。
- 巡礼機のシルエット（全長 400m 級。背中に町が乗っている。脚は 4〜8 本の範囲で自由）。**生き物ではなく機械**として描き、`00_共通ルール.md` 5 章の「町を背負って歩く巨大なもの」の作品に似せないこと。

### 4. 地域の色見本（`artbible_<案>_colorscript.png`）
次の 9 地域について、小さな雰囲気のサムネイル 1 枚と、代表色 5 色を並べる。

1. オルド背町（拠点の町）
2. 錆の砂海（赤錆の砂丘に沈んだ都市）
3. 鏡の塩原（真っ白な塩の平原と巨大な鏡の塔）
4. 呑まれた塔（樹海に呑まれた雲を突く塔）
5. 凍結プラント（氷に閉ざされた観測施設）
6. 浮遊岩礁（重力の乱れで岩が浮く空）
7. 暁の城塞（敵組織の本拠。夜明けの色）
8. 終着点ターミナス（巡礼機が集まる大地の果て）
9. 深層アーカイブ（地下深くの眠りの施設）

### 5. spec.md
`00_共通ルール.md` の 6 章の項目に加えて、次を書く。
- この案のキーワード（3〜5 語）
- 塗りと線のルール（輪郭線の有無と太さ、影の段数、ハイライトの入れ方）
- 3D で再現するときの想定（トゥーンシェーディング、輪郭線の描画、テクスチャの描き込み量など）
- 頭身と体型の決め方
- この案が「ゲームの手触り」に合う理由

## 判断の基準（ユーザーが選ぶときの観点）

1. 世界観（明るいレトロフューチャーの冒険）に合っているか
2. 3D アクションの画面で見やすいか
3. 既存の作品に似ていないか
4. 長く見ていて飽きないか、このゲームだけの個性があるか
