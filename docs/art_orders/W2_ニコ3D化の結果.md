# ニコを絵から 3D にした結果（nico.glb）

> 2026-10-18〜19。Codex の W2-01 の描き直し r2（`origin/art/w2-townsfolk` の `art/concepts/W2_townsfolk/` の `nico_*_r2.png`、`spec_nico_r2.md`、
> `spec_townsfolk_3d.md`・`spec_townsfolk_3d_add.md`）から、第 1 章でハルが遺構から助ける町の女の子ニコ（8 歳、120cm、NPC、持ち物なし）の 3D を作り、
> ゲームの 3 か所（訓練場・遺構 B1 の救出 `ch1.r01`・下段の家の前）の仮の形（茶色のカプセル）と置き換えた。
> 作り方は `.claude/skills/model-from-art/SKILL.md` のとおり「部品の表 → 体の土台 → 顔 → 決まりの塗り → 部品 → 骨」。
> 部品の表の下書きは `W2_人物の部品表.md` の 8 章。設定 `tools/blender/recon/chars/nico.json`、部品の表 `chars/nico_parts.py`、動作 `tools/blender/models/child_anims.py`。
> 作り直しは `.venv-blender/bin/python tools/blender/recon/build_char.py --char nico --from hull`（views・calib は済み。views を動かすと calib が上書きされる）。
> 確認ページ：https://hassy0511.github.io/project-relic/models/?m=nico

## 1. 部品の表（作ったもの）

骨付けの段で 1.20m へ 0.774 倍。斜めの絵の角度は較正で右前 48.3 度・左前 −50.0 度（足幅の比 0.665・0.643）。どちらも外形の一致が 0.8 未満なので、縁の寄せ（`snap.REAL`）は正面・右真横だけ。

`face.ATLAS_SCALE` を 3.2 にした（新しい定数。既定は 4 のまま）。

## 2. 動作（`tools/blender/models/child_anims.py`、`ai_character.py --clips child`）

ハルの 14 動作（銃を構えた待機・斬りなど）は子どもの住人に合わないので、ニコだけ別の 4 動作を焼く（`chars/nico.json` の `rig_args` に
`--clips child`。既定は `standard` のままで、ハル・ヤーナ・バートンは変わらない）。60fps、つなぎは SINE の EASE_IN_OUT、足の裏は床に着ける
（`ground=True`。足の接地点はニコの靴の寸法 `--foot-contacts=-0.14,0.11,-0.085`。既定はハルの値のまま）。

| 動作 | 長さ | 中身 | ゲームで使う所 |
|------|------|------|---------------|
| idle | 3 秒の輪 | 重心を左右へ移し、胸が息で動き、頭が少し傾く。腕は力を抜いて下ろし、体に遅れて揺れる | 訓練場・下段・救出のあと |
| walk | 1 秒（1 歩 0.5 秒） | 胸と腰の逆のひねり、腕は脚と逆、腰の上下 1.4cm | 使っていない（確認ページで見られる） |
| run | 0.53 秒（1 歩 0.27 秒） | 前傾 13 度、肘を曲げて大きく振る、浮いた足は床合わせから外す | 訓練場の「禁足扉へ走っていく」（`ch1.nico_run`）で、会話のあと 1.3 秒走ってから消える |
| cower | 1.2 秒の輪 | しゃがんで体を丸め、両手を顔の前へ、肩をすくめ、4 こまごとに左右へ小さく震える | 遺構 B1（`ch1.r01`）：救われるまで。子番機を倒すと立ち上がって話す |

## 3. ゲームへの組み込み（`godot/scripts/view/props_view.gd`）

- `NPC_MODELS` に `npc_nico` → `res://assets/models/nico.glb`。ニコの出る 3 か所（`ch1_town.json` の訓練場 (6, 0, 38)、下段 (14, 0, 3.2)、遺構 B1 (6, 0, 9)）は、
  どれも同じ `npc_nico` なので、カプセルの代わりにこのモデルが立つ。**当たり判定・きっかけ・会話・イベントは変えていない**（sim のファイルは触っていない）。
- 表情：`NICO_FACES`（通常 0・笑顔 1・驚き 2・怒り 3。会話の `face` の smile・smirk・laugh → 1、surprised → 2、angry → 3、sad・serious・normal → 0）。
  表情を切り替える住人の表 `NPC_FACE_SETS`（ヤーナは今までの `NPC_FACES` のまま）。
- 動作の選び方 `_npc_anim_for`：遺構 B1 では、救われる（`ch1.nico_rescued`）まで cower。子番機が出て、全部倒されたら idle（救出の会話 `ch1.nico_saved` は立って話す）。ほかは idle。切り替えは 0.35 秒でつなぐ。
- 走り去り：イベントの `remove`（`ch1.nico_run` だけがニコを消す）で `hide_npc` が呼ばれたとき、`NPC_RUN_OFF` の住人は run の動作でハルから離れる向きへ
  3.6 m/s で 1.3 秒走ってから見えなくなる（見た目だけ。sim の住人はその時点でもう無い）。
- 名札の高さ：`NPC_LABEL_Y`（ニコは 1.6m。既定 2.1m は大人の背丈）。
- 取り込み：`nico.glb.import` の `animation/fps=60`（動作が 60fps）。
- 確認の見本：`--nico_shots`（`godot/scripts/debug/demo.gd`）。訓練場で待つ・話す・走り去る、遺構 B1 でしゃがむ・会話・子番機・立って話す、下段の家の前、ビー玉を返す会話を撮り、
  動作の名前と表情の区画を 11 件確かめる。
