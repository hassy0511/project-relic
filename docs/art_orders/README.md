# Codex への作画発注書

本作（タイトルは差し替え予定）の絵を Codex に発注するための指示書一式。
Codex が描いた絵をもとに、Claude が 3D モデル・アニメーション・UI を作る。

---

## 発注の進め方

```
W0 アートバイブル（画風 3 案）
   ↓ ユーザーが 1 案を選ぶ（修正指示も可）
W1 主要キャラクター（MVP の開発と並行）
   ↓ ユーザーが確認 → Claude が 3D 化できるかを確認
W2 第1章の敵・ボス・巡礼機・背景・小物・UI・エフェクト（本気ステージの開始までに）
   ↓
W3 以降 第2章以降の地域・幹部など（量産の段階で、1 章先行して発注）
```

### 1 回の発注で Codex に渡すもの
1. `00_共通ルール.md`（毎回必ず）
2. その回の発注書（例：`W1_01_ハル.md`）
3. W1 以降は、選ばれたアートバイブル一式（`art/concepts/W0_art_bible/` の選定案）

### 納品先
- リポジトリの `art/concepts/<波>_<アセットID>/` に置く（例：`art/concepts/W1_haru/`）。
- ファイル名の規則は `00_共通ルール.md` を参照。

### 確認と修正
- ユーザーが見た目を確認する。
- Claude が「3D 化に必要な情報がそろっているか」を確認する（三面図の整合、寸法、色の数値など）。
- 修正が必要な場合は、番号つきの修正指示を出す。修正版はファイル名の末尾に `_r2`、`_r3` を付けて納品する（古い版は消さない）。

## 世界観の要約（Codex 向け）

- 遠い未来。地表は赤錆色の砂と、千年前に消えた先史文明の巨大な残骸に覆われている。
- 人々は、山のように巨大な古代の歩行機械〈巡礼機〉の背中に町を築き、大地を歩きながら暮らしている。
- 先史の遺物を遺跡から持ち帰る「回収屋」という職業がある。遺跡は無人の自律機械〈番機〉が守っている。
- 雰囲気は**明るいレトロフューチャーの冒険活劇**。終盤は少しシリアスになる。現実的なメカの理屈にはこだわらない。
- 詳しくは `docs/design/10_シナリオ設計.md` と `docs/design/11_キャラクター設定.md` を参照してよい。
