# AI で 3D を作って取り込む手順（B案）

絵（Codex の W1-00）→ TRELLIS.2 で 3D の塊にする → Claude が骨・重み・動作を付けてゲームに入れる。

## 1. 使うサービスと条件

| 項目 | 内容 |
|------|------|
| サービス | **TRELLIS.2**（Microsoft）の公式デモ：https://huggingface.co/spaces/microsoft/TRELLIS.2 |
| 費用 | 無料。登録なしで使える（混んでいると待たされる。Hugging Face のアカウントでログインすると使える回数が増える） |
| ライセンス | MIT（商用可）。ただし一部の付属部品は別のライセンスなので、販売前にもう一度確かめる |
| 申告 | Steam で売る場合、AI で作った素材を使ったことの申告が必要（Codex の絵も該当） |

## 2. あなたにお願いする作業（(a) の方法）

Codex の W1-00 の絵（ブランチ `art/w1-haru3d` の `art/concepts/W1_haru_3d/`）が届いたあと：

1. 上のデモのページを開く。
2. `haru_3d_front.png` を画像の欄に入れる。
3. 設定は既定のままで生成する。テクスチャの大きさを選べる場合は 2048 にする。
4. できた 3D をページ上で回して、全身がそろっているか（腕や足が欠けていないか）を見る。欠けていたら、もう一度生成する（生成のたびに少しずつ結果が変わる）。
5. GLB をダウンロードする。
6. GitHub のリポジトリのページで、ブランチ `claude/busy-bell-oagnck` を選び、「Add file」→「Upload files」で `art/3d_sources/` に置く。ファイル名は `haru_trellis_front.glb`。
   - GitHub の画面から上げられるのは 1 ファイル 25MB まで。大きすぎる場合は、デモの設定で面の数（decimation / simplify）を減らして作り直す。
7. 余裕があれば、`haru_3d_three_quarter.png`（斜め前）でも作って `haru_trellis_34.glb` として置く。どちらが良いか比べる。
8. 置いたら Claude に知らせる。

## 3. Claude が行う作業

```bash
npm run ai:haru      # art/3d_sources/haru_trellis_front.glb → public/assets/models/haru_b.glb
```

中身は `tools/blender/models/ai_character.py`：

1. 向き（正面・前後の自動判定）、大きさ（身長 1.55m）、足の位置をそろえる。
2. 形から関節の位置を推定する（A ポーズの腕の軸を直線で当てはめる）。うまく推定できないときは、`--joints` の JSON で手で直す。
3. 面を約 16,000 三角形まで減らす。
4. 骨の重みを付ける（Blender の自動の重み。失敗したら骨までの距離の重みに切り替える）。
5. 腕を下ろした姿勢を新しい基準の姿勢にして、標準の骨を入れ直す。MVP の 14 動作がそのまま使える。
6. 銃（右手。絵が届くまでは箱の組み合わせの仮の形）、光刃（左前腕）、銃口の目印を付ける。
7. 琥珀色の部分を探して光らせる。

確認：見た目の確認ページのモデルで `haru_b` を選ぶ。ゲームは URL に `?haru=b` を付ける。

## 4. 試験の結果（本物の出力が届く前の確認）

A案の試作のハルを「A ポーズ・骨なし・1 つの塊」にした代役で試した。

| 代役 | 結果 |
|------|------|
| 色付き・4,200 三角形 | 自動の重みが失敗（部品が離れているため）→ 距離の重みで成功。動作も問題なし |
| 継ぎ目のない塊・16 万三角形・向きを 90 度ずらしたもの（AI の出力に近い） | 向きと前後を自動で直せた。16,200 三角形に減らし、自動の重みで成功。走り・跳躍・銃の構え・斬りで破綻なし |

## 5. 私ができない場合の方法（(b)）

この作業環境から Hugging Face に接続できるようにすれば（環境の設定の Network access で `huggingface.co` と `*.hf.space` を許可）、2 章の作業も Claude が行える。
