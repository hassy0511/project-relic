# バートンを絵から 3D にした結果（burton.glb）

> 2026-10-01。Codex の W2-01 の絵（`origin/art/w2-townsfolk` の `art/concepts/W2_townsfolk/` の `burton_*`、`spec_townsfolk_3d.md`）から、
> 回収屋ギルドの支部長バートン（190cm、NPC、持ち物なし）の 3D を作った。**最初から「部品の表 → 体の土台 → 顔 → 決まりの塗り →
> 部品 → 骨」の順（`.claude/skills/model-from-art/SKILL.md`）で作った最初の人物**。ゲームの流れには入れていない（Godot の確認画像まで）。
> 確認ページ：https://hassy0511.github.io/project-relic/models/?m=burton

## 0. 先にしたこと：部品の表を人物ごとの設定へ移した（ハルは 1 バイトも変わらない）

`costume.py`・`hand.py` にハルの値で書いてあった部品の表・塗りの決まり・手の寸法を、**人物ごとのファイル
`tools/blender/recon/chars/<id>_parts.py`** へ移した（`costume.py` が `RECON_CHAR` の人物のファイルを読み込み、その大文字の定数と
`pieces()`・`boot_pieces()`・`body_rules()` を自分の中に入れる。`costume.py` の道具 `frame`・`octagon`・`rrect`・`jp`・`param_of`・
`inside_poly` などは、読み込むときに渡すので import しないで使える）。

- ハル：`chars/haru_parts.py`（値は移しただけ）。部品の材質の名前は `<id>_parts`（ハルは今までどおり `haru_parts`）。
- **確かめ方**：骨付けの段（`ai_character.py`）と塗りの段（`texture.py`）を新しいコードで作り直し、コミット済みのものと比べた。
  `haru_r.glb`・`haru_textured_apose.glb`・`haru_body_base.png`・`haru_body_emit.png` が **バイト単位で同じ**（`cmp`）。
  前のコードでもう一度作った `haru_r.glb` も同じ（作り方が決定的であることの確認）。
- 共通の足し算（ハルでは使わない値なら何もしない）：`ai_character.py` の開いた手を左右どちらにも（NPC は `--no-weapon --hand-part`
  で両手とも開いた手の部品）、`hand.py` の手袋なし（`HAND['GLOVE'] = None`）・掌の大きさ、`costume.BOOT_CUT_X`、
  `hair.SKIN['jaw_ka']`（あごの幅を絵から読まずに節で決める）、`build_char.py` の指紋に `chars/<id>_parts.py`・`hand.py`、
  `audit_viewer.mjs --model <名前>`（身長は `chars/*.json` から、区域の高さ・距離を身長の比で伸ばす。`--head-y`）。

## 2. やり方の記録（うまくいかなかったこと）

| 試したこと | 結果 | 今のやり方 |
|-----------|------|-----------|
| 白髪の帯を髪の上の殻（部品）に | とがった房の上に浮いた鉢巻きに見えた | 髪の色の所だけ多角形で灰に塗る（形の場で決める） |
| あごの幅を正面の絵の肌の色の幅から読む（既定） | 立ち襟の陰の生成りが肌の色に入り、あごが襟の幅の横棒になった | `hair.SKIN['jaw_ka']` で節の値を書く |
| 斜めの絵（右前 45 度）にも縁を寄せる（既定） | 絵の斜めの図が別の角度に近く（較正の値が上限に当たった）、肘の後ろにひれができた | `snap.REAL` を正面・右真横だけに |
| 帽子（髪の土台）を外形のまま | 耳の高さで帽子の下の縁が耳の幅まで張り出し、ほおの横に棒が出た | `hair.CAP.undercut`（刈り上げ） |
| 頭の横の髪を「y > 0 で高さ 1.375 より上」で塗る | 四角い肌の窓が残った | 後ろからの角度でなめらかに上がる髪の下の縁 |
| 体の足を消す範囲 \|x\| < 0.32（ハルの値） | 広い靴底の外に体の爪先の端が細く残った | `BOOT_CUT_X = (0.03, 0.40)` |
| 顔の窓を広げすぎ | 顔の材質が耳の前まで回った | 窓を頬の手前まで、差し替えの範囲を眉・目・口だけに |
| 側頭の髪を髪の場（hair − skin）で決める | 刈り上げの帽子は頭の面から 6mm 以内なので場の差が負になり、耳の前・後ろに四角い肌の窓が残った | 正面からの角度の表 `HAIR_LOW` の高さより上を髪（形の場は房と耳にだけ使う） |
| 首の後ろ（襟の上）を襟の下の内着の石墨のまま | UV のつぶれた三角形が隣の島の色を拾い、石墨・肌・髪の斑点になった | 耳より後ろは髪の線より上を襟の下でも髪にする（首の後ろの島ごと髪の色）。耳の下の小さな斑点だけ残る |
| 顔の絵のもみあげをそのまま（細い黒い縦線） | 顔の材質の縁に黒い縦線と、その外の肌の帯が残った | `flat.FACE_SIDEBURN`：外側まで髪にし、縦にならし、内へ 4.5% 広げ、下の端は外へ斜めに細らせる |
| 体の髪の線を正面から 33 度より外に広げ、もみあげの下を水平に切る | 顔の材質の縁（三角形の辺）が「体は髪・顔は肌」の境になり、階段が見えた | 境の両側を同じ色に：体の髪の線を顔の近くで上げ（33 度 1.405 → 60 度 1.372）、もみあげの下は斜めに |
| 鼻の古傷の線を絵の色のまま | 平らな肌の上で濃い橙の × 印に見えた | `flat.FACE_WARM_SOFT`：明るく赤みの強い線だけ肌へ 7 割寄せる |
| 2 周目：もみあげを顔の画像の髪で（`FACE_SIDEBURN`） | 統括の確認で「額・こめかみに髪の色の切れ端」。肌の面に髪の色を塗るかぎり、縁は形と合わない | 顔の材質を肌の形の上だけにし、顔の画像に髪を置かない。髪の色は髪の形の上だけ |
| 白髪を多角形で塗る | 側頭に平らな明るい灰のくさび（シールのよう） | 白髪の房 2 本を作り、その房の形の上だけ灰に |
| 房の表のまま当てはめ（浮きの下限なし、帽子は外形のまま） | 当てはめが浮きを 0 近くへ寄せ、房が帽子に沈んで丸い帽子に見えた | 帽子を外形より 1.4cm 内側にし、浮きの下限 2cm、絵を読んだとがった房の表 8 本 |
| 白髪の房も当てはめる | 外形に合わせて 3cm 浮き、片方は顔の範囲の判定で落ちた | 当てはめで動かさない房（`LOCK_FIXED`）、顔の範囲の判定からも外す |
| 色を spec の hex のまま | 確認ページで上着が明るい桃色寄り、靴が灰緑（絵は暗い茶の靴に茶の底） | 絵の平らに照らされた所の中央値で測った色に（上着・ズボン・生成り・真鍮・靴・底・白髪） |
| 3 周目：生え際を絵より 1.5cm 低いまま、前の房の先を前・上へ | Godot の顔の近写で、前髪が額に低くかぶさるおかっぱに見えた | 生え際を絵で測った高さへ上げ、前の 3 本の根を生え際に、先を上・後ろへ（浮きの下限 3〜3.5cm） |
| 白髪の房を頭の髪の場の一部にして、房の場の近くを灰に塗る | 房が帽子に半分うまり、灰が茶の髪の上に白い切れ端・ぎざぎざの縁で載った | 白髪の房を別の形の部品（管）にし、部品の色見本の 1 色に。先を浮かせると角のように飛び出し、浮かせないと横の茶の房が突き抜けたので、幅の中で一番外の面に 3.5mm 浮かせて載せる |
| 鼻の古傷を細く・薄く残す（`FACE_WARM_SOFT` 7 割） | 近写で橙のしみに見えた | 古傷と鼻の陰を肌に（線を消す）。鼻の穴の線は残る |
| 首の後ろの斑点を塗りの決まりだけで | 決まりは髪なのに、UV のつぶれた三角形が隣の島（襟の下の石墨・肌）の画素を拾って斑点が残った | `texture.SOLID_ZONES`：首の後ろ（正面から 95 度より後ろ、z 1.20〜1.355）と耳の後ろ（118 度より後ろ）の、テクセルの少ない三角形の UV を、3D で一番近いテクセルの多い三角形の UV の重心 1 点へ付け替える（耳は除く。耳に掛けると耳に髪の色が載った） |

### 3.1 確認の格子で見たもの（3 周目・頭だけ、2026-10-05、idle 0.5 秒、頭の 16 こまを全部見た）

| 区域 | 向き | 中身 | 直したか |
|------|------|------|---------|
| 頭 | 正面・斜め（Godot の顔の近写） | 前髪が額に低くかぶさる平らなおかっぱ | **直した**：生え際を絵の高さへ、前の房は上・後ろへ立ち上がる。額が見え、頭頂の房がとがる |
| 頭 | 横・後ろ斜め・後ろ | 白髪が茶の髪の上の白い切れ端・ぎざぎざの縁 | **直した**：白髪の房 4 本（部品、房全体が灰 `#9A928C`）。左右とも 2 本の房の形で見える |
| 頭 | 後ろ・後ろ斜め | 首の後ろ・耳の下の襟の際の暗い斑点 | **直した**（UV の付け替え。首の後ろは襟の中まで髪） |

### 3.2 残り（直していないもの）と、直せなかった理由

| 区域・向き | 中身 | 理由・次にすること |
|-----------|------|------------------|
| 頭・正面・斜め | 生え際の縁が細かいぎざぎざ（2〜3mm の三角） | 縁は髪の形（帽子）の縁そのもので、帽子は 2mm の格子の場から作った面を間引いた三角形で切れている。塗りでなく形の縁なので塗りでは直らない。帽子の顔の側の切り口（`hair.face_cut`）をなめらかな曲線で切って細かい面にする（形の段の作り直し、約 25 分） |
| 頭・後ろ・後ろ斜め | 右の白髪の房が左より頭から浮いて見える（横の茶の房のふくらみの上に載るため） | 髪の形が左右対称でない（房の当てはめが左右の絵の外形に別々に合わせる）。白髪の房は左右同じ道なので、右だけ茶の房の上に載る。房の当てはめを左右対称にする（左の絵は右の反転なので、右の房を反転して左に使う）のが本当の直し |
| 頭・横 | 耳の前のもみあげが肌（絵は耳の中ほどまで髪） | もみあげの形（房）が無い。肌の面に髪の色を塗らない決まりにしたので、房を 1 本ずつ足す（形の段から） |
| 首・正面 | 内着の石墨とあごの肌の境がぎざぎざ | 顔の材質の下の縁（三角形の辺）が境。2 周目から変わらない |
| 胴・後ろ | 体の土台の陰の凸凹 | 形の段の直し（2 周目の表のとおり） |
