# 3D 変換用の絵の条件（すべての 3D 化の発注に共通）

> Codex（作画担当）へ。キャラクター・機械・小物を 3D にするための絵の描き方。
> `00_共通ルール.md` と食い違う場合は、**3D 変換用の絵についてはこの文書を優先**する（背景、1 枚ずつ分けること、など）。
> 各発注書の「3D 変換用の絵」の表と一緒に使う。

---

## 1. なぜこの条件か

Claude は、絵の**外形（輪郭）から形**を作り、**描かれた色をそのまま表面の色**として貼る。
したがって、絵の中の「外形の位置」と「色」が、そのまま 3D の形と色になる。

ハルの 3D 化（W1-00）で分かったこと：
- 正面・背面・真横・斜めを、同じ大きさ・同じ高さで描いてくれたので、形が 98% 以上一致した。**この条件は今後も守る**。
- 斜めの絵が、発注の 45 度ではなく約 31 度で描かれていた。角度がずれると形と色がずれる。
- 真横の絵では腕が胴の横を隠すため、胴の横の色が分からず、3D では継ぎはぎになった。
- 首・襟、手（指）、靴の底、頭の上と後ろは、全身の絵では小さく、3D で粗が残った。

このため、今回から「全身の絵」に加えて「部分の拡大の絵」を必ず描いてもらう。

---

## 2. すべての絵に共通

| 項目 | 条件 |
|------|------|
| 大きさ | 正方形 **2048×2048**。生成できる最大の大きさで描いてから合わせる |
| 背景 | **透明**（アルファ付き PNG） |
| 投影 | **遠近感をつけない正投影**。カメラは対象の中心の高さ、水平に向ける |
| 光 | 正面からの**均一で柔らかい光**。形がわかる程度の弱い陰影はよい。落ちる影・逆光・縁の光・光沢のハイライトは描かない |
| 発光する部分 | 平らな色で塗る。光のにじみ（グロー）や周りへの光の漏れを描かない（ゲームで光らせる） |
| 輪郭線 | 描かない（W0 A案どおり） |
| 床と影 | 描かない |
| 文字など | 文字・寸法線・矢印・ラベル・署名を画像の中に入れない（説明は spec に書く） |
| 色 | spec の hex の色で塗る。広い面は 1 色で塗り、細かい模様を描き込まない |
| 1 枚 1 方向 | **1 つの画像に 1 つの向き**だけを描く（シートに並べない） |

---

## 3. 全身の絵（人物）

### 3.1 そろえること（最重要）
- **すべての向きで、同じ大きさ・同じ位置**：足の裏の行、頭のてっぺんの行を全画像で同じにする。体の中心を画像の横の中央（1024 px の列）に置く。
- 全身を画像の高さの **85〜90%** に収め、上下に余白を残す。
- 同じ人物・同じ服・同じ姿勢。向きだけを変える（1 つの 3D の人形を回して描くつもりで）。

### 3.2 姿勢
- **A ポーズ**：まっすぐ立ち、腕は体から約 35 度開いて斜め下へ。肘と膝はまっすぐ。足は肩幅で、つま先は正面。
- 手は軽く開き、**指を少し離す**。手のひらは体の側へ向ける。**何も持たない**。
- 顔は正面、目を開けた落ち着いた表情、口を閉じる。髪で目を隠さない。

### 3.3 向き（ファイル名は `<ID>_3d_<向き>.png`）
| 向き | 内容 | |
|------|------|--|
| `front` | 正面 | 必須 |
| `back` | 背面 | 必須 |
| `side_right` | 本人の右側から見た真横（顔は画像の右を向く） | 必須 |
| `side_left` | 本人の左側から見た真横（顔は画像の左を向く） | 左右が非対称なら必須、それ以外は推奨 |
| `front_right45` | 本人の右前 **ちょうど 45 度** | 必須 |
| `front_left45` | 本人の左前 ちょうど 45 度 | 左右が非対称なら必須 |
| `side_right_noarms` | `side_right` と同じ絵から**腕だけを取り除いた**もの（肩の付け根で切る）。腕に隠れていた胴の横の服・帯・模様を描く | 必須 |

- **45 度の確かめ方**：45 度の絵では、左右の足の間隔（両足の中心の距離）が、正面の絵の約 0.7 倍になる。0.8 倍より広い場合は角度が浅すぎる。
- 左右非対称の部品（片腕だけの義手、片側だけの板など）は、spec に「本人の右／左」を必ず書く。

## 4. 部分の拡大の絵（人物）

全身の絵と**同じデザイン・同じ色**で描く。背景透明、正投影、均一な光は同じ。

| ファイル名 | 内容 | |
|-----------|------|--|
| `<ID>_face_front.png` | 首から上の正面。画像の高さの約 85% が頭。目・眉・口がはっきり見える通常の表情 | 必須 |
| `<ID>_face_expressions.png` | 2×2 の並び：左上 通常、右上 笑顔、左下 驚き、右下 痛み（発注書で別の表情を指定する場合はそれ）。**4 つとも `face_front` と同じ大きさ・同じ位置**で、変えるのは目・眉・口だけ | 必須 |
| `<ID>_head_side_right.png`、`<ID>_head_back.png`、`<ID>_head_top.png`（真上から）、`<ID>_head_front_right45.png` | 首から上の 4 方向（1 枚に 1 方向）。`face_front` と同じ大きさ。**髪の房の分かれ方と重なり**が分かるように描く | 必須 |
| `<ID>_neck.png` | 首まわり（襟・フード・首の付け根）の拡大。正面・真横・背面を 1 枚に 3 つ並べてよい（この絵だけ並べてよい） | 必須 |
| `<ID>_hands.png` | 右手の拡大：開いた手の甲側・手のひら側、握った拳（横から）。指の本数と関節、手袋の境目が分かること。左右で違う場合は左手も | 必須 |
| `<ID>_shoes.png` | 靴の拡大：真横・正面・底（真下から） | 必須 |

## 5. 持ち物・機械・小物

| ファイル名 | 内容 | |
|-----------|------|--|
| `<ID>_side.png` | 真横 | 必須 |
| `<ID>_top.png` | 真上 | 必須 |
| `<ID>_front.png` | 正面（銃なら銃口の側） | 必須 |
| `<ID>_3q.png` | 斜め 45 度（上から少し見下ろしてよい） | 必須 |
| `<ID>_back.png`、`<ID>_bottom.png` | 背面・真下 | 形が前と違う場合・人型でない機械は必須 |

- 真横・真上・正面は、**同じ大きさ**（1 px が同じ長さ）で描く。spec に全長（cm）を書く。
- 持つ物は、握る部分（グリップ）の位置が分かるように描く。
- 動く部品（殻・脚・扉など）がある機械は、`<ID>_parts.png`（分解図：部品を少し離して並べ、つながる位置を細い線で示す）を追加する。この絵だけは、部品を並べた 1 枚でよい。

---

## 6. spec（`spec_<ID>_3d.md`）に書くこと

1. 納品物の一覧（ファイル名・大きさ・背景）。
2. **自己確認の結果**：全身の各画像の「頭のてっぺんの行」「足の裏の行」「体の中心の列」（px）。45 度の絵の「足の間隔 ÷ 正面の足の間隔」。
3. 色見本（部位・hex・材質）。発光する部分はその旨。
4. 左右非対称の部品と、その側（本人の右／左）。
5. 絵から読み取りにくい部分の説明（帯の回り方、部品の取り付け方、髪の後ろの形など）。
6. 設計の絵（三面図など）から変えた点と理由。
7. 描けなかったものと理由（冒頭に「未納品」として）。

---

## 7. 避けること

- 2〜5 章の条件を破ること。特に、遠近感、向きごとの大きさ・高さのずれ、斜めの角度のずれ、影、物を持たせること、指をくっつけること。
- 向きによってデザインが変わること（部品の数・位置・色）。
- 1 枚に複数の向きを並べること（`_neck.png`・`_hands.png`・`_shoes.png`・`_parts.png` を除く）。
