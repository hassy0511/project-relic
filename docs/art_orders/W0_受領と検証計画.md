## 2. 絵から読み取ったハルの形と、仮に決めること

W0 は正面の概念図で、確定した三面図ではない。正面から読めない点や説明書と食い違う点は、次のように仮に決めて試作する。試作の結果と一緒に報告し、必要なものは番号つきの追加作画として戻す。

| 番号 | 論点 | 絵・説明書の状態 | 試作での仮の決め方 |
|------|------|------------------|-------------------|
| P-1 | 頭身 | 並び図は約 5 頭身。spec の目標は 4〜4.5 頭身 | **4.5 頭身**で作る。ゲーム中の距離で読みにくければ 4.0 と比べる |
| P-2 | 肩と腰の板 | 絵では本人の右肩と右太ももだけにある。spec は「左右で同じ部品を使える形」 | **絵のとおり左右非対称**にする（右肩と右太もも）。部品の形は左右反転して使い回せるものにする |
| P-3 | 脚のフレーム | 絵は琥珀のレンズつき膝当てと、すねの縦板 | 絵のとおり。膝当ては脛の骨に付け、膝を曲げたときは太もも側と重なってよい形にする |
| P-4 | 光刃の付き方 | 左前腕のガントレットから、手首の先へ前腕に沿って伸びる（腕の刃）。いまの MVP は左手に持たせている | **左前腕に固定**し、手首の先に見える部分を約 45cm にする。斬撃のモーションは「持つ剣」から「腕の刃」の振り方に作り直す |
| P-5 | 銃 | 本人の右手に持つ独立した小型銃（約 30cm）。正面からしか分からない | 箱を組み合わせた単純な形で、横から見た形は仮に作る。手と溶接しない |
| P-6 | 背中 | 肩越しに黒い帯が見える。背中側は不明 | 背中で**帯を X 字に交差させるだけ**にする。背負う荷物は付けない |
| P-7 | 髪の後ろ側 | 正面から見て 5〜7 個の大きな塊。後ろは不明 | 後ろにも大きな塊を 3 つ置き、襟足は短くする |
| P-8 | ゴーグル | 額の上に上げた、開いたゴーグル。ヘルメットにはしない | 後頭部に帯を回す。レンズは琥珀色で、弱く光らせる |
| P-9 | 顔 | 大きな目、眉、小さな口。微笑み | 顔の形は単純にし、目・眉・口は**テクスチャで描く**。表情はテクスチャの差し替えで 4 種（通常、笑顔、驚き、痛み） |
| P-10 | 手 | 指なし手袋 | 指は親指と、4 本をまとめた 2 つの塊にする（3 角形の数を抑えるため）。銃を握る形と開いた形の 2 種 |
| P-11 | 塗り | 輪郭線なし。基本色と広い陰影 1〜2 層 | 3 段の階調で塗るシェーダー（トゥーン寄り）と、柔らかい陰影の標準シェーダーの **2 通りで見比べる** |

## 3. 検証の進め方

1. **モデル**：Blender のスクリプトで作る（MVP の仮ハルと同じ作り方）。いまの標準の骨と 14 種のアニメーションを使えるようにし、必要な分だけ体型に合わせて直す。
2. **最低限の動作**：待機、走る、跳ぶ、撃つ（右腕を照準へ向ける）、光刃の 3 段斬り（腕の刃に合わせて作り直す）。
3. **見え方の確認**：次の画像を撮る。
   - 正面・横・背面・斜めの静止画（明るい灰色の背景）
   - ゲーム中の距離（カメラ距離 5.5m、画角 60 度）での後ろ姿、ロックオン中、10m 先
   - 赤い砂の地面と暖かい朝日の中（キービジュアルの色調の仮の場面）
   - 肩・肘・膝を大きく曲げた姿勢の拡大（変形と装備の干渉を見る）
   - 短い動作見本（走る、跳ぶ、撃つ、斬る）
4. **ゲームへの組み込み**：MVP の仮ハルと差し替え、試遊版でも見られるようにする（試遊版の差し替えは、比較のため切り替えられる形にする）。

## 5. 本採用の判断に使う確認項目（`handoff_claude.md` より）

1. 正面・横・背面とゲーム中の距離で、A案の輪郭・顔・色分けが読めるか。
2. 歩く・走る・跳ぶ・撃つ・斬るで、肩・膝・肘の変形や装備の干渉に無理がないか。
3. 赤い砂の背景と暖かい光の中で、ハルを見失わず、A案の雰囲気を保てるか。
4. 3 角形の数、材質とテクスチャの数、シェーダー、難しかった点、実機での負荷を記録できたか。

結果は「再現できた点」と「直しが必要な点（番号つき）」に分けてユーザーへ出す。作画へ戻す直しは番号つきの追加依頼にする。
