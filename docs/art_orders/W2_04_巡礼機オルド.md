## 1. どんな存在か

- 千年前の先史文明が、地上に残される人々のために造った**山のような巨大歩行機械**。
- 決まった道（巡礼路）を、何百年もかけてゆっくり歩き続けている。
- **背中に人々の町（オルド背町）が築かれている**。体内は遺跡になっている。
- このゲームの象徴。タイトル『アークウォーカー（歩く方舟）』は巡礼機のこと。**見た瞬間に心をつかむシルエット**にしたい。
- 物語の後半で、巡礼機は「残された人々の避難船」として造られたことが明かされる。**方舟**を思わせる要素を、さりげなく入れてほしい。

## 2. 寸法と構造

| 項目 | 値 |
|------|-----|
| 全長 | 約 400m |
| 背中までの高さ | 約 120m |
| 脚 | 4〜8 本の範囲で自由（アートバイブルで描いたシルエットと合わせる）。1 歩に数十秒かかる、ゆったりした歩き |
| 背中の町 | 約 180m × 90m。甲羅（または背中の構造物）の曲面に沿った 3 段の段々 |
| 尾の側 | 体内の遺跡への入口（「禁足扉」） |
| 脇腹 | 地上へ降りる昇降リフトの発着場 |
| 頭の側 | センサーや航行の装置を思わせる部分（動物の顔にしすぎない） |

- 先史の技術の質感に、千年の歳月（風化、砂の堆積、人々が後付けした足場や配管）を重ねる。
- **避けるもの**：既存の有名な「町や国を背負って歩く巨大なもの」に似たシルエット。特に『ゼノブレイド2』の巨神獣（アルス）、『ONE PIECE』のゾウ、『ハウルの動く城』、『移動都市／モータル・エンジン』の移動都市、『ワンダと巨像』の巨像。**生き物ではなく機械**であること、巡礼（決まった道を歩き続ける）と方舟の性格で差をつける。

## 3. ほかの巡礼機について
- 世界には数十体の巡礼機がいる。形はそれぞれ違うが、**同じ設計思想の兄弟**に見えるようにしたい。
- 今回はオルドに加えて、ライバルの町を乗せた巡礼機「カラン」を**シルエットのみ**で 1 案描く。
