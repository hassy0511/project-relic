# ハル：Fable 5.2 が別に作る試作（haru_f）

## 目的

ユーザーの依頼（2026-11-11）：「このゲームのキャラを、試しに作りなおしてみてほしい。デザインは Codex の絵のままでよく、3D モデルの作成をやってほしい。
斬撃などのアクションも。今のデータは上書きせず別に作り、今ある確認ページで比べられるように」。
ねらいは、今後の分担（①ゲーム全体の設計は今の Opus 5.5、②個別のキャラクターなどの作成は Fable 5.2）を決めるための見きわめ。

- これまでのハル（`haru_r`）と、スキル集の試作（`haru_bs`）はそのまま残す。ゲームの既定も `haru_r` のまま。
- 新しいモデルは **`haru_f`**（`godot/assets/models/haru_f.glb`）。ゲームでは `--haru=f`（ブラウザ版は `?haru=f`）、確認ページでは「Fable の試し」の欄。
- きれいな比べのため、`haru_r` の形・重み・テクスチャ・動作のキーと、プロジェクトの人物の道具（`tools/blender/recon/` の形づくり・塗り・骨付け）は使っていない。
  使ったのは、Codex の絵と仕様書（`art/w1-haru3d`）、ゲームとの約束（骨・動作・部品の名前、動作の長さ、原点・身長・向き）、
  自動の確かめ（`glb_audit.py`・`test_models.gd`）と確認ページの撮影の道具（`audit_viewer.mjs`）だけ。

## 作り方

スクリプトは `tools/blender/trial_f/`。考え方は「**ローポリの作り手が手で組むのと同じことを、寸法の表から式で組む**」。
絵は面の大きい平らな色の 3D 風なので、外形を掛け合わせたり色を写したりせず、部品をひとつずつ寸法から作って、部品ごとに 1 色を付けた。

| 段 | ファイル | やること |
|----|---------|---------|
| 寸法 | `measure.py`・`spec.py` | 絵に cm の格子を重ねて、関節・部品の位置と大きさを読む（全身の絵は頭頂 125 行・足裏 1922 行 = 155 cm）。原点は足の長さの真ん中の床（真横の絵の中心から 2.1 cm 後ろ） |
| 形の道具 | `geo.py` | numpy だけ：輪を積む筒（腕・脚・袖）、輪郭を押し出して面取りした板（肩・膝・太ももの板、靴底、銃）、面に沿う帯（肩ひも・ゴーグルのヒモ）、葉の形の房。閉じた部品は体積の符号で面を外向きにそろえる |
| 体と作業着 | `parts_body.py` | 胴・首・上着（前の開いた殻）・フードの襟・袖・腕・ベルトとバックル・ポーチ・ズボン・すね・足首のカフ・靴 |
| 頭 | `parts_head.py` | 頭は高さごとの断面（半幅・前・後ろ）16 段の表。鼻は真ん中の列だけ前へ。耳、髪の土台、葉の房 40 本（つむじから放射状の 4 段＋前髪）、ゴーグルとヒモ |
| 装備 | `parts_gear.py` | 外装フレーム 3 群（胴：肩ひも・背中の板・右肩の板、腕：籠手と射出口、脚：膝当て・蝶番・すね当て・右太ももの板）、開いた左手、銃を握る右手、スパーク、光刃 |
| 顔 | `face_tex.py` | 顔の絵から目・眉・口だけを切り出し、肌は 1 色に。表情 4 つ（通常・笑顔・驚き・痛み）を 2×2 に並べ、ゲームは `uv1_offset` で切り替える。体の肌も同じ材質の「肌だけの点」を指すので、顔と首・腕の肌の色は必ず同じ |
| 色 | `textures.py` | 色見本 17 色を並べた 64×80 画素の 1 枚（面ごとに 1 色の升を指す）と、琥珀だけが光る発光の 1 枚。髪の房は葉の 2 つの面を明・中の 2 段、裏を暗い段にした（絵の描いた陰） |
| 重み | `rigw.py` | 自動の重みは使わない。位置から式で決める：胴は高さ、腕・脚は関節の面からの距離でなめらかに渡す。硬い部品は骨 1 本（肩の板は肩 0.8・上腕 0.2、太ももの板は太もも 0.7・腰 0.3） |
| 組み立て | `bl.py`・`build.py` | Blender（bpy）は物体・材質・骨格にして GLB に書き出すところと、絵と同じ枠の描画（`render.py`、比べ用）にだけ使う。作り直しは 1 回 約 1 秒 |
| 動作 | `anim.py`・`anim_bake.py` | Blender を使わない。GLB の骨の基準の姿勢を読み、姿勢を「モデルの軸での回転」で書いて 60 こま/秒で GLB に差し込む（骨の向きの決まりに頼らない）。脚は足の置き場所から解く |

## 動作

14 種とも新しく作った（名前と長さは `haru_r` と同じ）。`haru_r` のキーや `humanoid_anims.py` の数値は写していない。
こま並べ（上の段が真後ろ＝ゲームのカメラ、下の段が真横）：[攻撃](haru_f_trial/motion_attacks.jpg)・[移動ほか](haru_f_trial/motion_moves.jpg)。

| 動作 | こま | 設計 |
|------|------|------|
| idle | 120・輪 | 少し左足前の立ち、呼吸と重心の揺れ |
| run | 40・輪 | 前傾 13 度、腰と胸の逆ひねり、蹴り上げから振り出し。銃の腕は控えめに振る |
| jump | 16 | 沈みから 4 こまで伸び。左ひざを上げ、右脚は伸ばす。左腕は前上、銃の腕は下 |
| fall | 40・輪 | 脚を前後に開き、腕はひじを曲げて下げる（T の形にしない） |
| air | 18 | 落下の姿勢 → 左上後ろへ振りかぶり → 右前下へ斬り下ろし → 落下へ |
| dash | 14 | 低い前傾と大きな歩幅。刃を右腰に引き、左へ抜き打ち（ダッシュ斬りと共用） |
| combo1 | 17 | 左上後ろへ振りかぶり → 右前へ大きな袈裟 → 体の右外・胸の高さで刃が水平に伸びて止まる。銃の腕は反動で後ろへ |
| combo2 | 18 | combo1 の終わりから右上へ振りかぶり → 左へ返す刀 → 体の左外で刃が水平に伸びて止まる |
| combo3 | 27 | combo2 の終わりから頭上へ（つま先立ち、背を反らす）→ 右前下へ叩きつけ（腰が 21 cm 沈む）→ 5 こま保つ → 構え |
| lunge | 20 | ひじを引いて溜め → 半身になって左肩の外の線で水平の突き、左足を 52 cm 踏み込む → 保つ → 構え |
| charge | 30 | 左後ろへ引く（ひねり 55 度）→ 右後ろまで横なぎ → 刃を体の前へ回して構え |
| drill | 8・輪 | 左腕を胸の高さで前へ突き出して踏ん張る。細かい震え |
| hurt | 16 | 3 こまでのけぞり、腕が胸の前へ跳ねる → 身をかがめた守り |
| dead | 36 | ひざから崩れて前へ倒れ、うつ伏せ。体の一番低い所を床に合わせる |

- 攻撃は「予備動作 → 振り抜き（いちばん短い、約 3 こま）→ 行き過ぎ → 戻り」。振り抜きは当たり判定の始まり（長さの 25%）に置いた。
  腰 → 胸 → 腕 → 前腕の順に遅らせ、頭は逆へ回して正面に残し、前の足を踏み込む。各段の終わりの構え＝次の段の始めの構え（右・左・右と交互）。
- 1 周目は combo1・combo2・lunge の振り終わりで刃が体の前に隠れ、真後ろから読めなかった。2 周目で弧を大きくして刃を体の外へ出した
  （真後ろから体に隠れない刃の割合：combo1〜3・lunge の 3〜12 こま目で最低 56%、振り終わりは 60〜100%）。
- 床：足の最も低い点 +0.0〜+0.1 cm、輪の継ぎ目 0.00 cm、dead の最後は体が床に着く。root は上下だけ動かす（その場の動作）。大きさの道は書いていない。
- 刃と体の距離（刃の全頂点と、左前腕・左手を除く体）：最小は combo2 の振りかぶりで頭の横 2.5 cm。
- 靴は足の骨に固く付くので、かかとを上げる回転の軸は爪先の端に置いた（母指球で回すと爪先が床へ沈む）。

## 作り直しのコマンド

```bash
bash tools/setup_blender.sh
mkdir -p build/art_f && for f in $(git ls-tree -r --name-only origin/art/w1-haru3d | grep art/concepts/W1_haru_3d/); do git show origin/art/w1-haru3d:$f > build/art_f/$(basename $f); done
bash tools/blender/trial_f/make.sh        # 顔の地図 → 形と GLB → 動作の差し込み → godot/assets/models/haru_f.glb
```

確かめ：`.venv-blender/bin/python tools/blender/recon/glb_audit.py godot/assets/models/haru_f.glb --strict`、
`python3 tools/blender/trial_bs/check_glb.py godot/assets/models/haru_f.glb --ref godot/assets/models/haru_r.glb`、
`tools/godot.sh import && tools/godot.sh test`、`node tools/blender/recon/audit_viewer.mjs --model haru_f --out docs/art_orders/haru_f_trial`。
絵との比べは `.venv-blender/bin/python -m tools.blender.trial_f.build --render front,back,right,fl45 --head --pose arms_up,crouch,run`。
