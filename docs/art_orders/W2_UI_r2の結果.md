# W2-08 UI r2 の結果（Godot に入れた）

W2-08 の直し（r2。`origin/art/w2-ui` の f525c4c、`art/concepts/W2_ui/spec.md` の「修正履歴」）を、HUD・メニュー・タイトルの仮の部品と入れ替えた（2026-10-18）。
**見た目だけで、遊びは変えていない**（ゲームの中身は読むだけ。HP の遅れて縮む時間・危険の境目（3 割）・点滅の速さ・チャージの段の時間はそのまま）。
直したのはダッシュボード 5 章 U1 の「絵の直し待ち」の項目（HP の危険の色、減った分の色、チャージと解析の進み、選択中のボタン、選択肢の札、タイトル）。

写し方は `tools/import_ui_art.py`（名前を並べると、その分だけ写す。元の部品は消さずに残した）。

### 2.1 HP（spec r2 の役割どおり）

- 通常：煉瓦色（`full_r2`）。被弾で減った分：白磁色（`damaged_r2`）で、0.45 秒待ってから毎秒 0.7 ずつ縮む（前と同じ）。特殊武器のエネルギーの琥珀色とは並んでも見分けられる。
- 危険（3 割未満）：高彩度の赤（`danger_r2`）に入れ替えて点滅。前は満タンと同じ色の絵を明るくして見分けていた（その手当てはやめた）。「HP」の文字が赤みの色になるのは前と同じ。
- r2 の中身は両端が丸い。減った分を中身の後ろに全部重ねると、中身の左の丸い端から白磁色が細くのぞいたので、減った分は「今の値〜遅れている値」の所だけに描くようにした（見た目は「後ろで縮む」のまま）。

### 2.2 チャージと解析（輪を時計回りに見せる）

- 空の輪（track）の上に、一周した中身の輪（fill）を、上（12 時）から時計回りに進みの分だけ見せる。絵の中心から扇形に三角形を並べて絵を貼る（`UiArt.draw_radial`。TextureProgressBar の円の塗りと同じ作り。シェーダーを使わないので、ブラウザ版の描き方 gl_compatibility でもそのまま描ける。`blend_mul` なし）。
- 主武器のチャージ：1 段目（0.6 秒）までの間に白磁の輪（`fill_stage1`）が一周 → 1 段目から 2 段目（1.2 秒）までの間に、その上を琥珀の輪（`fill_stage2`）が一周。琥珀の輪がそろえば 2 段目。
- 光刃の溜め斬り（1 段、0.7 秒）：白磁の輪が一周し、溜まりきると琥珀の輪。「琥珀の輪がそろう＝いちばん溜まった」でそろえた。
- 解析：照準の空の輪（`analyzing_track`）に、琥珀の輪（`analyzing_fill`）が解析の進みの分だけ回る。射程外で照準が薄いときも、進みの輪は薄くしない（解析は距離に関係なく進む。前の平らな弧も薄くしていなかった）。
  納品の `analyzing_fill` の輪（半径 92〜106、256px の絵で）は、照準の輪の溝（85〜93）より少し外にあり、外側の真鍮の線に半分かかる。絵のとおりに重ねている（4 章の残り）。

### 2.3 ボタンと選択肢

- 選んでいる行：暗い面に琥珀の縁（`button_focus_r2`）＋左のカーソル。押している間：煉瓦色の面（`button_pressed`）。前はどちらも煉瓦色だった。
  Godot はフォーカスの札を状態の札の上に重ねて描くので、押している間だけフォーカスの札を外す（`UiArt.add_cursor`）。キー・パッドの決定、マウス、タッチで同じ。
- 会話の選択肢：選んでいない札は `choice_r2`（角の飾りが上下 12px＝元の絵の 24px、縦に伸ばせる所が 36px）、選んでいる札はメニューと同じ `button_focus_r2`。中の余白（文字の場所）は前と同じで、文字の入り方は変わらない（パソコン 620px・スマホ 400px の幅）。
- 9 分割の角は spec r2 の表（元の絵で飾りの外端まで測った値）の半分を切り上げた値にした：会話 21／22、名前 14／21、選択肢（旧）21／28・r2 14／12、タブ 14／17、ボタン 17／22（大・小は前と同じ）。

## 3. タイトル画面

- 背景は `ui_title_r2`（低く長いオルドと背中の町、左下にそれを見るハル）を画面いっぱいに（はみ出す分は上下・左右の中央で切る）。前の「夜明けの空」（3D）は、絵が読めないときの後ろとして残る。
- ロゴは左上の空に、絵（`ui_title_logo`）で。スマホの横向き（低い画面）・縦長の画面では `ui_title_logo_nosub`（副題なし）：副題の文字が 360px の高さで 14px を切り、選択肢とも詰まるため。
  幅は画面の半分弱（パソコン 47%・スマホ 42%）。横に長い画面では高さで決める（背景が大きく描かれてオルドの舳先が上がるので、ロゴが掛からないように）。
- 選択肢は**右下**に移した（左下は絵のハルが立つ所で、前の位置だとハルの体が隠れる）。操作の説明は**右上の空**の短い表（移動・カメラ、ジャンプ・調べる、撃つ、ロックオン、光刃、ポーズ。割り当てを変えるとその割り当てで出る）にした。
  前の 18 行の表は、絵のオルドの後ろ半分を隠すため。全部の操作は「操作の設定」とポーズの「操作の説明」で見られる（タイトルにその 1 行を添えた）。スマホは前と同じ 4 行の短い表。
  説明の文は、ロゴの右から画面の右の余白までに収まらないときは折り返す（16:9 のスマホは UI を大きく描くと幅が約 1170 になる）。
- 選択肢の動き（パッド・キーボードの上下と決定、マウス、タッチ、無効の「つづきから」）は前と同じ `_menu_buttons`。「試遊版（Godot 版）」の印は左下へ。
