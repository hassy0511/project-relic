- **おすすめの順番は 7 章**（バートン → ヤーナ → ニコ → 店主 → トルーデ → ジャンク屋）。

### 共通の注意（5 人ともに当てはまる）

1. **左右対称が多い**。肩掛け・上着・靴・ポケット・袖は左右同形なので、片側を作って反転する（SKILL 2.2「1 つの定義を反転」）。左右で違うものは各表の「左右」の列に書いた。
2. **町の住人は、遠くでしか見ない**（SKILL 6.2）。1 周目（最初の 2 時間で粗くても最後まで通す）で止めてよいのは、店主とジャンク屋。トルーデ（町の長）・バートン（ギルド）・ヤーナ（MVP の住人）は近くで会話するので、確認の格子を全部撮って直す。
3. **住人は待機の動作しか使わない**（SKILL 5 章の `--no-weapon`、ヤーナの結果の文書）。長く垂れる布は**走り・跳躍で裂けない作り**までは要らない。ただし、歩く住人（巡回）を後で足す可能性があるので、重みの付け方は 6 章に書いた。
4. **腕なしの真横の絵**（トルーデ・バートン）は、腕を肩で外した所に**空洞の筒**（袖の切り口）が描かれている。胴の前後の厚みの測定にだけ使い、肩の形は他の絵に合わせる。ヤーナの腕なしの絵は肩がなめらかなシャツで、そのまま使える。
5. 「色は spec の hex」と決まっているが、**spec に無い色**（髪の一部・当て布・ルーペのガラス・工具の灰色・靴の本革の濃淡など）が各人にある。各表で「**要指定**」と書いた。着手の最初に、絵から測った hex を spec の末尾に書き足してから作る（Codex に聞くほどではない）。

## 6. 垂れる布（エプロン・スカート・ケープ・タオル）の作り方と重み

対象：ヤーナのエプロン前布とタオル、店主のエプロンとスカートとリボン、トルーデのスカートと前掛けとケープ、バートンの上着の裾、ジャンク屋のベスト。
どれも住人なので、**待機だけ使う前提**でよい。歩く住人を足す場合は、下の「歩くとき」に進む。

### 6.1 形

- **一周に近い布（スカート、上着の裾）**：骨の軸（上下）のまわりに、高さごとの断面（角を丸めた多角形）を積む（`build_loft`、靴と同じ）。トルーデのスカートは 12〜16 面の面（絵の折り目のとおり）、腰 径 28cm → 裾の幅 63cm、丈 61cm。厚みは 6〜10mm、裾に少し厚みを付けて縁を面取りする。裾の線は水平から少し下がる（前が低い）が、まず水平でよい。
- **前だけの布（エプロンの前布、前掛け）**：体の前面を測った面（光線を飛ばして測る、SKILL 2.1「体に沿う殻」）の上に、幅の輪郭を置き、**上は体に沿わせ、下に行くほど体から離す**（胸当ては 1.5cm、膝では 6〜8cm）。ヤーナの絵の側面では、エプロンの下半分が体の前へ平たいひらひらとして出ているので、離れ方も測る。
- **ケープ**：肩・胸・背中を覆う殻。肩の丸みは円柱でなく球。裾は水平に近い。
- **リボン・タオル**：薄い板を数枚つなぐ（輪 2・結び目・尾 2）。タオルは腰から垂れる 1 枚の板（わずかに外へ反る）。
- 縁取り・縁の線・真鍮の帯は**別の細い帯**にして、布の殻の縁に重ねる（色を縁で分けず、形で分ける）。
- 布の補修の細かい縫い目（トルーデ・ジャンク屋・店主）は**色**のまま。独立した形にはしない（spec の 3D 化の注意のとおり）。

### 6.2 骨と重み（待機だけの場合）

| 布 | 骨 | 重み |
|----|----|------|
| スカート・エプロンの腰より下 | hips | すべて 1（剛体）。脚は布の中に隠れるので、脚へ追従させない |
| エプロンの胸当て、ケープ、ベストの上 | chest（上）→ spine（中）→ hips（下）の高さでなめらかに移す | `BOOT_RAMP` と同じ形のなめらかな移し方（階段にしない） |
| ケープの肩の外側、上着の裾の脇 | 近くの体の重みを写す（`FOLLOW_BODY`） | 腕を下ろす・上げるで肩が破れない |
| 腰のタオル、リボンの尾 | hips | 1。揺らさない |
| 持ち物（杖・ハンマー） | 手の骨 | 1 |

### 6.3 歩く・走るとき（住人が歩くようになったら）

- スカート・エプロン：腰の高さまで hips に 1、そこから下は、**左右の脚（thigh.L / thigh.R）へ横の位置（x の符号）で 0 → 0.5**に移す。前と後ろの中心線（x ≒ 0）の頂点は hips のまま（中心の縦の継ぎ目が裂けない）。
- 長いスカートは脚の動きの 5 割までしか追わせない（絵の鐘形の輪郭を保つ）。
- ヤーナのエプロンは「走り・しゃがみで裂けて見える」（結果の文書 3 章の 6）。**待機だけなら今は直さなくてよい**。直すなら上のとおり。
- 靴は SKILL 2.1 のとおり（`BOOT_RAMP`）。

| シャツ（肩・半袖・襟の中・背中の上） | `#DCC7A7` | 胸当ての縁と肩ひもの幅の外を正面の絵 1 枚で測る。袖は袖口の帯の高さで切る |
| 腕（袖口の下から手首） | 肌 | 高さで切る。手首の袖口の帯の上で終わる |
| 脚（裾の折り返しの下から靴の口まで、約 5cm） | 肌 | 折り返しの下端と靴の口の高さで切る（素足が見える） |
| つなぎの胴・腰・脚の下地 | `#54777B` | 部品の真下は布の下地（`cover_body`）。**膝の大きな面の色差・腰の縫い目の線・右腰の脇ポケットの切れ込みは塗らない**（spec は「脚の面の小さな色差はテクスチャ」と書くが、決まりの塗りでは平らな 1 色にする。形の面の折り目で陰が出る） |
| 首・顔 | 肌 | 襟の上で高さで切る。あご下・首の後ろは決まりの肌 |

### 8.3 顔

通常・笑顔・驚き・怒りの 4 表情（`nico_face_expressions_r2.png`、左上通常・右上笑顔・左下驚き・右下怒り）。大きな青緑の目と短いまつ毛は顔の絵のまま貼る（目の色は `spec` に hex が無い。顔の絵に含まれるので指定は不要）。表情ごとの前髪は同じに描かれている（ヤーナのような前髪の差し替えは要らない見込み）。

### 8.4 垂れる布・持ち物

- 持ち物は無い。**垂れる布も無い**（つなぎは丈の短いふくらんだズボンで、スカートではない）。
- ゴーグルは**頭に付けず、首の布帯から胸の前へ下がる**。骨は chest（待機では動かさない）。走りなどで揺らさない（剛体）。
- 風船形のズボンは、膝から裾にかけて脚の骨より大きく外へ出るので、**体の土台の脚を細くしても外形が合う**ように、ズボンの筒を主役の形にする（脚の絵の輪郭を測るのは筒の部品）。

### 8.5 不足・食い違い

| # | 内容 | 要るか |
|---|------|--------|
| 1 | 必須の絵（全身 6 方向 + 腕なし真横、顔と表情、頭 4 方向、首、手、靴）は全部そろっている | 追加の発注は無し |
| 2 | 腕なし真横は、袖の切り口が空洞の筒（砂色）で描かれている（トルーデ・バートンと同じ） | 描き直し不要。胴の前後の厚みだけを測る |
| 3 | 脇ポケットの切れ込みが右真横だけに見え、左真横には無い（spec は左右対称） | 形にしないので影響なし |
| 4 | 手の拡大の袖口（砂色の折り返し）は、全身の絵の袖の位置より手首に近い | 手の絵に合わせる（小さな帯 2 本） |
| 5 | 右前 45 度（0.629）と左前 45 度（0.689）の足幅比が違い、実際の角度は左右で違う | 較正で測り直す（SKILL 1 章の整合の測定） |
| 6 | ゴーグルのレンズの色は `#594333`（spec）だが、絵では少し赤みの濃い茶 | spec の hex を使う（発光しない平らな色） |
