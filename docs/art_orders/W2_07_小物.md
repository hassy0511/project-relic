## 1. 描くもの

### 遺跡の設置物
| ID | 名前 | 状態・種類 | 要点 |
|----|------|-----------|------|
| `chest` | 宝箱 | 小・大 × 閉・開 | 先史の保管箱。開けると中から光が漏れる |
| `beacon` | セーブビーコン | 待機・起動中 | **遠くから見える光の柱**を立てる装置。安心感のある形 |
| `door` | 扉 | 通常・鍵つき・封印・エレベーター | 鍵つきと封印は見た目で区別できること |
| `switch` | スイッチ類 | 床のスイッチ・壁のスイッチ・動力の球・弁の輪 | 「撃てる／押せる」ことが分かる見た目 |

| `repair_s` `repair_l` | 補修パック（小・大） | HP の回復 |

| `we_pickup` | 武器エネルギーの粒 | 敵が落とす小さな回復 |

### 遺物（第1章の 5 点）

| ID | 案 |
|----|-----|

### 壊せる目印（全 9 種）
特殊武器で壊せる・動かせる場所に付ける、ひと目で分かる模様。**今回 9 種すべてのデザインをそろえる**（統一感のため）。

| 特殊武器 | 対象 |
|---------|------|
| ブレイクドリル | ひび割れた壁・岩 |
| アイアンナックル | 重いブロック、大型スイッチ |
| プリズムレーザー | 光の受信装置 |
| ホーミングドローン | 見えない位置のスイッチ |
| サンダーウィップ | 止まった回路 |
| ミラージュデコイ | 感圧床・センサー |
| グラビティウェル | 浮いている岩 |
| フロストエッジ | 凍らせられる水面 |
| 黎光 | 深層の封印 |
