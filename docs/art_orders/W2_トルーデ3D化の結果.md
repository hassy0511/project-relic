# トルーデを絵から 3D にした結果（trude.glb）

> 2026-10-19。Codex の W2-01・W2-01b の絵（`origin/art/w2-townsfolk` の `art/concepts/W2_townsfolk/` の `trude_*.png`・`cane_*.png`、
> `spec.md`・`spec_townsfolk_3d.md`・`spec_townsfolk_3d_add.md`）から、町長トルーデ（140cm、NPC、右手に T 字の杖）の 3D を作り、
> ゲームの 2 か所（町長の家 `ch1.mayor`・中段の広場の壇 `ch1.mid`）の仮の形（茶色のカプセル）と置き換えた。
> 作り方は `.claude/skills/model-from-art/SKILL.md` のとおり「部品の表 → 体の土台 → 顔 → 決まりの塗り → 部品 → 骨」。
> 部品の表の下書きは `W2_人物の部品表.md` の 4 章。設定 `tools/blender/recon/chars/trude.json`、部品の表 `chars/trude_parts.py`、動作 `tools/blender/models/elder_anims.py`。
> 作り直しは `.venv-blender/bin/python tools/blender/recon/build_char.py --char trude --from hull`（views・calib は済み。views を動かすと calib が上書きされる）。
> 部品・動作だけの直しは `--only rig`（約 2.5 分）。**塗りの段（約 5GB）はほかの塗りの段と同時に流さない**（5 章）。
> 確認ページ：https://hassy0511.github.io/project-relic/models/?m=trude
> **2 周目**（統括の確認から：髪の房・帽子・お団子・耳・鼻・肩掛けの前の板・補修布）は 8 章。

## 2. 動作（`tools/blender/models/elder_anims.py`、`ai_character.py --clips elder`）

ハルの 14 動作は杖をついた老人に合わないので、トルーデだけ別の動作を焼く（`chars/trude.json` の `rig_args` に `--clips elder`。
既定は `standard` のままで、ほかの人物は変わらない）。60fps、つなぎは SINE の EASE_IN_OUT、足の裏は床に着ける
（足の接地点はトルーデの靴の寸法 `--foot-contacts=-0.165,0.13,-0.09`）。

| 動作 | 長さ | 中身 | ゲームで使う所 |
|------|------|------|---------------|
| idle | 3 秒の輪 | 右手で杖の T 字の握りを上から握って少し寄りかかる。胸を少し前へ、頭は少し上げて相手を見て、ゆっくり左右を見る。息で胸が動く。左腕は力を抜いて下ろす（広いスカートに手が入らないよう上腕を外へ 12 度） | 町長の家・中段の広場の壇 |

**杖の先を床に着ける右腕の姿勢は、こまごとに解く**（`elder_anims.solve_arm`）：杖は手の部品と一緒に hand.R に付いている
（`ai_character.py` の `_build_grip_hand`。目印＝横棒の中心・先・横棒の軸の点を、基準の姿勢の座標で stats に残す）。
体の姿勢（胸・頭の揺れ）を置いたうえで、上腕・前腕・手首の 8 つの回転を Powell → Nelder-Mead で解く：軸がまっすぐ下、
先が本人の右前（再構築の座標 x −0.285・y −0.235・z 0）、横棒が水平で左右、指が前、肘が体の横（胴にめり込まない）。
4 つのこま（1・46・91・136）とも、先のずれ 0.3mm 以内・軸の傾き 0.1 度以内（解いた値は骨付けの段のログ `elder idle`）。
歩きは作らない（ゲームにトルーデが歩く場面が無い。スカートは hips の剛体なので、歩かせるなら脚に沿う重みが要る）。
確認ページは idle を既定で流すので杖をついた姿で見える（基準の姿勢では右腕を下ろしているので、杖は体へ横に刺さる。idle 以外の動作は無い）。

## 3. ゲームへの組み込み（`godot/scripts/view/props_view.gd`）

- `NPC_MODELS` に `npc_trude` → `res://assets/models/trude.glb`。トルーデの出る 2 か所（`ch1_town.json` の中段 `mid` の壇 (0, 0.8, 9)：
  オルドが止まったあと、朝は除く。町長の家 `mayor` (0, 0, 3)：それ以外）は、どちらも同じ `npc_trude` なので、カプセルの代わりにこのモデルが立つ。
  **当たり判定・きっかけ・会話・イベントは変えていない**（sim のファイルは触っていない）。
- 表情：`NPC_FACE_SETS` に `npc_trude` → `NICO_FACES`（区画の順がニコと同じ：通常 0・笑顔 1・驚き 2・怒り 3。会話の `face` の
  smile・smirk・laugh → 1、surprised → 2、angry → 3、serious・sad・normal → 0）。
- 話し手の名前：広場の会話 `ch1.plaza`・`ch1.trude.plaza_after` の話し手は「トルーデ」、名札（住人の名前）は「町長トルーデ」なので、
  今までの「話し手 = 名札」の比べ方では顔が変わらなかった。`NPC_SPEAKERS`（住人 → 名札と違う話し手の名前）を足した。
- 名札の高さ：`NPC_LABEL_Y`（トルーデは 1.8m。既定 2.1m は大人の背丈）。
- 取り込み：`trude.glb.import` の `animation/fps=60`（動作が 60fps）。
- 確認の見本：`--trude_shots`（`godot/scripts/debug/demo.gd`）。町長の家で待つ・話す（通常）、中段の広場の壇で待つ・話す（怒り「静かにおし！」・
  笑み）を撮り、モデルの有無・動作の名前・表情の区画を 5 件確かめる。ハルは横へずらして立たせる（真後ろだとトルーデが隠れた）。

## 5. やり方の記録（うまくいかなかったこと）

| 試したこと | 結果 | 今のやり方 |
|-----------|------|-----------|
| 顔の絵の色を全身の正面の絵へ当てはめる（既定。`face.fit_gain_offset`） | 肌の赤の幅が狭く、赤の倍率が下限 0.75 に当たって切片 +0.48。灰の眉が桃色、茶の目が赤になった（通常・驚き） | `face.COLOR_FIT: false`（新しい定数、既定は今までどおり）。顔の肌は flat.py が 1 色に塗り直すので、当てはめは要らない |
| 肩掛けを体から押し出す量を、超楕円の媒介変数の角度で測る | 点の実の向き（前の肩で 15 度ずれる）と違う向きの体を測り、胸・肩で体が肩掛けを突き抜けた（白い斑点） | 点の実の向きで外から撃ち、押し出しは「近所の最大 → ならす → 必要な量より内へ入れない」。体の頂点で数えて突き抜け 0 |
| 肩掛けを胸の剛体に | 杖をつく右腕の上腕（外へ 35〜43 度）が肩掛けの横を突き抜けた | 近くの体の重みを写す（`FOLLOW_BODY`）。腕を上げた側の肩掛けが腕に沿って持ち上がる |
| スカートを体の土台（レンズ）のまま | 外形の下の縁で厚みが 0 へ丸まり、裾が内へすぼんだ風船・ちょうちんのズボンに見えた | スカートを殻の部品に（1 章の表）。高さごとの体の面＋6mm で、下へ行くほど半径を減らさない |
| スカートの殻の半径の表をならす（`grey_dilation` の mode='wrap'） | 高さの向きまで周期になり、裾の半径がベルトの高さの上の縁へ回り込んで、腰につばができた | 角度の向きだけ周期、高さの向きは端の値 |
| スカートの殻を軸から撃って最初に当たる面で（全部の高さ） | 裾の近くで脚の間の面を拾い、体が殻を突き抜けた（白い点） | 裾の近く（z < 0.40）は外から撃つ（この高さに手は無い）。上は軸から（外から撃つと手・腕を拾う） |
