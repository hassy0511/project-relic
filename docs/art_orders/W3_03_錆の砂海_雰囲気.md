## 1. どんな場所か

- **赤錆の砂丘に沈んだ都市と、半分埋もれたノード**（`docs/design/10_シナリオ設計.md` 4 章の第2章）。先史の都市が千年の砂に呑まれ、ビルの頂部や橋の欄干だけが砂から突き出している。
- オルドが砂海のノードに停泊し、ハルは**初めて昇降リフトで地上に降りる**。第1章（オルドの背中と体内）から、広い外の世界へ出る解放感が見せどころ。
- ノードには黎明機構の**楔**が打ち込まれていて、補給できない（W3-02）。ノードの壁には父コウの印（`art/w1-kou` の `kou_mark.png`）が刻まれている。
- ノードの前で、ライバルのボルタ（`art/w1-volta`）と**ノードの仕掛けの先取り競争**をする。
- 雰囲気は明るい冒険活劇。昼の砂丘は明るく、沈んだ都市の中とノードの奥は日陰と遺物の光。

### 地上フィールドの決まり（`30_レベルデザイン設計.md` 2.2）
| 項目 | 内容 |
|------|------|
| 広さ | 250〜400m 四方の半開放の区域 |
| 着地点 | 昇降リフトの着地点から、ノードの目印が必ず見える |
| 見どころ | 3〜5 か所（小さな遺跡 2 つ、素材の採れる場所、景色のよい場所） |
| 賞金首 | 縄張りを持って歩き回る強い番機（4 体） |
| 地域の危険 | **砂嵐**（見通しが悪くなる。目印の見え方が変わる） |

### 色（W0 A案の地域の代表色）
#8C3F2E、#D97756、#F3E9D2、#7B6A63、#E3A281。遺物とノードの光は琥珀 #FFBC52、楔の侵食は青緑（#91D5D8 前後。W3-01・W3-02）。
