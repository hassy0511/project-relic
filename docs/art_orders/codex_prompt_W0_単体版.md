# Codex への発注プロンプト W0（リポジトリなしで使う単体版）

Codex がリポジトリを読めない場合に使う。必要な情報をすべてプロンプトに含めてある。
下の枠の中を、そのまま Codex に貼り付ける。

## Codex に貼り付けるプロンプト

````text
あなたは、これから開発する 3D アクションアドベンチャーゲームの作画担当です。
この発注では、ゲーム全体の「画風の方向性」を決めるための見本を、方向性の違う 3 案で描いてください。
依頼者が 1 案を選び、以後のキャラクター・敵・背景などはすべてその画風で描きます。

描いた絵は、別の担当（Claude）が 3D モデルに作り直すための設計図として使います。
そのため、絵としての美しさ以上に「形と色が正確に読み取れること」を重視してください。

━━━━━━━━━━━━━━━━━━━━━━━━━━
■ 1. ゲームの世界
━━━━━━━━━━━━━━━━━━━━━━━━━━
- タイトル：『アークウォーカー』
- 遠い未来。地表は赤錆色の砂と、千年前に消えた先史文明の巨大な残骸に覆われている。
- 人々は、山のように巨大な古代の歩行機械〈巡礼機〉の背中に町を築き、大地を歩きながら暮らしている。
- 遺跡から先史の遺物を持ち帰る「回収屋」という職業がある。遺跡は無人の自律機械〈番機〉が守っている。
- 雰囲気は「明るいレトロフューチャーの冒険活劇」。わくわくする冒険が主で、終盤に少しシリアスな真相が来る。現実的なメカの理屈にはこだわらない。
- 遊びの中心は、敵をロックオンして撃つ・光の剣で斬る戦闘と、遺跡の探索。

━━━━━━━━━━━━━━━━━━━━━━━━━━
■ 2. 3 案すべてに共通する条件
━━━━━━━━━━━━━━━━━━━━━━━━━━
- 読みやすさ：3D ゲームの画面で、キャラ・敵・調べられる物がひと目で分かること。
- 先史の技術の見た目（候補）：白磁のような滑らかな白い外装、真鍮の継ぎ目、琥珀色の光。より良い案があれば提案してよい。
- アクセントカラー（候補）：琥珀色。主人公の装甲、相棒 AI、遺物の光で共通に使う「遺物の光」の色。
- 主人公の主な色に、青系を使わない。
- ローポリ〜ミドルポリの 3D（主要キャラで 6,000〜10,000 三角形程度）で再現できる造形にする。
  - シルエットを最優先。大きな面と塊で構成し、細かい凹凸は色の塗り分けで表現する。
  - 髪は細い毛束ではなく、大きな房のまとまりで描く。
  - 体から離れて浮く細い部品、何重にも透ける布、細い鎖の束は避ける。
  - 主要な色は 5〜6 色＋アクセントカラー程度に絞る。

━━━━━━━━━━━━━━━━━━━━━━━━━━
■ 3. 3 案の振り分け（目安。より良い振り分けがあれば提案してよい）
━━━━━━━━━━━━━━━━━━━━━━━━━━
3 案は、塗り方と頭身がはっきり違うものにしてください。
- 案 a：テクスチャの手触りを残したレトロ調（初期の 3D ゲームのような素朴さを、現代の解像度で）。5 頭身前後。
- 案 b：アニメ塗りのセル調（輪郭線あり、影は 1〜2 段）。5.5〜6 頭身。
- 案 c：手描き風の柔らかい塗り（絵本やガッシュ画のような質感）。6〜6.5 頭身。

━━━━━━━━━━━━━━━━━━━━━━━━━━
■ 4. 描くもの（1 案につき 4 枚。3 案で合計 12 枚）
━━━━━━━━━━━━━━━━━━━━━━━━━━
【1 枚目】キービジュアル（ファイル名：artbible_<案>_keyvisual.png）
- 横長 16:9、できるだけ高解像度（最低 1920×1080px）。
- 夜明けの赤錆色の砂漠を歩く、巨大な巡礼機。その背中の町の縁に、主人公の少年（外装フレームを装着）と、肩のあたりに浮かぶ光る球体の相棒 AI が立ち、遠くを見ている。
- 世界の広さと、冒険の始まりのわくわく感を伝える。

【2 枚目】キャラクターの並び図（ファイル名：artbible_<案>_lineup.png）
- 次の 6 人を「同じ縮尺・正面・全身」で横に並べる（画風の見本なので、デザインは仮でよい）。
  1. ハル：15 歳の少年、155cm。回収屋の作業着（ポケットの多い砂色系のジャケット、防砂スカーフ、カーゴパンツ、頑丈なブーツ）に、部分的な古代の外装フレーム。頭はヘルメットではなく、ヘッドバンドから出るバイザー。額にゴーグル。右手に小型のエネルギー銃（腕と一体化させない）、左腕に光の剣を出すガントレット。
  2. ナゴミ：直径 25cm の光る球体ドローン（相棒 AI）。花のつぼみのような分割された外殻が、中心の光を包む。大きな単眼にはしない。
  3. ヤーナ：38 歳の女性、172cm。工房主。がっしりした体格、右腕が機械の義手、作業エプロン、刈り上げの短髪。
  4. ボルタ：17 歳の少女、150cm。自称天才の発明家。ぶかぶかのツナギ、大きなスパナ、跳ねたくせ毛に大きなヘアクリップ。
  5. コウ：45 歳の男性、180cm。伝説の回収屋で主人公の父。風雨にさらされたロングコート、無精ひげ、主人公と同じゴーグル。
  6. アルデン：外見 40 代の男性、185cm。千年前の先史人。白金色の短髪、幾何学文様の入った白と金の長衣、瞳にかすかな光の輪。

【3 枚目】機械の見本（ファイル名：artbible_<案>_machines.png）
- 小型の敵〈番機〉1 体：人の腰ほどの高さ、遺跡を守る無人の自律機械。顔はなく、横一文字のスリット状のセンサーが光る。
- 巡礼機のシルエット：全長 400m 級、背中に町が乗っている。脚は 4〜8 本の範囲で自由。生き物ではなく「機械」として描く。

【4 枚目】地域の色見本（ファイル名：artbible_<案>_colorscript.png）
- 次の 9 地域について、小さな雰囲気のサムネイル 1 枚と、代表色 5 色の色見本を並べる。
  1. オルド背町（巡礼機の背中の町。拠点）
  2. 錆の砂海（赤錆の砂丘に沈んだ都市）
  3. 鏡の塩原（真っ白な塩の平原と、巨大な鏡の塔）
  4. 呑まれた塔（樹海に呑まれた、雲を突く塔）
  5. 凍結プラント（氷に閉ざされた観測施設）
  6. 浮遊岩礁（重力の乱れで岩が浮く空）
  7. 暁の城塞（敵組織の本拠。夜明けの色）
  8. 終着点ターミナス（巡礼機が集まる大地の果て）
  9. 深層アーカイブ（地下深くの眠りの施設）

■ 5. 似せてはいけないもの（将来販売するため、厳守）
━━━━━━━━━━━━━━━━━━━━━━━━━━
次の作品のキャラクター・メカ・デザインに似せないでください。
- ロックマンシリーズ全般（DASH、X、ZERO、エグゼを含む）：腕そのものが砲身になる武器、青いヘルメットの少年、赤いアーマーに金髪ロングの剣士、緑色の光の剣、空賊の一家とその手下のロボット。
- ゼルダの伝説（ブレス オブ ザ ワイルド等）：石の体に青や橙の紋様が光る古代機械、タコ型の古代兵器。
- メトロイド：腕に装着する大型のアームキャノンとパワードスーツ。
- 町や国を背負って歩く巨大なものが出てくる作品：『ゼノブレイド2』の巨神獣、『ONE PIECE』のゾウ、『ハウルの動く城』、『移動都市／モータル・エンジン』、『ワンダと巨像』。
- 有名な RPG の主要キャラクターの、特徴的な髪型と衣装の組み合わせ。

また、次のことも守ってください。
- 既存の絵や写真をなぞったり、組み合わせたりしない。
- 署名、透かし、実在のブランドのロゴや文字を入れない。看板などの文字は、読めない架空の文字にする。
- 描いたあとに自分で上の作品と見比べ、似ている点があれば描き直す。

- 各画像には、上で指定したファイル名を付けてください（ファイル名を付けられない場合は、画像の直前にファイル名を書いてください）。

|------|-----|

- 描けなかったものがあれば、説明書きの冒頭に「未納品：<何を>、理由：<なぜ>」と書いてください。
- 最後に、12 枚のファイル名の一覧と、各案の狙いを 3 行ずつでまとめてください。
````

## 納品物の受け渡し（ユーザー向け）

Codex が描いた絵を、Claude が読める場所に置く手順。

1. Codex の画面から、12 枚の画像をダウンロードする（ファイル名は Codex の指定どおりに付け直す）。
2. GitHub のリポジトリのページを開き、**Add file → Upload files** を選ぶ。
3. アップロード先のフォルダ名として `art/concepts/W0_art_bible/` を入力し、12 枚をまとめてドラッグして、コミットする。
4. Codex が出した説明書き（3 案ぶん）は、次のどちらかで渡す。
   - 同じフォルダに `spec_a.md`、`spec_b.md`、`spec_c.md` として保存する。
   - Claude との会話にそのまま貼り付ける（Claude がファイルにする）。
5. 「W0 を置いた」と Claude に伝える。Claude が 3 案を 3D 化の観点で確認し、比較の要点をまとめる。

> W1 以降の発注では、**選んだ案の画像を Codex に添付**して「この画風に合わせて」と指示する必要がある（Codex はリポジトリを読めないため）。W1 以降の単体版プロンプトは、画風が決まった時点で Claude が用意する。
