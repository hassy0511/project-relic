## 1. なぜ今か

- 第1章の章末（もう遊べる）で、黎明機構の飛行艇の中のダグとハイナルが話す（ダグ 2 行、ハイナル 1 行）。いまは顔アイコンも姿も無い。
- ダグは**第2章のボス**（砂海のノードに打ち込まれた楔の前で戦う）。第5章でオルドの襲撃を指揮し、第7章で住人を守るために寝返る。3D は第2章で要る。
- ハイナルは第4章のボスで、父コウを捕らえた張本人。第1章と第2章では会話と後ろ姿だけ。

## 2. 黎明機構の見た目の決まり（2 人に共通。今後の幹部・兵・飛行艇・楔もこれに合わせる）

| 項目 | 決まり |
|------|--------|
| 考え方 | 「先史の技術を、今の人が組織として使っている」。総帥アルデン（`art/w1-arden`：白と金の長衣、瞳の青緑の光の輪）の気品を少しだけ受け継ぎ、回収屋の手作りの道具（ハルたち）とは逆に、**そろった・整った・量産された**印象 |
| 色 | 地は黒鉛色の金属（#444641 前後）と白磁の板（#F3E9D2 前後）。差し色は金（アルデンの金）を細い線で少し。**先史の光は青緑（アルデンの瞳の輪の #91D5D8 前後）**にして、ハルの琥珀 #FFBC52 と一瞬で見分けられるようにする |
| 紋章 | 黎明機構の紋章を 1 つ決める（夜明け・地平線から昇る光を、大きく単純な形で）。服・腕・飛行艇・楔に付ける |
| 避けるもの | 赤黒の配色・トゲ・ドクロ（いかにもの悪の組織）。実在の軍隊・政治団体の記章や制服を思わせる形。ロックマンシリーズの悪の組織の配色（`00_共通ルール.md` 5 章） |

## 3. ダグ

| 項目 | 内容 |
|------|------|
| 通り名・名前 | 鉄腕のダグ |
| 性別・身長 | 男・195cm（並ぶ人物でいちばん大きい。バートン 190cm より大きい） |
| 年齢 | 壮年（提案してよい） |
| 性格 | 正々堂々とした武人。大食漢。部下と住人を大事にする |
| 一人称・口調 | 俺。短く、武骨 |
| セリフ例 | 「名乗れ、小僧。拳を交える相手の名は覚えておく主義だ」／「腹が減っては戦はできん。……おい、それ食わんのか？」 |
| 戦い方 | 巨大な機械の右腕による格闘。この右腕のコアから、ヤーナが特殊武器「アイアンナックル」（拳を飛ばし、強くのけぞらせる）を作る |
| 見た目の方向（`11_キャラクター設定.md`） | 巨体、**剃り上げた頭と髭**、**巨大な機械の右腕（体の半分ほどの大きさ）** |

### ダグのデザインの条件
- 機械の右腕は、黎明機構の技術で作った**装着式の巨大な籠手**（肩から指先まで。脱いだ下に生身の右腕がある）。2 章の色と光の決まりで、指が動く大きな手と、拳を撃ち出す仕掛け（手首の継ぎ目）を持つ。**腕を砲身にしない**（`00_共通ルール.md` 5 章）。
- 似てはいけない味方：**ヤーナの右の義手**（`art/w1-yana`。自作・真鍮と黒鉛・人の腕の大きさ）、**バートン**（`art/w2-townsfolk`。190cm の大柄で厳格なギルドの支部長。髪あり、ギルドの制服）。遠目のシルエット（右腕の大きさ・剃った頭）と色で見分けられること。
- 左腕と体は生身で、動きやすい黎明機構の制服（2 章の色）。大食漢らしい、腹の出た力士のような体格でもよい。
- 避けるもの：有名作品の「巨大な機械の腕の大男」（『ファイナルファンタジーVII』のバレットの銃の腕など）、ロボットアニメの「ロケットパンチ」の見た目そのもの（拳を飛ばすのはよいが、形は独自に）。

### ダグの表情（会話の顔アイコン）
`normal`（通常）、`serious`（武人の真剣な顔）、`laugh`（豪快に笑う）、`angry`（怒り）、`surprised`（驚き）、`grin`（不敵な笑み・相手を認める）

### ボス戦（提案でよい。最終は第2章の詳細設計で Claude が決める）
- `docs/design/20_ゲームシステム設計.md` 12 章：3 段階（HP 66%・33% で変わる）、攻撃 4〜7 種、大技のあとに反撃の好機、弱点は特殊武器ブレイクドリル（籠手の装甲を砕く）。
- 絵にしてほしい攻撃の案（各：予備動作 → 攻撃 → 硬直）：踏み込みの直拳、床を叩いて輪の衝撃波、**拳を撃ち出して戻す**（ワイヤーで手首とつながる）、つかみかかる突進、籠手を開いて排熱（反撃の好機）。
- 段階ごとの見た目の変化（例：第2段階で籠手の外装が一部はがれ、第3段階で排熱口が開いたまま青緑の光が漏れる）。

## 4. ハイナル（設計の絵と会話の顔だけ）

| 項目 | 内容 |
|------|------|
| 通り名・名前 | 千眼のハイナル |
| 性別・身長 | 女・170cm |
| 性格・口調 | 冷徹で合理的。一人称は私。淡々と、短く |
| セリフ例 | 「千の目がお前を見ている。逃げ場はない」／「感情は照準を狂わせる」 |
| 戦い方 | 小型ドローンの群れを使った狙撃と包囲 |
| 見た目の方向（`11_キャラクター設定.md`） | 細身のロングコート、片目に照準器のモノクル、周囲に浮かぶ小型ドローンの群れ。寒色系 |
| 過去 | 自分の巡礼機が止まって故郷を失った（「今の世界はどうせ滅ぶ」）。第7章で父の独房の鍵を開ける |

- 似てはいけない味方：**ボルタの片目のルーペ**（左のこめかみの真鍮のルーペ）とモノクルの形・位置・色を変える（例：右目、黒鉛の枠に青緑のレンズ、耳当てと一体の照準器）。**コウのロングコート**（オリーブカーキ、ひざ下）とコートの色と形を変える（寒色・細身）。
- ドローンは顔のない小さな機械（手のひら〜頭くらい）。2〜3 種の形を決める（偵察・射撃・盾など）。千体の群れでも重くならない単純な形。
- 避けるもの：有名作品の女性狙撃手（『オーバーウォッチ』のウィドウメイカー、『メタルギアソリッド』のスナイパー・ウルフなど）に似た髪型・服・配色。

### ハイナルの表情（会話の顔アイコン）
`normal`（通常・無表情に近い）、`serious`（冷たく見据える）、`smirk`（わずかな冷笑）、`surprised`（わずかに目を見開く）

## 7. 守ること

- 絵は必ず画像生成機能で描く。描いた絵の拡大縮小・切り抜き・位置合わせに画像編集を使うのはよい。
- `art/concepts/W3_dag/`、`art/concepts/W3_hainal/` 以外のファイルを変更しない。参照した絵を作業ブランチにコピーしない。
- 既存の絵や写真をなぞったり合成したりしない。署名・透かし・実在ブランドの文字やロゴを入れない。
