# 雑貨屋の店主を絵から 3D にした結果（shopkeeper.glb）

> 2026-10-19。Codex の W2-01・W2-01b の絵（`origin/art/w2-townsfolk` の `art/concepts/W2_townsfolk/` の `shopkeeper_*.png`、`spec.md`、
> `spec_townsfolk_3d.md`・`spec_townsfolk_3d_add.md`）から、第 1 章の町の中段の雑貨屋の店主（160cm、NPC、持ち物なし）の 3D を作り、
> ゲームの仮の形（`npc_shopkeeper` のカプセル）と置き換えた。
> 作り方は `.claude/skills/model-from-art/SKILL.md` のとおり「部品の表 → 体の土台 → 顔 → 決まりの塗り → 部品 → 骨」。
> 部品の表の下書きは `W2_人物の部品表.md` の 3 章。設定 `tools/blender/recon/chars/shopkeeper.json`、部品の表 `chars/shopkeeper_parts.py`。
> 作り直しは、まず `python3 tools/blender/recon/chars/shopkeeper_prep.py build/shopkeeper/art build/shopkeeper/src`（下の 0 章の絵の準備。
> `build/shopkeeper/art` は絵のブランチから取り出した元の絵）、
> 次に `build_char.py --char shopkeeper --only views --force` → `--only calib --force` → `--from hull`（重い段は `flock /tmp/blender_heavy.lock` で囲む）。
> 確認ページ：https://hassy0511.github.io/project-relic/models/?m=shopkeeper

## 2. 動作

標準の 14 動作の待機は銃を構える姿勢なので、住人の 4 動作（`--clips child`：待機・歩き・走り・しゃがむ。ニコと同じ `child_anims.py`）を焼いた。
足の接地点は店主の靴の寸法（`--foot-contacts=-0.17,0.08,-0.085`）。**ゲームで使うのは idle だけ**（店の台の後ろに立つ）。
スカート・前掛けは hips に剛体なので、歩き・走り・しゃがむでは脚がスカートを突き抜ける（確認ページの動作の選択でだけ見える。残りの表）。

## 3. ゲームへの組み込み（`godot/scripts/view/props_view.gd`）

- `NPC_MODELS` に `npc_shopkeeper` → `res://assets/models/shopkeeper.glb`。中段（`ch1_town.json` の `mid`、(24, 0, 5.0)、向き 180 度）の雑貨屋の台の後ろに立つ。
  **当たり判定・きっかけ・会話・イベントは変えていない**（sim のファイルは触っていない）。
- 表情：`SHOPKEEPER_FACES`（smile・smirk・laugh → 3、ほかは 0）を `NPC_FACE_SETS` に。
- 名札の高さ：`NPC_LABEL_Y` に 2.0m（お団子の上 0.4m）。
- 取り込み：`shopkeeper.glb.import` の `animation/fps=60`。
- 確認の見本：`--shopkeeper_shots`（`godot/scripts/debug/demo.gd`）。雑貨屋の前に立つ（待機）・話す（笑顔の区画 3）・会話のあと（通常の区画 0）を撮り、3 件確かめる。
