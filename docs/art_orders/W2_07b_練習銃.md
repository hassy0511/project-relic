## 1. なぜ要るか

- 第1章の最初（訓練場・ニコの救出・昼の町）、ハルは回収屋ギルドの**古い練習銃**を使う。とても弱く、連射しかできない。夜にヤーナから父の銃「スパーク」を受け取って、やっと普通に戦えるようになる（`docs/design/20_ゲームシステム設計.md` 2.1、`docs/design/10_シナリオ設計.md` の区間 2）。
- いまのゲームでは、練習銃の見た目がスパークと同じで、性能だけが弱い。ユーザーの指示で、見た目を変える。
- スパーク（ブランチ `art/w1-haru3d` の `spark_gun_3d.png`・`spark_gun_side.png`）：全長約 30cm、黒鉛色の角ばった銃身、琥珀の窓、真鍮の帯、後ろに白磁の当て。

## 2. 描くもの

| 項目 | 指定 |
|------|------|
| 正体 | 回収屋ギルドが見習いに貸す、古い量産の訓練用の銃。何人もの見習いが使い回した。威力は弱い（小さな火花の弾） |
| 一目でスパークと違うこと | ゲームの画面では、ハルの手の中で小さく映る（画面の高さの 1/30 ほど）。**輪郭と色の両方**で、スパークと見分けられること。スパークの「黒鉛色・琥珀の窓・真鍮の帯」の組み合わせを使わない |
| 色と材質の方向 | 町の色（砂色・赤錆色・木）の、くたびれた量産品。例：塗装のはげた砂色の外装、木の握り（割れを布テープで巻いて直した跡）、くすんだ鉄の筒。光る部分は無いか、小さく暗い表示の窓だけ（琥珀にしない） |
| ギルドの印 | 回収屋ギルドの貸し出し番号の小さな札か刻印（架空の文字と数字）。実在の文字・ロゴは入れない |
| 形 | スパークより素朴で、少し短く丸みのある銃身（全長 24〜28cm）。部品の数は少なめ（ローポリで作るので、大きな面と少ない段差） |
| 握り | **握る部分の太さ・長さ・角度と、引き金の位置はスパークと同じ**にする（ハルの右手の 3D の部品が、同じ形のまま握れるように） |

## 4. 守ること

- 既存のファイル（`art/concepts/W2_props/` の絵、`art/w1-haru3d` のスパークの絵）を変えない・消さない。スパークの絵を作業ブランチにコピーしない。
- 実在の銃に似せない（実在の銃の型・刻印・ブランドを連想させない）。腕と一体の砲身にしない（`00_共通ルール.md` 5 章）。
- 類似チェックの結果を spec に書く。
