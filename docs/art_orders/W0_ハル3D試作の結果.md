## 2. 作ったもの

- **モデル**：`tools/blender/models/haru_a.py`（Blender のスクリプト。手作業のファイルは無く、何度でも同じものを作り直せる）
  - 4.5 頭身の骨格（P-1）。骨の名前と構成は標準の人型と同じなので、MVP の 14 動作をそのまま使えた。
  - 本当に曲がるメッシュ。骨までの距離で重みを付け、関節の近くでは 2 本の骨が混ざる。
  - 色は spec の hex を並べた色見本テクスチャ 1 枚で持つ。顔は表情 4 種のテクスチャ（P-9）で、ゲーム中に切り替えられる。
  - 光刃は左前腕の骨に付けた部品として、モデルに含めた（P-4）。銃口と刃の根元の目印もモデルに入れた。
- **テクスチャ**：`tools/blender/models/haru_a_textures.py`（色見本、発光、顔 4 表情をスクリプトで描く）
- **見た目の確認ページ**：`lookdev.html` と `src/lookdev.ts`。自動撮影の道具は `tools/lookdev_capture.mjs`
- **ゲームへの組み込み**：`src/view/playerView.ts` と、見た目の共通処理 `src/view/characterLook.ts`（塗り方の切り替え、表情、輪郭の光）

### 制作の手間（量産の見積もりに使う）
- スクリプトは約 490 行（形の道具は別に共通化、約 290 行）。1 回の作り直しは約 50 秒。
- 比率の調整に 4 回、細部の調整に 3 回、作り直した。
- 手間がかかった点：髪の房（約 20 個）の位置を座標で決める作業、ゴーグルの帯を髪の表面に沿わせる作業、顔のテクスチャを頭の形に合わせる作業。
- 手間がかからなかった点：骨と動作の使い回し、色の変更（spec の hex を変えるだけ）、装甲など硬い部品。
- 見込み：同じ作り方なら、**人型の 2 人目からは共通部品（手、靴、骨、形の道具）を使えるので、1 人あたりの手間はハルより少ない**。髪と顔は人ごとに作り直しになる。

## 4. 確認項目ごとの結果

### 4-1. 輪郭・顔・色分けが読めるか（正面・横・背面・ゲーム中の距離）
- **正面・斜め**：A案の色の分け方（レンガ色の作業着、白い装甲、暗いフレーム、琥珀の光）は、そのまま再現できた（`00`、`01`）。
- **顔**：大きな目、眉、小さな口をテクスチャで描く方式で、近くで見たときの可愛さと少年らしさは出せた（`02`）。表情の切り替えも読める。
- **ゲーム中の距離（5.5m）**：顔の細部はもう読めない（これは想定どおり）。代わりに、**はねた髪の輪郭、白い装甲、黒い銃が目印になり、向きと動きは読める**（`05`）。
- **横と背面**：絵が無いので仮の形（P-6、P-7）。背中の X 字の帯と後ろ髪は、ゲームのカメラ（主に後ろから見る）でいちばん長く見える部分なので、**追加作画 H-1 が必要**。

### 4-2. 肩・膝・肘の変形と装備の干渉（走る・跳ぶ・撃つ・斬る）
- 肘・膝・肩は、距離で付けた重みで破綻なく曲がった（`04`）。
- 銃は腕を伸ばすと上面が上を向く向きで作ったので、ゲームの照準処理（右腕を前へ上げる）でそのまま正しく構えられた。
- 光刃は前腕に沿って拳の先へ伸びるので、横薙ぎでは腕の延長の刃として読める（`m2`）。
- 見つかった問題と対処：
  - **振り下ろしの構えで左手が頭に当たった** → 頭が大きくなったため。腕を少し横に開く姿勢に直した。
  - **右の太ももの板**は太ももの骨に固定したので、脚を大きく振るとベルトから離れる（`03` の走り）。T-4 で直す。
  - 跳躍で脚を高く上げると、股のあたりの布が伸びる。遠目では目立たない。
- ゲームのコードの不具合を 1 つ見つけて直した：**撃ち終えても右腕が上がったまま戻らない／跳躍中に撃つと胸のひねりが積み重なる**。MVP からあった不具合。three.js が値の変わらない骨を書き直さないことが原因。テストを追加した（`tests/unit/poseOverride.test.ts`）。

### 4-3. 赤い砂と暖かい光の中で、人物を見失わないか
- **ここが A案のいちばんの課題。** spec では作業着と砂丘が同じ `#B75B43` なので、赤い砂の上ではハルの服が地面に溶ける（`05`、`06`）。
- 見分けの手がかりは、髪、白い装甲、黒い銃、影。止まっているときより、動いているときのほうが見つけやすい。
- 輪郭の光（リムライト）を足すと少し良くなるが、光だけでは解決しきれない（`06`）。強さ 0.45 を標準にした。
- 逆光（キービジュアルと同じ向きの朝日）では、ハルは暗い影絵になる。雰囲気は出るが、戦闘中の見やすさは落ちる。

### 4-4. 塗り方の比較
- **柔らかい陰影**：W0 の絵の、手で塗ったような柔らかさに近い。
- **3 段の塗り分け**：境目がくっきりして、遠目でも形が締まって見える。アニメ調に寄る。
- どちらでも A案の雰囲気は保てる。**試作では「柔らかい陰影＋輪郭の光」を標準にした**。どちらにするかは D-1 で決めてほしい。
