# 発注書 W2-08：UI

> Codex（作画担当）へ。`00_共通ルール.md` と、選ばれたアートバイブルに合わせて描くこと。
> 納品先：`art/concepts/W2_ui/`
> UI の実装は Claude が HTML/CSS で行う。ここで描いてほしいのは**見た目のデザイン（画面の見本、部品、アイコン）**。

---

## 1. デザインの方向

- 世界観に合った UI：先史の遺物の技術（アクセントカラーの光のライン）と、回収屋の手作りの道具（使い込まれた金属、革、布）の組み合わせ。
- **戦闘中でも一瞬で読み取れる**こと。HUD は画面の端にまとめ、中央を広く空ける。
- 文字は日本語。フォントはあとで Claude が商用利用できるフォントから選ぶので、「どんな雰囲気の書体が合うか」を提案してほしい（見本の画面では近い書体で描いてよい）。
