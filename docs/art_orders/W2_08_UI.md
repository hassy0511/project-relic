# 発注書 W2-08：UI

> Codex（作画担当）へ。`00_共通ルール.md` と、選ばれたアートバイブル（W0 A案）に合わせて描くこと。
> 納品先：`art/concepts/W2_ui/`　作業ブランチ：`art/w2-ui`
> UI の実装は Claude が **Godot**（ゲームエンジン）の画面部品（Control・パネル・ラベル）で行う。ここで描いてほしいのは**見た目のデザイン（画面の見本、部品、アイコン）**。部品はそのまま Godot に入れて使うので、3 章の部品の決まりを守ること。
> いまのゲームの画面（仮の見た目）は https://hassy0511.github.io/project-relic/ で遊べる（スマホでは画面の操作が出る）。どこに何が出るかの参考にしてよい。
> **絵は必ず画像生成機能で描く**（プログラムで描いた図形・3D ソフトの画像は不可。描けないときは代わりの方法を取らず、spec の冒頭に「未納品」と書く）。

---

## 1. デザインの方向

- 世界観に合った UI：先史の遺物の技術（琥珀色 #FFBC52 の光のライン、白磁、真鍮）と、回収屋の手作りの道具（使い込まれた金属、革、帆布、つぎはぎ）の組み合わせ。
- **戦闘中でも一瞬で読み取れる**こと。HUD は画面の端にまとめ、中央を広く空ける。
- **スマホの小さな画面でも読める**こと（横向き、画面の高さ 360px 相当まで縮めても文字とアイコンが潰れない）。
- 文字は日本語。フォントはあとで Claude が商用利用できるフォントから選ぶので、「どんな雰囲気の書体が合うか」を提案してほしい（見本の画面では近い書体で描いてよい）。
- **アイコンの絵柄は、W2-07 で納品済みの壊せる目印**（ブランチ `art/w2-props` の `art/concepts/W2_props/mark_*.png` 9 種、`props_marks.png`）と**同じ描き方**にそろえる（線の太さ、色の数、形の単純さ）。特殊武器のアイコンは、その武器の目印と一目で対応が分かるようにする。
- アイテムのアイコンは、W2-07 の拾えるアイテム（`props_items.png`）の形に合わせる。

## 3. 部品（Godot にそのまま入れる）

部品は**1 つずつ別の PNG**（透明の背景）で描く。Godot で伸ばして使うため、次の決まりを守る。

- **伸ばす枠**（パネル・ゲージの枠・ボタン・会話ウィンドウ）：四隅の飾りは角に収め、辺の中ほどは**どこで切っても同じ模様**（伸ばしても崩れない）にする。spec に「角の大きさ（px）」を書く（9 分割で伸ばす）。
- **ゲージ**：枠と中身を別の画像にする（中身は横に伸ばして長さを変える）。満タン・減少・危険の色は中身の色を変えて表す。
- **状態**：ボタンは「通常・押している・選んでいる（フォーカス）・使えない」の 4 つ。
- **光る所**は平らな色で塗る（光のにじみはゲームで足す）。影を付ける場合は、部品の画像の中に収める。
- 大きさ：アイコンは 256×256px で描く（128px に縮めても読めること）。

## 6. 守ること

- 絵は必ず画像生成機能で描く。プログラムで描いた図形・3D ソフトで作った画像は不可。描けないときは代わりの方法を取らず、spec の冒頭に「未納品」と理由を書く。
- 実在のゲーム機のボタンの記号・ロゴ・商標（会社のマーク）を描かない。ボタンの表示は「A」「RT」などの文字か、独自の記号にする。
- 『ロックマン』シリーズの HUD（縦長のライフゲージなど）に似せない。
