> Codex（作画担当）へ。`00_共通ルール.md`、選ばれたアートバイブル（W0 A案）、ブランチ `art/w1-haru3d` のハルの絵に合わせて描くこと。
> 納品先：`art/concepts/W1_haru_3d/`（ハルの既存のフォルダ）　作業ブランチ：`art/w1-haru3d`（既存のブランチに追加する）
> 第5弾（2026-10-06）。**絵は必ず画像生成機能で描く**（3D ソフトで作った画像・プログラムで描いた図形は不可。描けないときは代わりの方法を取らず、spec の冒頭に「未納品」と書く）。

## 1. なぜ要るか

- 第1章の会話で、ハルは約 90 行話す（いちばん多い）。ヤーナ・ナゴミ・住人・ボルタ・コウ・アルデンには会話の顔アイコン（胸から上・斜め前・透過 1024px）があるのに、**ハルだけ無い**。
- いまのゲームは、3D モデル用の顔の絵（`haru_face_expressions.png` の 2×2）を切り抜いて代わりに使っている。表情が 4 つしかなく、首から上・真正面なので、ほかの人の顔アイコンと並べると見え方がそろわない。
- W1-01（ハルの設計の絵）の「会話の顔アイコン」だけを先に、**いまのハル**（`art/w1-haru3d` の 3D 変換用の絵。ゲームの 3D モデル `haru_r` の元）で描いてもらう。W1-01 の残り（普段着とフレームの三面図など）は今回は描かない。

## 3. 形式（ほかの人の顔アイコンとそろえる）

| 項目 | 指定 |
|------|------|
| 大きさ | 1024×1024px、透過 PNG（RGBA） |
| 構図 | 胸から上。体は本人の右前へ少し斜め（約 15〜20 度）、顔はほぼ正面〜少し斜め。手本：`art/w1-yana` の `yana_face_*.png`、`art/w2-townsfolk` の `nico_face_*_r2.png`、`art/w1-volta` の `volta_face_*.png` |
| 位置 | **9 枚とも同じ位置・同じ大きさ**。頭のてっぺん（跳ねた髪の先とゴーグルを含む）が上から約 40〜80px、あごが上から約 640〜700px、顔の中心が横 512px 付近。胸は画像の下の端で切れてよい。髪の先・ゴーグル・肩の板を左右と上の端で切らない |
| 表情ごとに変えるもの | 目・眉・口。必要なら頭の小さな傾きと、汗・怒りの記号を 1 つまで。服・髪型・ゴーグルの位置と大きさは変えない |
| 光と塗り | 3D 変換用の絵と同じ平らで柔らかい光と、W0 A案の塗り。背景・床・落ちる影・文字を描かない |
| 小さくしたとき | ゲームでは顔の枠（`art/w2-ui` の `ui_parts_face_frame.png`。256px の枠のうち x 38〜218、y 44〜216 の窓）に入れる。画面では 1 辺 104〜220px、スマホでは約 60px で映る。**128px に縮めても 9 つの表情が見分けられること**（とくに normal・smile・smirk・serious の違い） |

## 4. 表情（9 枚）

ファイル名の表情は、ゲームの会話データの表情の名前と同じにする（ヤーナの顔アイコンと同じ名前の付け方）。行数は第1章の会話でその表情を使う数（ていねいに描く順の目安）。

| ファイル名 | 表情 | 使う場面の例 | 第1章の行数 |
|-----------|------|-------------|-------------|
| `haru_face_normal.png` | 通常（口を閉じた落ち着いた顔） | 普段の会話 | 20 |
| `haru_face_surprised.png` | 驚き（目を見開き、口を開ける） | 予想外の出来事、オルドが止まる | 24 |
| `haru_face_smirk.png` | 得意げ・にやり（片方の口角を上げ、目を少し細める） | 「見習いだって回収屋は回収屋だ！」、調子に乗る | 21 |
| `haru_face_serious.png` | 真剣・決意（眉を寄せ、口を結ぶ） | 「絶対見つけてやる」、遺構へ向かう | 13 |
| `haru_face_laugh.png` | 大笑い（目を閉じ気味、口を大きく開ける） | はしゃぐ、喜ぶ | 6 |
| `haru_face_sad.png` | 悲しみ・うつむき（視線を下げる） | 父のことを思う | 4 |
| `haru_face_angry.png` | 怒り（眉をつり上げ、歯を見せる） | 敵に言い返す | 3 |
| `haru_face_smile.png` | やわらかい笑顔（口を閉じるか少し開ける） | ほっとする、礼を言う | 2 |
| `haru_face_troubled.png` | 困り・苦笑い（眉を下げ、口元を引きつらせる。汗の記号 1 つまで） | ヤーナにツケを取り立てられる | （新しく使う） |

## 6. 守ること

- 既存のファイル（`haru_face_front.png`、`haru_face_expressions.png` など）を変えない・消さない。
- 描いた絵の拡大縮小・切り抜き・位置合わせに画像編集を使うのはよい。形や色を描き足すのは画像生成で行う。
- 類似チェック：`00_共通ルール.md` 5 章の作品（特にロックマンシリーズの主人公の顔、有名作品の「額にゴーグルの少年」）と見比べ、結果を spec に書く。
