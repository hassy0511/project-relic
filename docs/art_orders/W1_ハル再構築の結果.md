# ハルを絵から起こし直した結果（haru_r）

> 2026-09-28。Codex の W1-00 の絵（正面・背面・右真横・右前斜め・顔・4 表情・銃）から、ハルの 3D を作り直した。
> 外のサービス（TRELLIS など）は使わず、この作業環境の中だけで作った。ゲームでは `-- --haru=r` で使える。
> 2026-09-29 追記：W1-00b の追加の絵（左真横・左右の前 45 度・腕の無い右真横・頭の 4 方向・首・手・靴）で直した（4 章）。

## 1. 作り方
| 段 | 内容 | スクリプト |
|----|------|-----------|
| 較正 | 絵ごとのカメラを求める。右前斜めの絵は発注の 45 度ではなく **約 31 度** で描かれていた（左右の脚・腕の間隔の比から求めた）。W1-00b の前斜めは **約 ±46.5 度**（間隔の比 0.688） | `views.py`、`carve.py --stage calib` |
| 体の形 | 3 方向の輪郭で削った塊（視体積）を基に、正面の輪郭をふくらませた丸い体を作り、輪郭の縁だけを絵の輪郭へ合わせる（輪切りごとに決めないので、横じまが出ない） | `carve.py`、`fair.py`、`snap.py` |
| 頭 | 顔・髪の土台・ゴーグル（六角の枠 2 つとベルト）・耳・前髪・髪の房（先が細い房を、3 方向の輪郭に合うように当てはめる）を部品として作る | `hair.py` |
| UV | 平面で 29 の部分に切って開き、隙間を詰めて並べる（テクスチャの 78% を使う。頭は体の約 2 倍の細かさ） | `uvparts.py` |
| 色 | 各方向の絵を、その方向から実際に見えている面にだけ貼る。腕の陰になる胴には腕の色を移さない。顔は高解像度の顔の絵から 4 表情の画像を作って差し替える | `face.py`、`texture.py` |
| 銃 | 横と斜めの絵から作る | `gun.py` |
| 骨と動作 | 既存の骨付けの流れ（`ai_character.py`）に、作った銃・右手の拳（シェイプキー）・平たい光刃を足した | `ai_character.py` |

一度に作り直す：`npm run haru:recon`（`tools/blender/recon/build_haru_r.py`。変わった段だけ作り直す。`-- --review` で確認の画像も作る）

## 6. 部位ごとに平らな色で塗る（2026-09-30）

ユーザーの指摘：ハルの色にしみ・むらがある（特に顔）。ナゴミ・閂（部位ごとに平らな色）は「色が完璧」。
原因は、体の色が各方向の絵をそのまま投影した色だったこと：絵どうしが数 cm 食い違い、絵の陰影・筆のむらも写り、
高解像度の顔の絵（陰影つき）を継ぎ目つきで混ぜていた（耳・もみあげ・ほおのしみ、顔の中の陰）。

**やり方**（`tools/blender/recon/flat.py`、`texture.py` の最後で呼ぶ。既定。前のやり方は `TEX_PAINT=proj` か
設定の `texture.PAINT: "proj"`。ヤーナの設定は `proj` のまま＝作り直すまで前と同じ）：
- 絵は「どこが何色か」を決めるのにだけ使う。焼いた色（視点の多数決）を spec の 7 色（れんが #B75B43・アイボリー #F3E9D2・
  グラファイト #444641・真鍮 #A98749・茶（髪・靴・すね）#594333・琥珀 #FFBC52・肌 #E7B58D）に分ける（明るさの差は半分の重み＝絵の陰影で
  暗い所も同じ色に入る）。部位で使わない色を決める：手にれんが・茶なし、胴・腕に茶なし（襟の内側の陰が茶のしみになった）、
  脚の茶は膝より下、首まわりの襟に暗い色なし、真鍮は籠手とバックルの所だけ、頭の真鍮に近い色はレンズの縁＝琥珀。
- 面の上で掃除：texel を 3mm の箱（部位・法線の向きも鍵）にまとめ、箱のつながり（3D の近さ・法線、UV の継ぎ目をまたぐ）の上で
  多数決のぼかしを 4 回 → 3D の面積が 3.5cm² より小さい島を周りの色へ併合（真鍮 0.4・琥珀 0.25cm²、手 0.3cm²、頭 5cm²）。
- 各 texel は近くの箱の色の重み付きの多数決、境目だけ 2 色を細く混ぜる。陰影は焼かない（光はゲームが付ける）。約 40 秒。
- 顔（2×2 の表情の画像）：肌に近い色の画素 → 体と同じ平らな肌色。表情の範囲の中の、肌に囲まれた小さな塊（目・眉・まつ毛・口・歯）は
  絵の色のまま（縁の画素だけ平らな肌色と混ぜる）。区画の縁に届く大きな塊（髪）は平らな茶。鼻・ほおの陰影と赤みは消える。

**結果**（`haru_r_trial/flat_before_after.jpg`：上から絵・前・後、`face_before_after.jpg`：4 表情の前後、
`ingame_showcase.jpg`：Godot の画面）：
- 顔の肌が 1 色になり、体の首・耳の肌と同じ色なので継ぎ目が消えた。顔の中の陰（鼻・ほお・あご）が無くなり、目・口はくっきりのまま。
- 上着・ズボン・板・帯・手袋・靴が平らな色になり、筆のむら・陰影のしみは消えた。境目はなめらか。
- 失ったもの（1 回目）：帯のバックル（2 回目で戻した）、絵の陰影がつくっていた立体感（顔の鼻）。

**2 回目の直し（同じ日）**：1 回目は顔の近写の下の胸・襟が迷彩のようなまだらになった（上を向いたフード・肩の上は
どの絵もよく見ていない面で、塗り足しの色から分けていた。襟の内側の陰は灰・茶に分けられた）。
- 胸・襟・首・帯の前（高さ 0.79〜1.215m、前を向いた面と上を向いた面）は、多視点の多数決をやめ、**正面の絵そのものを 2D で色に分け**
  （陰で暗い赤は茶に分けてから赤へ、肌は首の前の幅だけ）、2D で多数決のぼかしと小さな島の併合をした「色の地図」を正面からまっすぐ貼る。
  背中の同じ高さ（と首の後ろ）は背面の絵で同じことをする。シャツの V・フードの襟・肩ひもが絵どおりの形になり、**帯のバックル**も戻った。
- **ゴーグル**は形の部品の輪郭（`hair.py` の枠・レンズの多角形）で塗る：レンズ＝琥珀、枠・橋＝グラファイト。絵の色は使わない。角がくっきり。
- UV がつぶれて texel を持たない三角形（2,675 個、約 330cm²）に、3D で一番近い texel の色を UV の所へ書く（`patch_empty_tris`）。

**残っている問題**（2 回目の後）：
1. 首の後ろ（髪とフードの間）に 3cm ほどの色の欠けが残る（重なった面か UV のつぶれ。前のやり方でも出ていた）。
2. 右前・左前 45 度で、胸の横（肩ひもの横の面）に帯の灰色の細いぎざぎざが少し残る（正面の地図の外、多数決の所）。
3. 髪の房の分かれ目は形だけで、色は 1 色（絵の髪の明るい房は出ない）。髪と顔の横の境目（もみあげ）は直線的。
4. 顔の鼻は陰影が無くなったので読めない。銃（`gun.py`）は前のまま（絵の投影）。

**3 回目の直し（同じ日：頭を下・後ろ・横から見たしみ）**：ユーザーの指摘は、下から見たあごの下のまだら、髪に混じる耳の肌色、
ゴーグルのベルトの塗りの帯と形のずれ。原因はどれも、形の部品（房・帽子・耳・ベルト）の色を多視点の絵の多数決で決めていたこと：
横の髪にはベルトの帯のグラファイトと耳の肌色が数 cm ずれて載り、あごの下（どの絵も見ていない面）は塗り足しの色から分けていた。
- **形の部品の色は形から**（ゴーグルと同じ考え。`flat.head_parts`、場は `hair.part_fields_at`）：頭（部位 0）はまず全部肌。
  髪の場（帽子・前髪・形の段が当てはめた房。`recon_report.json` の房の値から作り直す）の面の上で頭の面より外＝髪の茶、
  耳の場＝肌、ベルトの場＝グラファイト、ゴーグルは前のとおり。あごの下・首は決まりで肌。絵の色は頭の部品には使わない。
- **ベルトの形**を絵に寄せた：幅 1.8 → 2.3cm、ゴーグルの横 z 1.425 → 1.418、後ろ 1.36 → 1.35（左右の真横の絵は後ろで約 1.335、
  背面の絵は約 1.364 と絵どうしが食い違うので、その間）。塗りはベルトの形そのものなので、形と色がずれない。
- `uvparts.unwrap` の「展開に失敗した島」の見つけ方に「つぶれた面の面積が島の 0.5% より多い」を足した（面の数の 2% だけでは
  首の後ろの左の島を見逃していた）。頭の前・頭の後ろ左右・左腕の前・右手の外の島が CONFORMAL で展開し直されるようになった。
- 結果：`haru_r_trial/head_before_after.jpg`（頭の近写 10 方向の前後：正面・左右 45 度・左右の真横・背面・左後ろの上・上・下 2 つ）、
  `ingame_showcase.jpg`。横・後ろの髪のグラファイトのしみ、耳のまわりの髪の肌色、あごの下のまだらは消え、ベルトは形どおりの帯になった。

**残っている問題**（3 回目の後）：
1. 首の後ろ（髪とフードの間、左側 x 0〜5cm・z 1.20〜1.25）の色の欠けは**直っていない**。原因は塗りでなく UV：その約 300 の三角形の
   UV が縮んで重なっている（UV の密度はほかの約 1/15、裏返った三角形 7 個、UV の面積があるのに texel が 0 の三角形 87 個＝
   ほかの三角形と UV が重なり、その色を拾う）。CONFORMAL で展開し直しても残る。次は、この島を首の後ろで切る（シームを足す）か、
   重なった・裏返った三角形を見つけてその所だけ展開し直す。
2. ベルトは房が突き抜ける所で縁がぎざぎざ（形のとおり）。絵どうしのベルトの高さの食い違い（後ろで約 3cm）は間を取った。
3. 下から光を当てると、あごの下の面の凸凹の陰が見える（色は 1 色の肌。形の問題）。

**4 回目の直し（2026-10-01：体の境目のにじみ・まだら）**：ユーザーの指摘は「顔はきれいになった。体も顔のように塗れないか。
近くで見ると体はまだにじみ・まだらがある」。顔がきれいなのは 1 枚のきれいな絵の線をそのまま使うから。体は texel ごとに
数 cm 食い違う何枚もの絵の多数決で色を決めていたので、袖口・白い板・帯・膝当て・靴のカフの境目がどれもゆらいでいた。
- **1 枚の絵のきれいな形**（`tools/blender/recon/flat_views.py`、`flat.paint_body` から。前のやり方は `FLAT_BODY=vote`）：
  正面・背面・右の真横（腕なし）・左の真横・右の真横（腕だけ）の絵を 2D で 7 色に分けて掃除し、色の塊の輪郭を
  ベクトルの多角形（少しなめらかにして Douglas-Peucker で間引く：直線は直線、角は角）にして 4 倍の細かさで塗り直した「色の地図」を作る。
  texel ごとに、なめらかにした法線がいちばん向いている絵 **1 枚** から色を引く（正面・背面を優先、見えているか奥行きで確かめる、
  約 72 度より斜めの絵は使わない）。絵の切り替わりは細い幅だけ 2 枚を混ぜる。どの絵もよく見ていない所（わきの下・股・靴底など）は
  面の上で一番近い texel の色。境目は texel 1〜2 個の幅のアンチエイリアス。
- **輪の決まり**（絵で測った高さ・長さで、面を平面で切る。ぐるりと真っすぐ同じ太さ）：帯（前 z 0.812〜0.856、後ろ 0.822〜0.872、
  バックルの真鍮は絵のまま）、袖口のグラファイトの輪（肩から腕の軸に沿って 17.7〜20.5cm）とその先の肌、ズボンの裾（z 0.474 より下に赤なし・上に茶なし）、
