# ハルを絵から起こし直した結果（haru_r）

> 2026-09-28。Codex の W1-00 の絵（正面・背面・右真横・右前斜め・顔・4 表情・銃）から、ハルの 3D を作り直した。
> 外のサービス（TRELLIS など）は使わず、この作業環境の中だけで作った。ゲームでは `-- --haru=r` で使える。

## 1. 作り方
| 段 | 内容 | スクリプト |
|----|------|-----------|
| 較正 | 絵ごとのカメラを求める。右前斜めの絵は発注の 45 度ではなく **約 31 度** で描かれていた（左右の脚・腕の間隔の比から求めた） | `views.py`、`carve.py --stage calib` |
| 体の形 | 3 方向の輪郭で削った塊（視体積）を基に、正面の輪郭をふくらませた丸い体を作り、輪郭の縁だけを絵の輪郭へ合わせる（輪切りごとに決めないので、横じまが出ない） | `carve.py`、`fair.py`、`snap.py` |
| 頭 | 顔・髪の土台・ゴーグル（六角の枠 2 つとベルト）・耳・前髪・髪の房（先が細い房を、3 方向の輪郭に合うように当てはめる）を部品として作る | `hair.py` |
| UV | 平面で 29 の部分に切って開き、隙間を詰めて並べる（テクスチャの 78% を使う。頭は体の約 2 倍の細かさ） | `uvparts.py` |
| 色 | 各方向の絵を、その方向から実際に見えている面にだけ貼る。腕の陰になる胴には腕の色を移さない。顔は高解像度の顔の絵から 4 表情の画像を作って差し替える | `face.py`、`texture.py` |
| 銃 | 横と斜めの絵から作る | `gun.py` |
| 骨と動作 | 既存の骨付けの流れ（`ai_character.py`）に、作った銃・右手の拳（シェイプキー）・平たい光刃を足した | `ai_character.py` |

一度に作り直す：`npm run haru:recon`（`tools/blender/recon/build_haru_r.py`。変わった段だけ作り直す。`-- --review` で確認の画像も作る）

## 2. 結果
- 絵との輪郭の一致（重なりの割合）：正面 0.976、右真横 0.967、右前斜め 0.956
- 三角形：体 約 4.6 万。テクスチャ 2048²（体）＋ 2048²（顔の 4 表情）
- テスト 19 本・自動の見本とも成功（`--haru=r`）

独立した点検役の評価は **10 点中 5 点**：
- 正面と背面は絵をよく再現している（色、部品、左右の違い、ゴーグル、顔と表情）。
- ゲームの普段の距離では、デザインどおりに見える。

## 3. 残っている問題（大きい順）
1. 横と斜めから見たときの色の継ぎはぎ：胴の横の肌色の筋、ポーチのあたりの黒ずみ、手袋の縞。
2. 首・フードの襟：のどを横切る茶色の帯、あごの下のこぶ。
3. 髪：横と斜めから見ると丸いもじゃもじゃで、絵のような後ろ・上へ伸びる大きな房になっていない。
4. 手：左手の指が爪のよう、銃の握りがミトンのよう。靴底のぎざぎざ。膝の蝶番と右肩の板のにじみ。
5. 溜め斬り（combo3）で腕が頭に入り込む。走りで銃が横を向く。光刃の色が琥珀より白っぽい。
