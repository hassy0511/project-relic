## 1. どんな町か

- 巡礼機オルドの背中に築かれた、主人公の町。人口は数百人。
- 甲羅（背中の構造物）の曲面に沿った **3 段の段々**の町。
- 歩く巨大機械の上なので、**風と砂と揺れ**に備えた暮らしの工夫がある（防砂の布、固定された家具、揺れ止めの綱、巡礼機から引いた配管と電線、給水塔）。
- 先史の遺物（ガラクタ）を再利用した、手作りの町。温かく、少し雑然としている。
- 昼は活気があり、夜は窓の灯りが美しい。

## 2. 町の配置（レベル設計で決まっている構成）

```
          [頭側]
  上段:  町長の家 / 回収屋ギルド / 展望台
  中段:  広場 ── 市場（雑貨屋・ジャンク屋）/ ヤーナの工房 / 食堂
  下段:  住宅の段々 / ハルの家 / 訓練場 / 昇降リフト / 禁足扉
          [尾側]
```
- 遊べる範囲は約 120m × 70m。段と段の間は、階段・坂・はしごでつながる。
