# 発注書 W2-09：エフェクト

> Codex（作画担当）へ。`00_共通ルール.md` と、選ばれたアートバイブルに合わせて描くこと。
> 納品先：`art/concepts/W2_vfx/`
> エフェクトは Claude がゲーム内で粒子や板ポリゴンで作る。ここで描いてほしいのは、**形・色・時間の流れが分かるキーフレームの見本**。

---

## 1. 描くエフェクト

| ID | 名前 | 描くこと |
|----|------|---------|
| `blade_combo` | 光刃の 3 段コンボ | 1〜3 段目の斬撃の軌跡（3 段目は大きく） |
| `blade_charge` | 光刃の溜め斬り | 溜め中の光 → 振り抜き → 前方に飛ぶ衝撃波 |
| `shot_rapid` | 主武器の連射 | 銃口の光、弾、着弾 |
| `shot_charge` | 主武器のチャージ弾 | 溜め 1 段目・2 段目の銃口の光、弾の大きさの違い、着弾 |
| `drill` | ブレイクドリル | 腕の先に現れるドリルの光、削る火花 |
| `scan` | エコーの解析 | ロックオンした敵をエコーが解析する光の輪、弱点が浮かび上がる瞬間 |
| `frame_fit` | **フレームの装着（見せ場）** | 封印室で、光の粒子が集まって部位が 1 つずつ主人公の体に組み上がっていく。6〜8 枚のキーフレーム |
| `dash` | ダッシュ | かかとのスラスターの噴射と軌跡 |
| `hit` | 命中の火花 | 通常・弱点（大きく派手）・装甲（弾かれる小さな火花）の 3 種 |
| `destroy` | 番機の撃破 | 核の光が弾け、部品が飛び散る |
| `beacon` | セーブビーコン | 光の柱、起動したときの広がる光 |
| `relic_glow` | 遺物の光 | 宝箱や遺物が放つ、拾える物の目印の光 |

---

## 2. 納品物

| # | ファイル名 | 内容 |
|---|-----------|------|
| 1 | `vfx_<ID>.png` | 各エフェクトのキーフレームを左から時間順に並べた 1 枚。各コマの下に経過時間（例：0.00 秒、0.05 秒…）を記入 |
| 2 | `spec.md` | `00_共通ルール.md` 6 章の項目。加えて、各エフェクトの色（hex）、明るさの変化、持続時間の目安 |
