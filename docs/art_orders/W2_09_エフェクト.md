# 発注書 W2-09：エフェクト（第1章）

> Codex（作画担当）へ。`00_共通ルール.md` と、選ばれたアートバイブル（W0 A案）に合わせて描くこと。
> 納品先：`art/concepts/W2_vfx/`　作業ブランチ：`art/w2-vfx`
> エフェクトは Claude が **Godot**（ゲームエンジン）の粒子や板ポリゴンで作る。ここで描いてほしいのは、**形・色・時間の流れが分かるキーフレームの見本**と、粒子に貼る**素材の画像**（3 章）。
> いまのゲーム（仮のエフェクト）は https://hassy0511.github.io/project-relic/ で遊べる。
> **絵は必ず画像生成機能で描く**（プログラムで描いた図形・3D ソフトの画像は不可。描けないときは代わりの方法を取らず、spec の冒頭に「未納品」と書く）。

---

## 1. 色の決まり

| 光 | 色 | 使う所 |
|----|----|-------|
| ハルの光（フレーム・光刃・スパーク） | 琥珀 #FFBC52 を中心に | 光刃、主武器、ダッシュ、ナゴミ |
| 番機の光 | W2-02 の spec のセンサーの色（通常・警戒）と核の色 | 番機の弾・予備動作・撃破 |
| 閂の光 | W2-03 の spec の錠前核の色。第3段階の赤熱 | 閂の攻撃 |
| 拾える物・セーブ | W2-07 の spec の色 | 宝箱・遺物・ビーコン |

- 光刃の色は**緑にしない**（『ロックマン』シリーズの緑の光の剣と重ならないように）。
- ハルの光と敵の光は、**一瞬で見分けられる**色にする（敵の攻撃の合図が読めること）。
- 画面の明滅が強くなりすぎないこと（設定でフラッシュを抑える前提だが、標準でもまぶしすぎない）。

## 2. 描くエフェクト

名前と動きは `docs/design/20_ゲームシステム設計.md`（6〜8 章、10〜12 章）、W2-02（番機）、W2-03（閂）、W2-07（小物）の発注書に合わせる。

### ハル（主武器スパーク・光刃・ブレイクドリル）
| ID | 名前 | 描くこと |
|----|------|---------|
| `shot_rapid` | 主武器の連射（ラピッド型） | 銃口の光、弾、着弾 |
| `shot_charge` | 主武器のチャージ弾（チャージ型） | 溜め 1 段目（0.6 秒、貫通弾）・2 段目（1.2 秒、大型弾）の銃口の光、弾の大きさの違い、着弾 |
| `blade_combo` | 光刃の 3 段コンボ | 1〜3 段目の斬撃の軌跡（3 段目は大きく、小型の敵を浮かせる） |
| `blade_air` | 空中斬り・ダッシュ斬り・踏み込み斬り | それぞれの軌跡（踏み込み斬りは一気に詰める残像） |
| `blade_charge` | 光刃の溜め斬り | 溜め中の光 → 振り抜き → 前方 6m に飛ぶ衝撃波 |
| `drill` | ブレイクドリル（特殊武器 1） | 腕の先に現れるドリルの光、多段ヒットの削る火花、装甲が砕ける破片 |
| `drill_wall` | ドリルでひび割れた壁を壊す | 壁のひびが広がる → 崩れる → 粉じん。W2-07 の目印（`mark_break_drill.png`）が光ってから壊れる |
| `mark_react` | **壊せる目印の反応** | 正しい特殊武器が当たったとき（目印が強く光る → 壊れる・動く）と、違う武器が当たったとき（弾かれて小さく光るだけ）。W2-07 の `mark_*.png` 9 種に共通の動き |
| `dash` | ダッシュ | かかとのスラスターの噴射と軌跡（出だしの無敵の 0.12 秒が分かる強い光） |
| `hurt` | ハルの被弾 | 小さい攻撃（短いのけぞり）と大きい攻撃（ダウン）、被弾後の無敵の点滅の見せ方 |
| `heal` | 補修パックで回復 | 体を包む光 |

### ナゴミとフレーム
| ID | 名前 | 描くこと |
|----|------|---------|
| `scan` | ナゴミの解析 | ロックオンした敵をナゴミが 1.5 秒解析する光の輪、弱点が浮かび上がる瞬間 |
| `node_memory` | **ノードの記憶の取り込み** | ノードから光の粒がナゴミへ流れ込む → ナゴミの殻が開いて光る → 取り込み終わり。第1章の終わり（オルドの記憶）が最初 |
| `seal_open` | 封印室がハルに反応して開く | 血縁にだけ開く生体錠：ハルの手の位置から扉の文様に光が走り、封印が解ける |
| `frame_fit` | **フレームの装着（見せ場）** | 封印室で、光の粒子が集まって部位が 1 つずつ主人公の体に組み上がっていく。6〜8 枚のキーフレーム。**カプセルの中で装甲を授かる演出にしない**（立ったままのハルのまわりに組み上がる） |

### 番機（第1章の敵）
| ID | 名前 | 描くこと |
|----|------|---------|
| `banki_alert` | 番機が侵入者を見つける | センサーの光が通常の色 → 警戒の色に変わる瞬間 |
| `banki_windup` | 攻撃の予備動作 | 0.4 秒以上の「光の合図」：歩哨型の砲口が光る、突撃型の衝角が光って体が沈む |
| `banki_shot` | 番機の弾 | 歩哨型の 3 連射・浮遊型の弾（ハルの弾と色で見分けられる）、着弾 |
| `banki_crash` | 突撃型が壁に激突 | 火花と破片、2 秒動けない間の小さな電気（側面の核が露出） |
| `hit` | 命中の火花 | 通常・弱点（大きく派手）・装甲（弾かれる小さな火花）の 3 種 |
| `shield_break` | 盾型の盾が崩れる | 光刃で盾の耐久を削るひび → 盾が砕ける |
| `banki_destroy` | 番機の撃破 | 核の光が弾け、部品が飛び散る（W2-02 の `<ID>_states.png` の壊れ方に合わせる）。セルと武器エネルギーの粒が落ちる |

### 閂（第1章のボス）

|----|------|---------|

## 3. 粒子の素材（Godot の粒子に貼る画像）

| # | ファイル名 | 内容 |
|---|-----------|------|
| 1 | `vfx_tex_<名前>.png` | 512×512、**黒い背景**（明るさがそのまま光の強さになる）、白〜灰の濃淡で描く（色はゲームで付ける）。火花、光の粒、斬撃の帯（横長 1024×256 でよい）、衝撃波の輪、煙・粉じん、破片のかけら、光の柱、六角形などの先史の文様。8〜12 種 |
| 2 | `vfx_tex_sheet.png` | 素材の一覧（確認用） |

- 素材の端は黒に溶かす（切れ目が出ないように）。

## 5. 守ること

- 絵は必ず画像生成機能で描く。プログラムで描いた図形・3D ソフトで作った画像は不可。描けないときは代わりの方法を取らず、spec の冒頭に「未納品」と理由を書く。
- 既存の作品のエフェクト（『ロックマン』シリーズの緑の光の剣・カプセルでの装甲の授与、『ゼルダの伝説』の古代機械の青や橙の光の紋様）に似せない。
