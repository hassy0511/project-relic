# ヤーナを絵から 3D にした結果（yana.glb）

> 2026-09-29。Codex の W1-03 の絵（`origin/art/w1-yana` の `art/concepts/W1_yana/`、コミット 00ad9db）から、ヤーナの 3D を
> ハルと同じ再構築の流れで作った。ゲームでは MVP の住人 `npc_yana` がこのモデルで立つ（待機の動作、話しかけるとハルの方を向き、
> 会話の行の顔 `face` で表情が変わる）。外のサービスは使っていない。
> 見た目はユーザーが承認した絵のとおり（設定の 38 歳より若く細く見えるが、絵を優先した）。

## 1. 作り方（ハルとの違い）

流れはハルと同じ（`build_char.py --char yana`＝`npm run yana:recon`：較正 → 形 → UV → 顔 → 色 → 関節 → 骨）。
ハル専用だった値を **キャラクターごとの設定 `tools/blender/recon/chars/yana.json`** へ出し、スクリプトは共通にした
（ハルは `chars/haru.json`。ハルを作り直した結果は、メッシュ・テクスチャ・顔のアトラス・関節・GLB が以前と 1 バイトも違わない）。

| 項目 | ハル | ヤーナ |
|------|------|--------|
| 身長 | 1.55m | 1.72m。**再構築は基準の身長 1.55m の座標で行い**（ハルで決めた長さの定数がそのまま使える）、骨付けの段で骨の物体を 172/155 倍に拡大 |
| 形に使う斜めの絵（`three_quarter` の役） | 約 31 度の古い絵 | 右前 45 度の絵（実は約 38.9 度。左前は約 −32.7 度。どちらも左右の脚の間隔の比から） |
| 頭の部品 | ゴーグル・ベルト・前髪の殻・耳 | ゴーグルとベルトなし。**刈り上げ**：帽子（髪の土台）を高さ 1.40〜1.45 より下で頭の面から 8mm までに締める（耳が見える）。前髪の殻は本人の右の前髪の房。房の最初の並びを上寄りに（輪 3 つ、最後の輪は短く）、顔の横へ下がる長い房を 1 本 |
| 顔の断面・耳・首・鼻 | 絵を読んだ節 | ヤーナの絵に 1cm の格子を重ねて読み直した（あご 1.248、目 1.35、顔の前の端、耳の中心、首の中心は体の中心から 1.2cm 本人の右） |
| 表情（2×2） | 通常・笑顔・驚き・痛み | 通常・豪快に笑う・驚き・怒る。表情の絵ごとに前髪の描き方が違うので、差し替える範囲を眉・目・口のまわりに限った（`face.ZONE_RECT`） |
| 持ち物 | 銃（拳のシェイプキー）・光刃 | なし（`ai_character.py --no-weapon`）。銃の段は動かさない |
| 腕 | 右の前腕を腕の無い真横の絵の差で前後に合わせる | 同じ（右＝義手）＋ **左の前腕も左真横の絵の肌の色の中点へ前後に合わせる**（左右の腕の前後の位置が絵で違う） |
| 色 | 左右非対称：右肩の板・右太ももの板・左の籠手 | 左右非対称：**右腕全体（義手）**・右の腰の袋・左の腰の布と小瓶。耳のまわりを肌の色に（`texture.EAR_SKIN`）。背面の絵の重みを 1.2 → 1.0、腕の無い右真横・左真横の向きのハンデを 15 → 5・8 度に（背面の絵のれんが色の布が横から見た背中に回り込むのを減らす。`texture.VIEW_GAIN`・`VIEW_BIAS_DEG`） |
| 靴底 | 斜めの外形へ縁を寄せる | 同じ（試した：斜めの外形へ靴底を寄せないと、視体積の角が板のように残った。靴の内側だけ寄せないのは効果なし。`snap.SOLE_SKIP_Z`・`SOLE_SKIP_X` は既定で使わない） |

新しく足した共通の仕組み（ハルでは使わない値のときは何もしない）：`char.py`、`build_char.py`、`hair.PARTS`・`CAP.undercut`・
`EAR.x0`・`NECK.cx`、`snap.LEFT_ARM_GAIN`、`face.ZONE_RECT`、`texture.EAR_SKIN`・`VIEW_GAIN`・`VIEW_BIAS_DEG`、`ai_character.py` の
`--no-weapon`・`--final-height`・`--name`、`review.py` の拡大の戻し、Godot の住人の確認画像 `godot_npc_showcase.gd`。

## 3. 残っている問題（目立つ順）

直した点（6 回目の直し。設定は `chars/yana.json` の `params` だけ。ハルは変えない）：
- 耳：大きな平たい板 → 小さく頭に近く（`hair.EAR`：半径 (0.007, 0.016, 0.025)、外への開き 10 度、中心 |x| 0.098）。正面・右前・真横の絵の大きさに近い。
- 靴底：斜めの絵の外形へ縁を寄せない範囲を足した（`snap.SOLE_SKIP_Z` 0.05、`SOLE_SKIP_X` 0.125）。左前 45 度のひれは消え、右前 45 度は細い薄板が少し残る。
- エプロンの横：新しい後処理 `texture.apron_cleanup`（`texture.APRON_SIDE`、既定は使わない）。エプロンの幅の外の胴・脚の横に出た
  れんが色（上はシャツの白、下はズボンの色へ）と、タオルの箱の横のれんが色（白へ）を塗り直す。効果は小さい（塗り直し：胴の横 761・脚の横 3,120・タオル 1,550 テクセル）。
- 髪：房を 27 本 → 21 本の変更は 2026-09-29 に戻した。頭のてっぺんが丸い帽子のようになり、絵のとがった先が出ていなかったため。

絵との輪郭の一致（最終のメッシュ）の前 → 後：正面 0.978 → 0.979、右真横 0.972 → 0.975、背面 0.925 → 0.926、
右前 45 度 0.891 → 0.885、左真横 0.843 → 0.845、左前 45 度 0.810 → 0.807。

1. 髪：上へ立つ大きな房（絵のとがった先）は、まだ出ていない（丸い帽子＋横の巻いた房）。頭の拡大の絵（`yana_head_*.png`）は、
   まだ形にも色にも使っていない。立つ房には、外形に合わせない「形を固定した房」か、頭の拡大の絵の外形での当てはめが要る
   （房を表に足して浮きを 12cm にした試しは、外形への当てはめで房がまた下がり、横の一致が下がったのでやめた）。
2. 絵どうしの食い違い：エプロンの横・タオルまわりの白とれんが色のまだらは、後処理では少ししか直らない。原因は形にもある
   （タオルの箱・エプロンの下半分が、左真横で体の前へ平たいひらひらとして出る）。背面の絵の背中のれんが色の布と、真横の絵の白いシャツ
   の食い違いは残る（右の背中の腕の陰の所）。左真横の絵では右の義手が体の向こうに隠れているが、右真横の絵の義手の前後の位置では少し前に出るので、左から見ると
   義手の手が体の前に見える（右真横の絵に合わせた）。
3. 右前・左前の 45 度の絵は実際には 38.9 度と −32.7 度で、左右で違う。左前は外形の一致が低い（0.81）。色は視点ごとの合わせ込みで吸収。
4. 首まわり：首の付け根・肩ひものまわりに茶色のまだら。あご下の顔の材質の境が近くで見ると少し分かる。
5. 靴底：右前 45 度で、靴の下に細い薄板が少し残る（左右の靴が重なる斜めの外形へ縁を寄せるため）。
6. エプロンは脚と一緒に曲がる（走り・しゃがみで裂けて見える）。NPC は待機だけなので今は目立たない。
7. ハンマーの小物（`hammer_*.png`）は作っていない。
