# 練習銃を絵から 3D にした結果（practice_gun.glb）

> 2026-10-18。Codex の W2-07b の絵（`origin/art/w2-props` の `art/concepts/W2_props/`、コミット 89a1e16：`practice_gun*.png`・
> `spec_practice_gun.md`）から、回収屋ギルドの古い練習銃を部品で組み、ゲームに入れた（ダッシュボード 5 章の P4）。
> ハルはスパークを受け取るまで練習銃を持ち、ヤーナから受け取った刻みでスパークに持ち替える。性能（`tuning.practiceGun`）は前のまま。

## 1. 部品の表（SKILL 1 章）

機械なので全部が部品（SKILL 2.2）。色は spec の hex で部品ごとに 1 色。塗りは「はげ」と「木目」だけで、どちらも決まりで塗る（3 章）。

## 2. 作り方（`tools/blender/recon/practice_gun.py`、GLB だけなら約 3 秒、`--review --hand-check` で約 10 秒）

- 座標はスパーク（`gun.py` の `spark_gun.glb`）と同じ：原点 = 握りの中心、銃身 +X、上 +Z、真横の絵は -Y 側（銃の右側）。
  空の目印 `muzzle` は銃口の先（x 20.35cm、上 6.55cm。スパークは x 25.4cm、上 7.2cm）。
- **握り・引き金・用心金の内側はスパークと同じ**：haru_r.glb のスパークの面（材質 `spark_gun`）を、右手の置き場所
  （`ai_character.hand_frame`、`HAND_WRIST_IN_GUN`）の逆で銃の座標へ戻し、真横の外形を多角形にして使った
  （握りの厚み ±1.75cm、用心金の下の棒 ±0.85cm もスパークの値）。戻した座標は、haru_r の目印 `muzzle`（基準の姿勢）がスパークの
  銃口の中心 (25.4, 0, 7.2)cm にぴったり来ることで確かめた。
- ほかの寸法は、真横の絵（全長 25cm → 46.96 px/cm）を、握りがスパークと重なる所（握りの外形の重なり 0.71）に置いて 1cm の格子で測った
  （絵の画素 (px, py) → x = (px − 657) / 4696、z = (1082 − py) / 4696 m）。幅は真上・正面の絵。
- 外装の幅は絵（真上で 5.7cm）より狭いスパークと同じ 4.6cm にした：親指と人さし指の付け根が受け筒の横に沿うため。
- 塗装のはげ（形にしない）：テクスチャの区画を決まりで使い分ける。砂色の大きな面は「まばら」（約 6%）、面取りの帯と短い辺の面（縁）は
  「多い」（約 30%）の区画。はげは擦れた鉄 `#9B8B75`、大きなはげの中はくすんだ鉄 `#666660`。面ごとに、その面を正面から見た投影（m）を
  区画の中の決まった所へ置く（1cm = 32px）。木目は握りの軸の向き。琥珀・真鍮・発光は無い。
- 右手の部品とのめり込み（`--hand-check`）：haru_r の右手の点（hand.R に重み 1、2,478 点）のうち、銃の面より 1.5mm 以上中に入る点は
  練習銃 0・スパーク 0。面から 4mm 以内の点は練習銃 247・スパーク 139（テープの 2 巻きの分だけ指に近い）。

## 3. ゲームへの組み込み

- `PlayerView`（`godot/scripts/view/player_view.gd`）：haru_r を読むとき、右手の骨 hand.R に `BoneAttachment3D` を足し、練習銃を
  スパークと同じ置き場所（`hand_gun_frame`：hand_frame と同じ式を骨の基準の姿勢から作る）に付ける。スパークは体のメッシュの面なので、
  練習銃を見せる間はその面だけ切り抜きの透明な材質に替える（影も出ない）。`muzzle`（Fx の溜めの光の位置）は持っている銃の銃口にする。
  被弾の点滅（`meshes`）は練習銃にも効き、隠した方の銃は点滅のあとも出ない。練習銃の無いモデル（haru_proxy・haru_a）はスパークのまま。
- 銃の決め方：`PlayerView.sync_gun(game)` = `set_gun(game.has_ability("spark"))`。性能（`GameSim.gun_cfg`）と同じ式なので、
  新しく始めた・セーブから再開した・フラグつきで部屋から始めた（後の本筋のフラグでも可）・ヤーナから受け取った刻み、がどれも合う。
  `main.gd` が毎刻み（`set_frame_parts` の隣）と `snap_views`（読み込み・瞬間移動の直後）で呼ぶ。第 1 章の外の部屋はスパーク。
- 弾の出る所（中身）：中身の銃口（`Player.muzzle`）は、練習銃のときスパークより 5cm 手前（`PRACTICE_MUZZLE_BACK`。銃身の長さの差）。
- 弾の見た目（`fx.gd`）：撃った瞬間に測ると、中身の銃口は見た目の銃口の目印より約 29cm 後ろ・15cm 右・7〜9cm 下だった
  （構えると腕が前へ伸びるため。スパークでも前から同じで、弾の尾が手の辺りから出ていた）。当たり判定は変えず、ハルの弾は
  **持っている銃の銃口の目印から出して、2.5m 進む間に中身の位置へ重ねて描く**（`SHOT_BLEND`。差が 0.6m より大きい＝銃口が壁の中で
  胸から撃ったときは寄せない）。銃口の光・溜め撃ちの輪も目印の所。弾の尾は銃口より後ろへ伸ばさない。溜めの光は前から `muzzle` を読む。
- 確認ページ（`tools/model_viewer/index.html`）に「持ち物 › 練習銃」を足した（スパークはハルの右手に付いている）。
- 自動テスト `test_practice_gun_until_spark`（`test_ch1.gd`）：置き場所（スパークの目印とのずれ 3mm 未満）、訓練場は練習銃・
  スパークの面は隠れる・銃口は約 5cm 手前・弾の出る所も 5cm 手前、点滅のあとも変わらない、受け取るとスパーク、セーブ（前・後）、
  後のフラグで部屋から、見本の部屋、仮のモデル。

## 4. 確認の画像（`docs/progress_shots/practice_gun/`）

- `practice_gun_sheet.jpg`（1600×1580）：上の段 = 絵と Cycles の画像（真横・斜め）。その下 = ゲームの画面（PC 1600×900 Vulkan と
  スマホ 844×390 gl_compatibility・タッチ）。訓練場で、受け取る前（練習銃）と後（スパーク）を、ふだんのカメラ（撃ち続けている所。
  画面全体と等倍の切り抜き）と右手の近写（立ち・撃った直後の弾）で。撮り方：`tools/blender/recon/godot_gun_shots.gd`（冒頭に
  コマンド）。撃った直後は続く 4 こまを撮り、弾の描かれたこまを選んだ（描画と中身の刻みが 1 対 1 でないため）。
- 見たこと：近写では練習銃（砂色・木の握り・赤錆色の筒先）とスパーク（黒鉛・琥珀の窓・真鍮の帯）がはっきり違い、右手は両方とも
  同じ形のまま握りに合う。弾は両方とも銃口の先から出る。ふだんのカメラ（真後ろ）で構えると、銃は体の前に隠れてほとんど見えない
  （立っているときは右の腰の横に小さく見える）。
- 外形の重なり（絵と同じ縮尺の正投影）：真横 0.888・真上 0.862・正面 0.805。
