## 1. この発注の目的

W0 A案のハルを、**画像から 3D モデルを作る AI（TRELLIS.2）に入れるための絵**を描く。
この AI は「絵に描いてある色と陰影」をそのまま 3D の表面に写す。したがって、**鑑賞用の絵ではなく、3D の材料としての絵**にする。

- 見た目のデザインは W0 A案 r3 のハルのまま変えない（色は `spec_a.md` の hex を使う）。
- 3D にしやすい条件（2 章）を最優先で守る。雰囲気や構図の工夫は要らない。

関連：`W0_ハル3D試作の結果.md`（前回の 3D 試作の結果）

---

## 2. 3D にしやすい条件（すべての絵に共通・最優先）

| 項目 | 条件 | 理由 |
|------|------|------|
| 背景 | **完全な無地**。透明（アルファ付き PNG）が最良。無理なら真っ白 `#FFFFFF` | 背景が混ざると 3D に余計な形ができる |
| 床と影 | 床、地面の影、接地の影を**描かない** | 影が足の形の一部として 3D になってしまう |
| 光 | **正面からの均一で柔らかい光**。強い陰影、逆光、縁の光（リム）、光沢のハイライトを入れない | 描いた陰影が表面の色に焼き付き、ゲームの光と二重になる |
| 輪郭線 | 描かない（A案どおり） | 線が表面の模様として 3D に残る |
| 視点 | **カメラは胸の高さ、真正面から。遠近感をつけない**（正投影に近い見え方） | 遠近があると頭が大きく、足が小さく歪んで 3D になる |
| 姿勢 | **A ポーズ**：まっすぐ立ち、腕は体から約 35 度開いて斜め下へ伸ばす。肘と膝はまっすぐ。足は肩幅で、つま先は正面 | 骨を入れて動かすための基本の姿勢 |
| 手 | 軽く開いた手。指は少し離し、手のひらは体の側（内側）へ向ける。**何も持たない** | 指がくっつくと 3D で指が 1 つの塊になる |
| 顔 | 正面を向き、目を開けた落ち着いた表情（口は閉じる）。髪で目を隠さない | 顔は 3D で崩れやすいので、はっきり見せる |
| 大きさ | 画像は正方形 **2048×2048 以上**。体全体（髪の先から靴底まで）を画面の高さの 85〜90% に収め、上下左右に余白を残す | 体の一部が切れると 3D にならない |
| 頭身 | **4.3〜4.5 頭身**（`spec_a.md` の目標）。身長 155cm の少年 | ゲームの体型に合わせる |
| 装備 | ゴーグル（額の上）、右肩の板、太ももの板、膝当て、左前腕の籠手は**体に着けたまま**描く。**銃と光刃は描かない**（別の絵にする） | 武器は 3D で別の部品にするため |
| 付け足し | 文字、寸法線、ラベル、矢印、署名を**描かない** | 模様として 3D に残る |

## 3. 納品物

| # | ファイル名 | 内容 | 優先度 |
|---|-----------|------|--------|
| 1 | `haru_3d_front.png` | 全身・正面・A ポーズ（2 章の条件） | **必須** |
| 2 | `haru_3d_back.png` | 全身・背面・同じ A ポーズ。後ろ髪、背中の帯、ゴーグルの帯の回り方が分かること | **必須** |
| 3 | `haru_3d_side_right.png` | 全身・本人の右側から見た真横・同じ A ポーズ | **必須** |

| 7 | `spark_gun_3d.png` | 銃「スパーク」単体。斜め 45 度から見た全体。無地の背景、影なし、均一な光。長さ約 30cm の小型銃 | **必須** |
| 8 | `spark_gun_side.png` | 銃の真横 | 推奨 |

- 1〜4 は**同じ人物・同じ服・同じ姿勢・同じ大きさ**であること。4 枚を並べて高さがそろっていること。
- 形式：PNG・sRGB。透明背景にできた場合は、その旨を spec に書く。

## 4. 説明書（spec_haru_3d.md）に書くこと

1. 納品物の一覧と、それぞれの画像の大きさ。背景が透明か白か。
2. W0 A案 r3 から**変えた点**と理由（姿勢以外は変えないのが原則。変えた場合は必ず書く）。
3. 正面の絵から読み取りにくい部分の説明：
   - 背中の帯の形（X 字に交差するか、そのほかか）
   - ゴーグルの帯が後頭部をどう回るか
   - 右肩の板と太ももの板の取り付け方
   - 靴の底の形
4. 色：`spec_a.md` の hex をどこに使ったか。肌・目・シャツなど spec に無い色を使った場合は、その hex。
5. 制作できなかった項目と、その理由。

---

## 5. 避けること

- 2 章の条件を破ること（とくに影、遠近、武器を持たせること、指をくっつけること）。
- W0 A案のデザインを変えること（色、髪型、装備の位置）。
- 青を主な色にすること。ヘルメット、腕と一体化した砲身、全身を覆うスーツ（`00_共通ルール.md` 5 章）。
