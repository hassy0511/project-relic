# 作画発注の共通ルール

> Codex（作画担当）へ。このルールは、すべての発注書に共通して適用される。
> 各発注書の指示とこのルールが食い違う場合は、発注書の指示を優先する。

---

## 1. 絵の目的

納品された絵は、**Claude が 3D モデルとアニメーションに作り直すための設計図**として使う（会話の顔アイコンなど、一部はそのままゲーム画面にも使う）。
そのため、絵としての美しさ以上に、次のことを重視してほしい。

1. **形が正確に読み取れること**（どの角度から見てもデザインが一致している）
2. **寸法が読み取れること**（同じ縮尺、同じ基準線）
3. **色が数値で分かること**（hex 値の色見本）
4. **ローポリの 3D で再現できる造形であること**

---

## 2. 納品の形式

| 項目 | 指定 |
|------|------|
| 形式 | PNG（sRGB） |
| 解像度 | 長辺 2048px 以上。三面図のシートは 4096×2048px 以上を推奨 |
| 背景 | 無地の明るいグレー（#E6E6E6）。顔アイコンなど「そのまま使う」指定のものは**透過 PNG** |
| 置き場所 | `art/concepts/<波>_<アセットID>/`（例：`art/concepts/W1_haru/`） |
| ファイル名 | `<アセットID>_<内容>.png`（例：`haru_turnaround_casual.png`、`haru_face_smile.png`） |
| 修正版 | 末尾に `_r2`、`_r3` を付ける。古い版は消さない |
| 説明書き | 各フォルダに `spec.md` を置く（下記 6 章） |

- **絵は画像生成機能で描く**。Blender などの 3D ソフトでモデルを作って撮った画像、プログラムで描いた図形の画像は納品しない（2026-09-29 の W2-02・W2-03 でこれが起き、描き直しになった）。3D のモデル・スクリプト・`.blend` などのファイルも納品物に入れない。
- 絵の中に説明の文字を入れる場合は、キャラクターや物に重ならない余白に置く。
- 署名、透かし、実在のブランドのロゴや文字は入れない。看板などの文字は、読めない架空の文字にする。

---

## 3. 三面図（ターンアラウンド）のルール

キャラクター・機械・小物の「三面図」は、次の条件で描く。

| 項目 | 指定 |
|------|------|
| 向き | 正面、斜め前（45°）、側面（キャラクターの右半身が見える向き）、斜め後ろ（45°）、背面 の 5 方向。発注書で方向数の指定がある場合はそれに従う |
| 投影 | **透視をつけない正投影**（遠近感をつけない） |
| 縮尺 | すべての向きを**同じ縮尺**で描く |
| 並べ方 | **1 枚のシートに全方向を横に並べる**（デザインの一貫性を保つため）。各向きの間には十分な余白を空ける |
| 基準線 | 頭頂、目、あご、肩、胸、腰、股、膝、足首、足裏の高さに、細い水平の基準線を引き、全方向で一致させる |
| ポーズ | A ポーズ（腕を体から 45° ほど下げて開く）。指は軽く開く。表情は無表情 |
| 持ち物 | 武器などの持ち物は外し、別の図として描く（発注書で指定がある場合を除く） |
| 陰影 | 平らな光。強い影、逆光、ドラマチックな照明は使わない |
| 禁止 | 背景の描き込み、ぼかし、動きの残像、足の切れ |

**左右が非対称な部分**（片腕だけの義手、片側だけの装甲など）は、どちら側かを文字で明記する。

## 4. ローポリで再現できる造形のルール

- **シルエットを最優先**する。遠くから見ても誰か・何か分かる形にする。
- 大きな面と、はっきりした塊で構成する。細かい凹凸や模様は、色の塗り分けで表現する。
- 髪は細い毛束ではなく、**大きな房のまとまり**で描く。
- 体から離れて浮いている細い部品、何重にも重なった透ける布、細い鎖の束などは避ける。
- 主要な色は 5〜6 色＋アクセントカラー程度に絞る。
- 材質（布、革、金属、陶器のような質感、発光部）を `spec.md` に書く。

---

## 5. 似せてはいけないもの

このゲームは将来販売する。既存の作品に似ていると問題になるため、次の作品のキャラクター・メカ・デザインに**似せないこと**。

| 作品 | 特に避ける要素 |
|------|---------------|
| ロックマンシリーズ全般（DASH、X、ZERO、エグゼなどを含む） | 腕そのものが砲身になる武器、青いヘルメットの少年、赤いアーマーに金髪ロングの剣士、緑色の光の剣、カプセルからアーマーを授かる演出、空賊の一家とその手下のロボット |
| ゼルダの伝説（ブレス オブ ザ ワイルド等） | 石の体に青や橙に光る紋様の古代機械、タコ型の古代兵器 |
| メトロイド | 腕に装着する大型のアームキャノンとパワードスーツ |
| ファイナルファンタジー、キングダムハーツなど有名 RPG の主要キャラ | 特徴的な髪型・衣装の組み合わせ |
| 「町や国を背負って歩く巨大なもの」が出てくる作品（『ゼノブレイド2』の巨神獣、『ONE PIECE』のゾウ、『ハウルの動く城』、『移動都市／モータル・エンジン』、『ワンダと巨像』） | 巡礼機のシルエットと、背中の町の見せ方 |
| その他の有名作品 | 既存の有名キャラクターを連想させる色と形の組み合わせ |

- 描いたあとに**自分で見比べて確認**し、似ている点があれば修正すること。
- 確認した結果を `spec.md` の「類似チェック」欄に書くこと（確認した作品と、修正した点）。
- 既存の絵や写真をなぞったり、組み合わせたりしないこと。

## 6. spec.md に書くこと

各フォルダの `spec.md` には、次の項目を書く。

```markdown
# <アセット名>

## 納品物
- <ファイル名>：<内容>

## デザインの説明
（どんな考えで形と色を決めたか。3〜10 行）

## 色見本
| 部位 | hex | 材質 |
|------|-----|------|
| 髪 | #xxxxxx | — |
| ジャケット | #xxxxxx | 布 |
| 発光部 | #xxxxxx | 発光 |

## 寸法
（身長、主要な部品の大きさ。発注書の指定と違う場合は理由）

## 3D 化のための注意
（非対称の部分、別部品にすべきもの、動く部分）

## 類似チェック
（確認した作品と、似ないように修正した点）
```

---

## 7. 統一感

- W1 以降は、選ばれた**アートバイブルの画風に合わせる**（線の質、塗り方、色の決め方、頭身）。
- 同じキャラクターの絵は、すべてのファイルで顔・髪型・色・部品が一致していること。
