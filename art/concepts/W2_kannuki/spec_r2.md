# W2-03 大番機「閂」：設計画 r2

前回（3D ソフトの画像）からの描き直し。前回は画像生成機能が HTTP 429 `usage_limit_reached` となり、向きと寸法をそろえるため Blender の原型を代用した。しかし設計段階と手描きの造形が欠け、発注と異なる方法を採った判断も不適切だった。今回は全画像を内蔵の画像生成機能で新規作画した。前回のファイルは履歴として残し、この `_r2` を採用候補とする。

未納品：なし。画像生成による各向きの細部・実寸比は完全な製図精度を保証しない。3D 制作では下記のメートル値と `spec_kannuki_3d_r2.md` の接続・可動条件を優先する。

設計画6枚は 4096×2048 px、RGB PNG。画像生成の元画像は主に 1774×887 px で、納品寸法へ Lanczos で補間した。細部が真の4K解像度で生成されたという意味ではない。背景は明るい灰色の無地に近い塗りだが、画像生成による淡い色むらが残る。雰囲気画には発注どおり遠近と演出的な照明を使用した。

## デザインの説明

長い円筒を扉の閂に見立て、左の鈍い錐形の差し込み端、右の角い受け口、両端の太い真鍮環で単なる筒と区別した。
背面中央の対向する厚い白磁の蓋と錠前板を、大技後に開く弱点の機構として見せる。
削岩腕は同形の4本を前後2組に分け、肩・肘・回転する三条の削岩錐を大きな塊で表した。
腹側の2組の爪で部屋の外周レールを挟み、レールを離れる第2段階では胴体そのものが落下する。
第3段階では腕の付け根と外装のすき間だけ赤熱させ、通常時と同じ基本形を保つ。
白磁・鈍い真鍮・暗い芯材・小さな琥珀色は W0 A案と W2-02 番機 r2 に合わせ、眼・顔・古代文字の模様を付けない。

## 寸法

| 対象 | 実装基準 |
|---|---|
| 閂の胴体 | 長さ約10m、直径約3.5m |
| 削岩腕 | 付け根から先端まで約4m、同形4本 |
| 炉心部屋 | 直径32m、天井高16m、閉じた中央の炉心扉、外周レール、壊れる柱4本 |
| 比較人物 | ハル155cm。衣装の厳密な設計は W1 の資料を優先 |

設計画は閂の長大な印象を優先したため、画像中の胴体の長さ／直径の画素比は 10／3.5 に厳密には一致しない。寸法表をモデル化の基準とする。部屋のパースも雰囲気用で、32m と16m を画素から測らない。

## 3D 化のための注意

- 胴体芯・前後端・2本の結束環・外装板・左右の蓋・錠前核・4本の腕・2組のレール爪を別部品にする。
- 腕は1本ずつ破損させられる。破損時には根元の暗い軸受けを残し、失った腕だけ非表示または破損用部品と交換する。
- 閂の前端は鈍い錐、後端は角い受け口。背中の核は長い胴体の上側中央であり、後端面そのものではない。
- 画像の微細なひび・留め具・細い線は画風の密度であり、ローポリ化では大きな面と接続軸を優先する。
- 琥珀・赤熱のグローや床への照り返しはテクスチャに焼き込まない。

## 類似チェック

生成後、[カプコンのロックマンDASH／リーバード資料](https://news.capcomusa.com/devroom/blog/2011/01/19/mega_man_legends_3_dev_blog%3A_event_4%3A_the_reaverbot)、[任天堂のゼルダ BotW ガーディアン資料](https://zelda.nintendo.com/media/)、[任天堂のメトロイド資料](https://metroid.nintendo.com/dread/news/metroid-dread-report-vol-4/)、[PlayStation のワンダと巨像](https://www.playstation.com/en-us/games/shadow-of-the-colossus/)、[ONE PIECE 象主](https://one-piece.com/character/Zunesha/index.html)、[ジブリのハウルの動く城](https://www.ghibli.jp/works/howl/)の公開資料と、W0 A案／W2-02 番機を見比べた。FF・KHの人型キャラクター、巨大な町を背負う機械・生物、車輪都市とも重なる意匠を点検した。

丸い発光部が単眼に見える懸念を避け、開放核を六角形の錠前ローターへ描き直した。石の体と発光する古代紋、タコ型の脚、腕砲、獣の顔・毛、背中の町、車輪の都市は描かず、長い閂胴体・4本の独立した削岩腕・外周レールの爪という構成を維持した。既存の作品画像は生成器へ渡さず、なぞりや合成もしていない。
